## 背景

任务树选中任务时，前端 `TaskDetail` 目前只展示标题、描述、生命周期执行提示及执行中任务的工作目录。任务本身已保存额外信息快照和模板字段，但详情页没有把额外信息用于可读展示；系统环境变量的可用范围也只能从现有 HTTP 帮助或 README 了解。

生命周期链在后端通过 `lifecycle.BuildCommandInput` 将任务详情资源编码为首个自定义命令的标准输入，并根据运行中的本机 HTTP 服务加入可选的 `baseURL`。执行路径会从后端实时读取活动终端。因此由前端自行拼装复制内容会与真实执行的动态状态发生偏差。

命令管理页现有单条命令说明，但缺少一处集中解释链级追加参数、标准输入输出管道、环境变量及重试语义的帮助内容。

## 目标 / 非目标

**目标：**

- 让任务详情可读地展示额外信息快照和应用稳定注入的系统环境变量。
- 让用户一键复制点击时的生命周期首段输入 JSON，并保证其结构和动态字段来源与实际执行共用规则。
- 在生命周期编排页面提供中文、可关闭的命令链扩展规则帮助。
- 为后端快照一致性和前端展示、复制、帮助交互建立回归测试。

**非目标：**

- 不改变生命周期钩子、命令执行顺序、参数合并、环境变量注入或重试的既有语义。
- 不修改任务 HTTP 接口、持久化模型或已有任务数据。
- 不在任务详情展示模板字段派生的 `TASKAI_<字段>` 环境变量，亦不暴露 PowerShell 运行器的内部传参变量。
- 不提供未来某个钩子的预测输入；复制内容只代表用户点击时的当前快照。

## 决策

### 1. 复制输入由后端生成，并与执行路径复用构造规则

新增只读 Wails 绑定，按任务 ID 加载当前任务和设置，复用生命周期执行使用的任务资源与 `lifecycle.BuildCommandInput` 构造逻辑，返回原始 JSON 文本。生命周期执行也经由该共享的应用层辅助方法生成首段输入，保证额外信息、活动终端、当前模板字段和可选 `baseURL` 的语义一致。

前端仅负责调用绑定并通过 Wails 剪贴板 API 写入返回的原始文本，成功与失败均在现有消息反馈机制中呈现。复制不格式化、持久化或记录 JSON。

备选方案是由前端根据 `TaskRecord`、设置和终端状态拼装 JSON。该方案会复制后端 `TaskResource` 的映射和 HTTP 服务状态判断，难以保证与执行时状态同步，因此不采用。通过本机 HTTP 接口读取详情也不采用，因为 HTTP 服务可关闭，且该路径不应成为复制功能的前提。

### 2. 详情页以任务快照与系统变量范围呈现信息

任务额外信息按 `catalogue` 分组，每条快照显示保存时的展示名称、固定字段和动态参数。复选框参数以人类可读的布尔文案展示；没有额外信息时给出空态。展示直接使用任务中的快照元数据，确保信息或模板之后被删除、修改时，历史任务仍可完整阅读。

环境变量区只列出面向用户的稳定系统变量及其注入范围：`TASKAI_TASK_ID`、`TASKAI_TERMINAL_ID` 和条件性注入到新建终端的 `TASKAI_STATUS_API`。模板字段环境变量虽继续按现有规则传给自定义生命周期命令，但不在该区显示。PowerShell 为启动命令使用的内部环境变量也不属于该区。

备选方案是同时展示全部模板派生变量和值。该方案与已确认的产品边界不符，也会令“系统注入”与用户配置注入混淆，因此不采用。

### 3. 在生命周期编排区域提供应用内规则帮助

“命令链”标题旁提供帮助入口，打开中文对话框。内容集中覆盖五个钩子的适用范围与执行顺序、逐行参数和固定参数加链级追加参数的合并顺序、首个及后续自定义命令的标准输入输出传递、环境变量作用范围、Git 与工作目录内置命令规则以及失败后从链首重试的语义。

帮助使用现有 Material UI 对话框和排版模式，不新增外部文档依赖或可配置状态。命令的既有个别 `documentation` 保持原位；集中帮助解释跨命令链的通用规则，两者互补。

## 风险 / 权衡

- [复制后的 JSON 与之后执行时状态不同] → 按钮与帮助明确内容是“当前输入快照”；每次点击均重新由后端读取状态。
- [复制内容包含用户任务数据] → 仅由用户主动触发写入系统剪贴板，不记录、不上传，也不增加持久化字段。
- [剪贴板运行时不可用] → 捕获绑定或剪贴板错误并显示反馈，任务和设置不发生变更。
- [帮助文字与执行规则漂移] → 帮助只描述现有受测试覆盖的行为，并为参数、输入输出和重试规则加入前端回归断言。

## 迁移计划

无需数据迁移。实现时新增只读应用绑定并更新生成的 Wails 前端绑定；前端在加载的任务与设置状态上渲染详情和帮助。若需回滚，移除新绑定和前端入口即可，不影响已有任务、设置或命令链配置。

## 待确认问题

无。任务详情复制范围、系统变量展示范围、帮助入口和验证策略均已在探索阶段确认。
