## ADDED Requirements

### Requirement: 命令管理页提供命令链扩展规则帮助

系统 MUST 在“设置 → 生命周期编排”的命令链区域提供打开和关闭中文“命令链扩展规则”帮助的入口。帮助 MUST 说明五个生命周期钩子的适用范围与执行顺序、命令链按配置顺序执行，以及链中每条命令必须覆盖链全部适用范围。

#### Scenario: 打开并关闭帮助
- **WHEN** 用户在命令链区域点击“查看命令链扩展规则”
- **THEN** 系统打开中文帮助对话框，用户可关闭对话框并继续编辑命令或命令链

### Requirement: 帮助说明参数、数据管道和重试规则

命令链扩展规则帮助 MUST 说明每行参数是一个参数、固定参数先于链级追加参数传入、关闭追加参数编辑不会删除已保存追加参数。帮助 MUST 说明首个自定义命令接收任务输入 JSON，后续自定义命令接收前一自定义命令的原始标准输出且系统不自动解析、合并或补回 JSON。帮助还 MUST 说明系统环境变量与模板环境变量的适用范围、内置工作目录和 Git 命令的特殊参数规则，以及失败重试从链首开始的语义。

#### Scenario: 用户查阅自定义命令的参数传递
- **WHEN** 用户打开命令链扩展规则帮助以配置允许追加参数的自定义命令
- **THEN** 帮助明确该命令先收到固定参数、再收到该链引用保存的逐行追加参数，并说明关闭编辑开关不会清除历史追加参数

#### Scenario: 用户查阅多命令数据传递
- **WHEN** 用户打开命令链扩展规则帮助并查看标准输入输出说明
- **THEN** 帮助明确后续自定义命令必须自行处理前一命令的原始标准输出，且任务详情复制功能仅用于取得当前首段输入快照
