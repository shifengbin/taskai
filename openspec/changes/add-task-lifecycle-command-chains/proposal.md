## Why

任务的开始、结束和修改操作目前无法编排外部命令，也无法向用户展示生命周期自动化的执行进度。将工作目录创建和删除固化在服务中，进一步限制了团队按任务流程接入初始化、通知、校验和清理动作的能力。

## What Changes

- 新增全局命令管理，支持命名自定义命令以及不可编辑、不可删除的系统内置“创建任务工作目录”和“删除任务工作目录”命令；每个命令显式限定可适用的钩子范围。
- 新增可排序、可复制和可按名称复用的命令链管理；链同样显式限定钩子范围，且只能包含覆盖该范围的命令，并可分别为 `beforeStart`、`postStart`、`beforeEnd`、`postEnd` 和 `updateTask` 设置默认链。
- 任务为五个钩子分别保存可选命令链引用；新建任务及未执行任务编辑时可按钩子选择适用链，执行中和已完成任务编辑时只读展示既有选择。
- 在任务开始、结束和执行中任务更新时运行对应链，按标准输入输出逐段传递 JSON 上下文，并在 HTTP 服务可用时传入顶层 `baseURL`。
- 增加任务生命周期命令链的进度、失败、重试和操作锁定；前置钩子失败阻止状态变更，后置钩子失败不回滚业务状态。
- 将任务工作目录的创建和删除改为可编排内置命令，保留安全校验并使重复执行可安全重试。

## Capabilities

### New Capabilities

- `task-lifecycle-command-chains`: 管理生命周期命令和命令链，将其绑定到任务的五个钩子并可靠执行、展示及重试。

## Impact

- 后端涉及任务模型、设置持久化、生命周期服务、应用绑定、工作目录服务和 Wails 事件。
- 前端涉及任务创建/编辑表单、设置界面、任务树操作状态、Wails API 类型与自动生成绑定。
- 需要为 JSON 标准输入输出、目录内置命令、链删除约束、钩子时序和失败重试补充 Go 与前端测试。
