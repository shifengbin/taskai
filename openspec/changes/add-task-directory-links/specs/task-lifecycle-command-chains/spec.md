## MODIFIED Requirements

### Requirement: 全局生命周期命令管理
系统 SHALL 提供全局生命周期命令库。每个自定义命令 MUST 包含稳定 ID、非空名称、非空可执行命令、逐行参数和至少一个钩子适用范围；名称用于用户识别，ID 用于链引用。系统 SHALL 始终提供“创建任务工作目录”“删除任务工作目录”和“同步任务目录链接”三个内置目录命令，且用户不得编辑或删除它们；创建命令仅适用于 `beforeStart`，删除命令仅适用于 `postEnd`，同步命令适用于 `beforeStart`、`postStart` 与 `updateTask` 且不接受链级参数。

#### Scenario: 创建并管理自定义命令
- **WHEN** 用户保存名称、可执行命令和参数均有效的自定义命令
- **THEN** 系统保存该命令并允许后续命令链按 ID 引用它

#### Scenario: 保护系统内置命令
- **WHEN** 用户尝试编辑或删除任一系统内置目录命令
- **THEN** 系统拒绝该操作并保留内置命令的固定定义

#### Scenario: 拒绝删除被链引用的命令
- **WHEN** 用户尝试删除仍被任一命令链引用的自定义命令
- **THEN** 系统拒绝删除并说明该命令仍被引用

#### Scenario: 同步命令不接受参数
- **WHEN** 用户尝试在命令链中为“同步任务目录链接”增加链级参数
- **THEN** 系统拒绝保存参数并说明该系统命令不支持参数

## ADDED Requirements

### Requirement: 系统默认链自动包含目录链接同步

系统 SHALL 提供稳定的“同步任务目录链接”命令链，该链只引用同名系统命令并适用于 `beforeStart`、`postStart` 与 `updateTask`。系统默认“创建任务工作目录”链 MUST 依次执行创建工作目录和同步目录链接；`iterations-ai` 链 MUST 依次执行更新默认分支、创建工作目录、同步目录链接、克隆指定仓库、生成清单和克隆 Git 仓库；“更新仓库”或新安装中的“更新框架仓库”链 MUST 先同步目录链接，再执行更新默认分支、生成清单和克隆 Git 仓库。“删除任务工作目录”链 MUST 保持原命令顺序。系统 MUST NOT 自动修改用户创建的命令链。

#### Scenario: 默认创建链先创建后同步
- **WHEN** 新建任务选择系统默认“创建任务工作目录”链并启动
- **THEN** 系统先创建或复用任务工作目录，再根据任务当前目录字段同步链接

#### Scenario: 公司框架链在仓库操作前同步
- **WHEN** 任务运行 `iterations-ai` 或“更新框架仓库”系统链
- **THEN** 同步命令在对应的克隆、清单或仓库更新命令之前运行，失败时后续命令不执行

#### Scenario: 用户自定义链不被自动插入
- **WHEN** 用户创建一条适用于 `beforeStart` 或 `updateTask` 的自定义命令链
- **THEN** 系统保存和加载该链时不自动加入同步命令，但命令库允许用户手工选择该命令

### Requirement: 默认预设和既有配置安全迁移目录同步

系统 SHALL 让“默认预设”的 `updateTask` 选择稳定的“同步任务目录链接”链，并保留其 `beforeStart` 创建链和 `postEnd` 删除链；“公司框架”预设 MUST 继续让 `updateTask` 选择仓库更新链，并由更新后的仓库链执行同步。升级既有数据时，系统 MUST 始终补齐固定同步命令和缺失的同步链，但 MUST 只更新与上一系统版本在稳定 ID、名称、钩子、命令顺序和参数上完全一致的系统链及预设。已有任务链选择完整匹配旧系统默认映射时 MUST 增加 `updateTask` 同步链；任何自定义链、预设或任务选择 MUST 保持不变。

#### Scenario: 新任务从默认预设获得更新同步
- **WHEN** 当前默认预设为系统“默认预设”，用户创建任务
- **THEN** 任务保存创建工作目录、删除工作目录和任务更新同步三个钩子的展开链选择

#### Scenario: 公司框架继续使用仓库更新链
- **WHEN** 新安装用户使用“公司框架”预设创建任务
- **THEN** 任务的 `updateTask` 仍选择“更新框架仓库”链，且该链的第一条命令为同步目录链接

#### Scenario: 迁移未修改的系统形状
- **WHEN** 升级前的系统链、预设和任务选择与上一版本默认定义完全一致
- **THEN** 系统按新顺序加入同步命令并为旧默认映射加入 `updateTask` 同步链

#### Scenario: 保留已修改的系统链
- **WHEN** 用户曾对具有系统稳定 ID 的链修改名称、钩子、命令顺序或参数
- **THEN** 升级不重写该链，也不把同步命令插入其中

#### Scenario: 保留自定义任务选择
- **WHEN** 既有任务的任一钩子选择不完整匹配旧系统默认映射
- **THEN** 升级保留该任务全部链选择，不自动增加 `updateTask` 同步链
