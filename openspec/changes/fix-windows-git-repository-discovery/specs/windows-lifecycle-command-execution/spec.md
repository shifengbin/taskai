## MODIFIED Requirements

### Requirement: 无窗口限制仅适用于生命周期链后台进程

系统 MUST 将无控制台窗口进程属性（隐藏启动窗口且不创建可见控制台）应用于 Windows 上所有由 TaskAI 直接启动的后台命令子进程：包括生命周期命令链直接执行的后台子进程、任务菜单中标记为后台（不显示终端，`ShowTerminal == false`）的命令项及其前置/后置脚本，以及任务 Git 仓库服务为发现、状态读取、提交、发布和同步直接启动的 Git 子进程。无论进程经 `cmd.exe`、PowerShell 或其他已配置 Shell 包裹，还是直接执行，系统 MUST 保持其工作目录、环境变量、标准输入、标准输出、标准错误、退出状态及执行顺序的既有语义。

系统 MUST NOT 将无窗口属性应用于显示终端（`ShowTerminal == true`）的内嵌终端，其继续通过既有终端后端提供可交互终端。系统不保证隐藏后台命令自身另行显式创建的命令行窗口、Windows Terminal 或图形程序窗口；仅保证 TaskAI 直接启动的后台命令子进程不显示控制台窗口。

#### Scenario: 后台启动的任务菜单命令不显示窗口

- **WHEN** Windows 用户触发任务菜单中标记为后台（不显示终端）的命令项，该命令经 `cmd.exe`、PowerShell 或其他已配置 Shell 启动，或被直接执行
- **THEN** 系统不显示该命令启动产生的控制台窗口，目标程序按其自身方式打开

#### Scenario: 后台启动的任务菜单脚本不显示窗口

- **WHEN** Windows 用户触发标记为后台的任务菜单命令，其前置或后置脚本经配置 Shell 执行
- **THEN** 系统不显示这些脚本启动产生的控制台窗口，并仍按既有规则在前置脚本失败时中止、在命令退出后执行后置脚本

#### Scenario: 任务 Git 仓库查询不显示窗口

- **WHEN** Windows 用户打开任务 Git 标签，系统为候选仓库执行 Git 验证、状态或远程查询
- **THEN** TaskAI 直接启动的每个 Git 子进程均不显示控制台窗口，并继续返回其标准输出、标准错误和退出状态

#### Scenario: 任务 Git 仓库操作不显示窗口

- **WHEN** Windows 用户对任务仓库执行提交、发布分支或同步远程操作
- **THEN** TaskAI 直接启动的每个 Git 子进程均不显示控制台窗口，操作成功或失败仍按既有规则反馈

#### Scenario: 显示终端的任务菜单命令保持内嵌终端

- **WHEN** Windows 用户触发任务菜单中标记为显示终端（`ShowTerminal == true`）的命令项
- **THEN** 系统继续通过既有终端后端提供可交互内嵌终端，不应用后台命令的无窗口限制

#### Scenario: 启动应用内嵌终端

- **WHEN** Windows 用户创建应用内嵌终端
- **THEN** 系统继续通过既有终端后端提供可交互终端，不应用后台命令的无窗口限制

#### Scenario: 命令自身显式打开窗口

- **WHEN** 后台命令自行启动命令行窗口、Windows Terminal 或图形程序
- **THEN** 系统不承诺隐藏该命令自行创建的窗口，且仅保证 TaskAI 直接启动的后台命令子进程不显示控制台窗口

#### Scenario: 后台命令失败仍保留失败信息

- **WHEN** Windows 上无窗口执行的后台任务菜单命令或任务 Git 子进程以非零状态退出
- **THEN** 系统仍保留其标准错误和退出状态，并按对应后台功能的既有规则反馈失败
