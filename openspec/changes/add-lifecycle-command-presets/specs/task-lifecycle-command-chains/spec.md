## ADDED Requirements

### Requirement: 命令链预设管理
系统 SHALL 提供名称非空、大小写不重复且具有稳定 ID 的生命周期命令链预设。每个预设 MUST 为零至五个生命周期钩子保存命令链 ID，且每个非空引用 MUST 指向存在并适用于对应钩子的链。系统 SHALL 允许创建、重命名、复制和删除预设，并允许选择零或一个默认预设；删除当前默认预设 MUST 清除默认选择。预设空映射和空默认选择均为有效配置。

#### Scenario: 保存并复制预设
- **WHEN** 用户保存名称有效、链引用均适用于相应钩子的预设，随后复制该预设
- **THEN** 系统保存原预设并创建具有新稳定 ID 和独立钩子映射的副本

#### Scenario: 设置或清除默认预设
- **WHEN** 用户选择一个现有预设作为默认预设，或随后清除默认选择
- **THEN** 系统相应保存该预设 ID 或空 ID，且不修改预设内容、命令链或任务选择

#### Scenario: 删除当前默认预设
- **WHEN** 用户删除当前默认预设
- **THEN** 系统删除该预设并清除默认预设 ID，新建任务不再自动获得该预设的映射

#### Scenario: 拒绝无效预设引用
- **WHEN** 用户保存引用了不存在链或不覆盖目标钩子的预设
- **THEN** 系统拒绝保存，且不产生部分配置变更

## MODIFIED Requirements

### Requirement: 命令链管理和钩子默认值
系统 SHALL 允许用户创建、重命名、复制和删除带有非空名称与至少一个钩子适用范围的命令链。每条链 MUST 保存有序命令引用，且每个引用命令 MUST 覆盖该链的全部适用范围；用户 SHALL 能调整其中命令顺序。系统 MUST 拒绝删除仍被任一生命周期预设引用的链，也 MUST 拒绝将链的适用范围缩小到不能覆盖任一预设引用钩子的修改。

#### Scenario: 复制并调整命令链
- **WHEN** 用户复制一条已有命令链并调整副本中的命令顺序
- **THEN** 系统创建具有新稳定 ID 的链副本，原链顺序保持不变

#### Scenario: 拒绝删除被预设引用的链
- **WHEN** 用户尝试删除仍被一个或多个命令链预设引用的命令链
- **THEN** 系统拒绝删除并说明该命令链仍被预设引用

#### Scenario: 拒绝缩小被预设引用链的适用范围
- **WHEN** 用户编辑命令链并移除一个仍被预设引用的钩子适用范围
- **THEN** 系统拒绝保存该修改并保留原命令链定义

### Requirement: 任务保存独立的钩子链选择
任务 SHALL 为五个生命周期钩子分别保存零或一个命令链 ID。新建任务表单 MUST 从当前默认预设的完整映射初始化；用户 SHALL 能选择任一预设以替换全部钩子选择，然后按钩子仅从适用链名称中独立调整。预设省略的钩子 MUST 清空该钩子的选择。新建任务保存时 MUST 持久化当前展开后的完整映射，包括显式空映射，而不得持久化预设 ID。未执行任务的编辑表单 MUST 允许修改该映射，执行中和已完成任务的编辑表单 MUST 只读展示已保存选择。后端 MUST 拒绝执行中或已完成任务的链选择修改。任务执行或重试链时 MUST 解析该 ID 指向的最新链定义，而非使用任务创建时的链快照。

#### Scenario: 链只显示适用命令
- **WHEN** 用户将命令链范围设置为 `beforeStart` 和 `postStart`
- **THEN** 链编辑器只允许选择同时覆盖这两个钩子的命令

#### Scenario: 预设和任务按范围筛选
- **WHEN** 用户在预设或任务中为 `beforeEnd` 选择命令链
- **THEN** 下拉框只显示覆盖 `beforeEnd` 的命令链

#### Scenario: 默认预设初始化新任务
- **WHEN** 用户打开新建任务表单且设置了默认预设
- **THEN** 表单为全部五个钩子预选该预设完整映射中的选择

#### Scenario: 选择预设替换全部钩子
- **WHEN** 用户在新建任务表单中选择另一个预设
- **THEN** 系统以该预设的完整映射替换所有五个钩子选择，并清空新预设未包含的钩子

#### Scenario: 单独调整后成为自定义
- **WHEN** 用户在已应用预设的任务表单中改选任一钩子的命令链
- **THEN** 表单显示“自定义”预设状态，且保存该用户调整后的完整映射

#### Scenario: 显式清空不回退默认预设
- **WHEN** 用户清空新建任务的全部五个钩子选择并保存
- **THEN** 任务保存空映射，且不得重新应用默认预设

#### Scenario: 预设改动不影响已创建任务
- **WHEN** 任务已从预设保存其钩子映射，用户随后编辑或删除该预设
- **THEN** 该任务保存的钩子映射保持不变

#### Scenario: 未执行任务编辑链选择
- **WHEN** 用户编辑未执行任务并修改某个钩子的命令链
- **THEN** 系统保存该任务新的链选择，且不执行 `updateTask` 钩子

#### Scenario: 执行中或已完成任务保持链选择
- **WHEN** 用户编辑执行中或已完成任务的标题、描述、颜色或额外信息
- **THEN** 系统保留该任务既有的生命周期链选择，界面不允许修改它们，后端也拒绝修改请求

#### Scenario: 编辑链影响已选择任务
- **WHEN** 任务已经选择某条链且用户随后编辑该链的命令顺序
- **THEN** 该任务下一次执行或重试该钩子时使用更新后的顺序

#### Scenario: 删除链保护可运行任务
- **WHEN** 用户尝试删除被未执行或执行中任务引用的链
- **THEN** 系统拒绝删除该链

### Requirement: 旧任务数据兼容
系统 SHALL 兼容不含生命周期命令链字段的既有设置和任务快照。加载旧数据时，系统 MUST 补齐系统内置目录命令、初始目录链、默认生命周期预设、任务链选择和空执行记录。旧任务缺少链选择时，系统 MUST 从解析出的默认预设映射按任务状态应用既有的范围规则。

#### Scenario: 迁移既有未执行任务
- **WHEN** 系统加载不含链选择字段的未执行任务
- **THEN** 系统为其应用默认预设中的创建目录链和删除目录链选择

#### Scenario: 迁移既有执行中任务
- **WHEN** 系统加载不含链选择字段的执行中任务
- **THEN** 系统为其应用默认预设中的删除目录链选择且不重新创建任务目录

#### Scenario: 迁移既有已完成任务
- **WHEN** 系统加载不含链选择字段的已完成任务
- **THEN** 系统保留其五个钩子选择为空且不创建或删除任何目录
