## MODIFIED Requirements

### Requirement: 工作台与任务树保持跑道式层级
系统 SHALL 在不改变现有工作台布局和操作位置的前提下，使用 2–2.5px 实色描边、默认 2px/3px/4px 的零模糊错位硬投影、6–9px 圆角和 hover 抬起位移表现快门波普的新粗野层级；任务行默认状态不得显示外部硬投影，但必须保留交互态和选择态所需的投影。顶栏、任务树、状态标签、任务行、终端子项、详情区、空状态、分隔条及拖拽反馈必须使用同一视觉语言。每个未选中的任务行 MUST 以其用户定义的任务颜色渲染约 4% 不透明度的极浅背景，并将该颜色作为位于完整外描边内侧的主要 5px 色条。任务和终端的上下文操作控件显示时，必须继承同一视觉语言并保持清晰可辨。

#### Scenario: 查看未选中的任务项
- **WHEN** 用户在任一亮色或暗色模式中查看未选中的任务项
- **THEN** 任务项必须显示约 2.5px 的完整实色描边、9px 圆角、无外部硬投影、任务色的 5px 内嵌色条和约 4% 不透明度的同色背景，并固定为 60px 高；标题以 Hanken Grotesk 800、13.5px 显示在第一行，描述以 Plus Jakarta Sans 500、11.5px 并相隔 1px 显示在第二行，描述为空时第二行显示“暂无描述”，且图标、状态提示和上下文操作控件保持清晰可辨

#### Scenario: 悬停任务项
- **WHEN** 用户在未启用减少动态效果偏好的设备上将指针移入任务项
- **THEN** 任务项必须向左上方抬起 1px，并显示 4px 外部硬投影，不得改变任务行的布局尺寸或操作位置

#### Scenario: 选择任务
- **WHEN** 用户在任务树中选择一个任务
- **THEN** 选中任务必须获得钴蓝描边和硬投影的可见快门波普选择态，任务色内嵌条、标题、描述、状态提示和上下文操作控件仍保持可辨认，且不得显示易被误解为新建任务状态的装饰性尾标

#### Scenario: 查看终端子项
- **WHEN** 用户展开任务并查看其终端子项
- **THEN** 每个终端子项必须显示 2px 实色描边、7px 圆角、次级表面和 2px 硬投影；悬停时必须向左上方抬起 1px 并将投影提升至 3px，选中时使用钴蓝描边与投影，且状态点和关闭操作保持可用

#### Scenario: 拖拽调整任务顺序
- **WHEN** 用户拖拽任务并悬停在有效插入位置
- **THEN** 插入指示器与拖拽预览必须使用快门波普主色或描边清晰标示目标，且不改变原有拖拽判定或排序行为

#### Scenario: 未选择任务或终端
- **WHEN** 用户未选择任务和终端
- **THEN** 详情区必须显示与快门波普主题一致、易读的引导空状态，且创建任务入口保持可见
