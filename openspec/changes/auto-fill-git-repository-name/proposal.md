## Why

创建 Git 额外信息时，用户需要重复填写仓库地址和项目名称；项目名称通常已包含在仓库地址中。项目名称同时用于信息展示和后续 Git 克隆目录，手工录入既增加操作成本，也容易产生不一致。

## What Changes

- 在新增或编辑 `git` 分类信息时，用户修改仓库地址后，自动从地址末段提取项目名称。
- 仅在项目名称为空白时回填，已有或用户手工填写的项目名称不被覆盖。
- 仅对可从最后一个 `/` 后、`.git` 前得到非空名称的地址回填；无效或未完成的地址保持项目名称不变。
- 为自动回填、手工名称保护和非 Git 分类不触发行为补充前端交互测试。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `task-extra-info`: Git 分类信息编辑时根据仓库地址自动回填空的项目名称。

## Impact

- 前端：`frontend/src/App.tsx` 中的额外信息编辑草稿更新逻辑。
- 测试：`frontend/src/App.test.tsx` 中的额外信息管理交互测试。
- 不涉及后端 API、数据存储格式或既有信息迁移。
