## ADDED Requirements

### Requirement: 搁置任务操作显示收纳和恢复图标

系统 MUST 在执行中任务的右键及任务操作菜单中，为“搁置任务”显示 MUI `ArchiveOutlined` 图标，为“取消搁置”显示 MUI `UnarchiveOutlined` 图标。图标 MUST 与同一菜单中现有固定操作的尺寸和图标加文本布局一致，且 MUST 保留完整的中文操作文本。

#### Scenario: 显示未搁置任务的收纳操作
- **WHEN** 用户打开未搁置执行中任务的右键菜单或任务操作菜单
- **THEN** 菜单显示带有 `ArchiveOutlined` 图标和“搁置任务”文本的操作项

#### Scenario: 显示已搁置任务的恢复操作
- **WHEN** 用户打开已搁置执行中任务的右键菜单或任务操作菜单
- **THEN** 菜单显示带有 `UnarchiveOutlined` 图标和“取消搁置”文本的操作项

### Requirement: 图标不改变搁置操作语义

系统 MUST 仅为搁置菜单项增加视觉图标。系统 MUST 保持既有的搁置状态切换、任务排序、生命周期锁定校验、菜单可用性和文本可访问名称。

#### Scenario: 通过带图标菜单项搁置任务
- **WHEN** 用户选择带有 `ArchiveOutlined` 图标的“搁置任务”菜单项
- **THEN** 系统按既有规则持久化任务搁置状态、刷新完整任务列表，并将任务移入搁置区

#### Scenario: 生命周期锁定时不显示搁置切换操作
- **WHEN** 执行中任务处于生命周期命令链执行或失败锁定状态
- **THEN** 系统继续不提供搁置或取消搁置菜单项，与添加图标前的行为一致
