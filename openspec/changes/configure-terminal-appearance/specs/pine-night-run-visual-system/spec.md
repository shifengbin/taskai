## MODIFIED Requirements

### Requirement: 终端与实时状态的视觉连续性

系统 SHALL 让终端标题栏、终端背景、前景文字、光标、选择区和左侧终端项的实时状态点保持清晰可用。xterm 的背景、前景、光标、选择区和 ANSI 调色板 MUST 使用保存的独立终端外观设置，MUST NOT 因工作台处于亮色或暗色模式而改变。默认终端外观 MUST 使用当前暗色终端的完整配色。终端标题栏和左侧实时状态点仍 SHALL 使用工作台视觉系统；右侧活动终端标题栏不得出现影响终端图标或标题阅读的额外横杠、实时状态点或关闭终端按钮，并必须保留始终可见的快捷输入入口。终端的输入输出、尺寸调整、焦点、关闭、剪贴板和实时事件行为不得因终端外观设置而变化；实时状态点和关闭操作必须继续在左侧终端项中可用。

#### Scenario: 在任意模式查看活动终端

- **WHEN** 用户在亮色或暗色工作台中选择一个活动终端
- **THEN** 终端使用已保存的独立主题，右侧标题栏显示终端图标、可裁剪标题和可直接操作的快捷输入入口，不显示实时状态点或关闭终端按钮；左侧对应终端项继续提供实时状态点和关闭入口

#### Scenario: 切换工作台颜色模式

- **WHEN** 用户在存在活动终端时切换工作台亮色或暗色模式
- **THEN** 终端的背景、前景、光标、选区和 ANSI 调色板保持不变，工作台和终端标题栏按新的工作台模式显示

#### Scenario: 终端出现工作中或未读状态

- **WHEN** 终端实时状态为工作中或未读
- **THEN** 左侧终端项的状态点继续使用工作台主题一致的静态或脉冲提示（working=钴蓝、unread=琥珀、error=红、idle=muted），且其现有无障碍状态标签保持不变
