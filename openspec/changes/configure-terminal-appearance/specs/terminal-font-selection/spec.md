## MODIFIED Requirements

### Requirement: 新终端使用已保存字体

系统 SHALL 在创建新的 xterm 会话时读取最新的 `terminalFontFamily` 设置，并将其解析为带默认回退栈的 CSS `fontFamily`。系统 MUST 在保存终端字体后将该字体应用到所有已有 xterm 会话；当前可见终端 MUST 重新适配网格并将新的行列尺寸同步到对应 PTY，后台终端 MUST 在下次显示时适配。更新 MUST 保留会话的滚屏内容和输入状态。

#### Scenario: 保存字体后创建新终端

- **WHEN** 用户保存字体设置并创建一个新终端
- **THEN** 新终端使用所选字体族，缺少字形的字符按默认回退栈显示

#### Scenario: 输出先于视图挂载

- **WHEN** 新终端在右侧视图挂载前收到输出并创建 xterm 会话
- **THEN** 该会话仍使用保存设置中的字体，而不是固定硬编码的旧字体栈

#### Scenario: 保存字体后更新当前终端

- **WHEN** 用户保存新的终端字体且已有终端会话处于活动状态
- **THEN** 已有会话立即使用新字体，当前可见终端重新适配并同步 PTY 行列尺寸，滚屏内容和输入状态保持不变

#### Scenario: 保存字体后切换到后台终端

- **WHEN** 用户保存新的终端字体且另一个活动终端暂未显示，随后切换到该终端
- **THEN** 该终端在显示时使用已保存字体完成适配，不回放或丢失已有输出
