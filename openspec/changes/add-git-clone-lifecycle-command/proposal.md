## Why

任务已经可以关联多条 Git 信息并通过生命周期命令链执行自动化，但命令链不能为同一命令提供本次执行专属的参数，也没有内置能力将这些仓库克隆到任务目录。用户只能手工编写脚本，无法复用任务已保存的仓库地址和分支信息。

## What Changes

- 命令链中的每个命令引用新增可选参数；运行时将其追加到命令自身的参数之后，使同一全局命令可在不同链中获得不同配置。
- 增加不可编辑、不可删除的系统内置“Git 仓库克隆”命令，支持 `beforeStart`、`beforeEnd` 和 `updateTask` 钩子。
- Git 命令从任务选中的全部内置 Git 信息读取项目名称、仓库地址和仓库分支，按顺序批量克隆到链中配置的 `dir` 目录。
- Git 命令在目标项目目录已存在时跳过该项目；指定远程分支不存在时，从远程默认主分支创建同名本地分支。
- 在命令库和命令链编辑界面提供系统命令的使用文档，并为 Git 命令说明 `dir` 参数、目录规则及分支处理行为。
- 兼容既有仅保存命令 ID 的命令链数据，将其迁移为不含链级参数的命令引用。

## Capabilities

### New Capabilities

- `git-lifecycle-command`: 在生命周期命令链中配置单次参数，并通过内置 Git 命令按任务 Git 信息批量克隆仓库。

### Modified Capabilities

<!-- 无。Git 信息既有快照与任务详情结构保持不变。 -->

## Impact

- 后端涉及生命周期命令/链模型、设置持久化迁移、命令链执行器和 Git 子进程调用。
- 前端涉及命令链编辑、系统命令说明、Wails 类型与绑定生成文件。
- 需补充链级参数合并、旧数据迁移、多仓库克隆、分支回退、目录跳过、失败重试和三个钩子可用性的测试。
