## MODIFIED Requirements

### Requirement: 工作台与任务树保持跑道式层级
系统 SHALL 在不改变现有工作台布局和操作位置的前提下，使用柔和 1px 分隔线、克制圆角、充足留白和低对比选择态表现庭院层级。顶栏、任务树、状态标签、任务行、终端子项、详情区、空状态、分隔条及拖拽反馈必须使用同一视觉语言；系统不得显示斜向反光条纹、荧光赛道路标、橘色硬阴影或不规则跑道式圆角。每个未选中的任务行 MUST 以其用户定义的任务颜色渲染约 4% 不透明度的极浅背景，并继续以该颜色的左边框作为主要颜色标记。

#### Scenario: 查看未选中的任务项
- **WHEN** 用户在任一亮色或暗色模式中查看未选中的任务项
- **THEN** 任务项必须显示与左侧任务色条相同色相的极浅背景，约为该任务色的 4% 不透明度，且标题、描述、图标和操作控件保持清晰可辨

#### Scenario: 选择任务
- **WHEN** 用户在任务树中选择一个任务
- **THEN** 选中任务必须获得可见但低干扰的庭院选择态，同时任务标题、描述、操作按钮和用户定义的任务颜色仍保持可辨认，且不得显示易被误解为新建任务状态的装饰性尾标

#### Scenario: 拖拽调整任务顺序
- **WHEN** 用户拖拽任务并悬停在有效插入位置
- **THEN** 插入指示器与拖拽预览必须使用庭院主色或边框清晰标示目标，且不改变原有拖拽判定或排序行为

#### Scenario: 未选择任务或终端
- **WHEN** 用户未选择任务和终端
- **THEN** 详情区必须显示与庭院主题一致、易读的引导空状态，且创建任务入口保持可见
