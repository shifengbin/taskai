## MODIFIED Requirements

### Requirement: 别名终端显示实际会话信息
系统 SHALL 仅在终端具有非空别名且未处于名称编辑状态时，为任务树终端项和右侧终端标题栏提供悬浮提示。提示 MUST 恰好按两行显示：第一行固定为 `标题: <实际标题>`，其中实际标题按既有回退规则得到；第二行固定为 `命令: <启动命令>`；启动命令缺失时，第二行 MUST 在命令值位置显示明确的缺省文本。

任务树中的终端悬浮提示 MUST 显示在对应终端项右侧，并与条目保留间距，不得显示在终端项上方。该提示 MUST NOT 接收鼠标事件或阻挡任务树中终端项的点击。右侧终端标题栏的提示 MUST 保持既有定位行为。

没有别名的终端 MUST 保持既有名称展示，系统不得仅因本能力新增悬浮提示。

#### Scenario: 悬浮查看别名终端的实际信息
- **WHEN** 名为 `前端调试` 的终端实际标题为 `npm run dev`、启动命令为 `zsh`，用户将鼠标悬浮在任务树或右侧标题栏的名称上
- **THEN** 对应提示按两行显示 `标题: npm run dev` 和 `命令: zsh`，且不将别名作为任一提示行

#### Scenario: 启动命令缺失时保留提示结构
- **WHEN** 具有别名的终端缺少启动命令信息，用户将鼠标悬浮在其名称上
- **THEN** 提示仍按两行显示实际名称和明确的启动命令缺省文本

#### Scenario: 任务树终端提示显示在右侧
- **WHEN** 用户将鼠标悬浮在任务树中具有别名的终端名称上
- **THEN** 提示显示在对应终端项右侧并与条目保留间距，不得出现在该终端项上方

#### Scenario: 任务树终端提示不阻挡点击
- **WHEN** 任务树中的终端悬浮提示处于显示状态，用户点击任务树中的终端项
- **THEN** 提示不接收鼠标事件，终端项仍可按既有行为被选中

#### Scenario: 右侧标题栏保持既有定位
- **WHEN** 用户将鼠标悬浮在右侧终端标题栏中具有别名的终端名称上
- **THEN** 系统继续使用该标题栏既有的提示定位行为，不应用任务树专用的右侧定位策略
