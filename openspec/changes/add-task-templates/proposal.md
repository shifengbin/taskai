## Why

任务目前只能保存固定的标题、描述、颜色、附加信息和生命周期命令链。不同类型的工作需要补充不同的结构化任务数据，且外部扩展与生命周期命令无法稳定获取这些数据。

## What Changes

- 在设置中新增任务模板管理，支持维护多个具名模板并选择一个当前使用模板。
- 任务模板字段支持键、显示名称、字符串或布尔类型、必填标记、默认值和环境变量注入标记。
- 新建和编辑任务时，按当前模板在任务描述和任务颜色之间展示字段；任务保存字段值并保留已不再使用的历史值。
- 在任务 HTTP 列表、任务 HTTP 详情和生命周期命令链标准输入中输出当前模板可见字段的 `templateFields` 对象。
- 将标记为环境变量注入的字段传递给自定义生命周期 Shell 命令，变量名为 `TASKAI_<KEY大写>`。

## Capabilities

### New Capabilities

- `task-templates`: 定义任务模板的设置管理、任务表单渲染、字段值持久化、HTTP 与生命周期命令链输出规则。

### Modified Capabilities

- 无。

## Impact

- 影响任务、设置和存储数据模型及旧数据归一化。
- 影响 Wails 后端绑定、前端设置界面、任务编辑表单和生成的前端模型类型。
- 影响任务 HTTP 列表与详情响应，以及生命周期命令链的 JSON 标准输入和自定义 Shell 命令环境变量。
- 不新增外部依赖，不修改内置生命周期命令的执行方式。
