## 为什么

任务启动、启动后和编辑后都需要向任务工作目录提供统一的迭代与仓库清单。当前只能通过自定义 Shell 命令自行解析任务输入，无法复用内置 Git 信息及模板分支回填规则。

## 变更内容

- 新增固定内置生命周期命令“生成清单文件”，可在 `beforeStart`、`postStart` 和 `updateTask` 命令链中使用。
- 为命令提供可选的 `dir=<相对任务工作目录>` 与 `name=<文件名>` 参数；缺省时生成 `<任务工作目录>/manifest.yaml`。
- 从任务标题、描述和已选择的内置 Git 信息生成 YAML 清单；Git 信息缺失分支时回填任务模板的 `branch` 字段。
- 对不安全路径或参数、不可用任务工作目录和写入失败提供明确错误，并以原子替换方式更新已有清单。

## 能力

### 新增能力

- `manifest-file-generation`：在任务生命周期内安全生成包含迭代、描述和 Git 仓库信息的 YAML 清单文件。

### 修改能力

- 无。

## 影响

- 影响生命周期命令类型、默认系统命令、参数校验和命令链执行器。
- 影响生命周期编排界面对新固定命令的展示及中文使用说明。
- 新增 YAML 序列化依赖，并补充后端与前端测试。
