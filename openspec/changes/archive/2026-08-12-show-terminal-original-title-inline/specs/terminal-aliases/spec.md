## MODIFIED Requirements

### Requirement: 别名终端显示实际会话信息
系统 SHALL 在终端具有非空别名且未处于名称编辑状态时，根据名称所在位置展示实际会话信息。

任务树终端项 MUST 继续只显示别名，并提供恰好两行的悬浮提示：第一行固定为 `标题: <实际标题>`，其中实际标题按既有回退规则得到；第二行固定为 `命令: <启动命令>`；启动命令缺失时，第二行 MUST 在命令值位置显示明确的缺省文本。该提示 MUST 显示在对应终端项右侧并与条目保留间距，不得显示在终端项上方；提示 MUST NOT 接收鼠标事件或阻挡终端项点击。

右侧终端标题栏 MUST 将名称显示为 `别名(实际标题:启动命令)`，其中实际标题和启动命令按既有回退规则得到。标题栏名称 MUST NOT 提供鼠标悬浮提示。进入名称编辑状态时，系统 MUST 只显示既有别名输入框，不显示括号内会话详情。

没有别名的终端 MUST 保持既有名称展示，系统不得仅因本能力新增会话详情行内文本或悬浮提示。

#### Scenario: 任务树悬浮查看别名终端的实际信息
- **WHEN** 名为 `前端调试` 的终端实际标题为 `npm run dev`、启动命令为 `zsh`，用户将鼠标悬浮在任务树中的终端名称上
- **THEN** 任务树仍只显示 `前端调试`，提示按两行显示 `标题: npm run dev` 和 `命令: zsh`，且不将别名作为任一提示行

#### Scenario: 右侧标题栏直接显示实际标题和启动命令
- **WHEN** 名为 `前端调试` 的终端实际标题为 `npm run dev`、启动命令为 `zsh`，系统显示该终端的右侧标题栏
- **THEN** 标题栏显示 `前端调试(npm run dev:zsh)`，且名称没有鼠标悬浮提示或固定的 `原标题` 文字

#### Scenario: 右侧标题栏为缺失的启动命令显示缺省文本
- **WHEN** 具有别名的终端缺少启动命令信息，系统显示该终端的右侧标题栏
- **THEN** 括号内启动命令位置显示既有缺省文本 `未提供启动命令`

#### Scenario: 编辑右侧标题时隐藏会话详情
- **WHEN** 用户双击右侧标题栏中的 `前端调试(npm run dev:zsh)` 进入别名编辑状态
- **THEN** 标题栏只显示值为 `前端调试` 的别名输入框，不显示括号内会话详情或悬浮提示

#### Scenario: 启动命令缺失时保留任务树提示结构
- **WHEN** 具有别名的终端缺少启动命令信息，用户将鼠标悬浮在任务树中的终端名称上
- **THEN** 提示仍按两行显示实际名称和明确的启动命令缺省文本

#### Scenario: 任务树终端提示显示在右侧
- **WHEN** 用户将鼠标悬浮在任务树中具有别名的终端名称上
- **THEN** 提示显示在对应终端项右侧并与条目保留间距，不得出现在该终端项上方

#### Scenario: 任务树终端提示不阻挡点击
- **WHEN** 任务树中的终端悬浮提示处于显示状态，用户点击任务树中的终端项
- **THEN** 提示不接收鼠标事件，终端项仍可按既有行为被选中

#### Scenario: 无别名终端保持既有名称
- **WHEN** 终端没有非空别名
- **THEN** 任务树和右侧标题栏继续按既有规则显示实际终端名称，且不新增会话详情行内文本或别名详情提示
