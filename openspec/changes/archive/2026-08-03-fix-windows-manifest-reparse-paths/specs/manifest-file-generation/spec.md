## MODIFIED Requirements

### Requirement: 安全地创建并更新清单文件

系统 MUST 要求最终任务工作目录存在、为目录且自身不是符号链接或其他重解析点。系统 MUST 允许该目录的上级路径由操作系统通过重解析点正常解析。系统 MUST 在已验证的任务工作目录内安全创建缺失的合法 `dir` 子目录，并拒绝经过符号链接或其他重解析点、离开任务工作目录或指向目录、符号链接、其他重解析点及其他非普通文件的目标。目标为普通文件时，系统 MUST 以原子替换方式覆盖其内容，且写入失败时不得留下部分清单内容。

#### Scenario: 通过上级重解析点写入清单
- **WHEN** Windows 任务工作目录自身是普通目录，但其上级路径包含目录联接点、挂载文件夹或其他可正常解析的重解析点
- **THEN** 系统在已验证的任务工作目录内生成或更新清单文件，而不会因上级重解析点使命令失败

#### Scenario: 拒绝重解析点任务工作目录
- **WHEN** 最终任务工作目录自身是符号链接、目录联接点或其他重解析点
- **THEN** 系统使当前生命周期命令失败，且不会在该目录指向的位置写入清单文件

#### Scenario: 原子覆盖已有清单
- **WHEN** 目标路径已有普通 `manifest.yaml` 文件，且任务更新触发清单生成
- **THEN** 系统以最新任务数据完整替换该文件内容

#### Scenario: 拒绝符号链接目标
- **WHEN** 合法输出路径中的目录或目标文件是符号链接或其他重解析点
- **THEN** 系统使当前生命周期命令失败，且不会在任务工作目录之外写入文件
