## ADDED Requirements

### Requirement: 任务详情提供 Git 标签
系统 MUST 在用户选中任务且未选中终端时将任务详情组织为“项目信息”和“Git”标签。“项目信息” MUST 保留现有任务模板、额外信息、系统环境变量、生命周期输入复制、生命周期状态和工作目录的展示；“Git” MUST 承载任务工作目录中的 Git 仓库管理界面。切换到 Git 标签不得修改任务、设置或生命周期执行状态。

#### Scenario: 查看任务 Git 信息
- **WHEN** 用户选择任务且没有选择终端，并点击任务详情的“Git”标签
- **THEN** 系统展示该任务的 Git 仓库管理界面，且已有项目信息仍可通过“项目信息”标签查看

#### Scenario: 选择终端时不显示任务详情标签
- **WHEN** 用户选择某任务下的终端
- **THEN** 系统继续显示终端视图，而不在终端视图内显示任务详情的“项目信息”或“Git”标签
