## MODIFIED Requirements

### Requirement: 提供受保护的内置 Git 模板
系统 MUST 提供且持久化一个不可删除的内置 Git 模板。该模板 MUST 包含键为 `name`、显示名称为“项目名称”的固定字段，键为 `repository`、显示名称为“仓库地址”的固定字段，以及键为 `branch`、显示名称为“仓库分支”的文本动态参数。系统 MUST 拒绝删除或修改这些内置字段和参数的键或显示名称；系统 MUST 允许用户为 Git 模板新增字段和动态参数、设置固定字段默认值。内置 `branch` 参数 MUST 始终可为空，以表示远程默认分支，且系统不得允许将其配置为必填；加载历史设置时 MUST 将该参数的必填标记归一化为 `false`，不修改已有任务快照。

#### Scenario: 首次打开额外信息管理
- **WHEN** 用户在没有任何额外信息数据的新安装中打开额外信息管理
- **THEN** 系统展示内置 Git 模板及其项目名称、仓库地址和可为空的仓库分支定义

#### Scenario: 基于 Git 模板创建信息时应用默认值
- **WHEN** 用户为 Git 模板的仓库地址设置默认值后新建一条 Git 信息
- **THEN** 信息表单将仓库地址输入框初始化为该默认值，且用户可在保存信息前修改该值

#### Scenario: 修改 Git 内置字段键被拒绝
- **WHEN** 用户尝试修改 Git 模板中 `name`、`repository` 或 `branch` 的键或显示名称，或删除其中任一项
- **THEN** 系统拒绝保存并说明 Git 内置字段不可修改

#### Scenario: Git 分支保持可为空
- **WHEN** 用户创建或编辑任务时未填写内置 Git 信息的 `branch`，或加载历史中将该参数标记为必填的 Git 模板
- **THEN** 系统允许空分支并将历史必填标记归一化为可选，已有任务快照保持不变
