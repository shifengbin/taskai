## MODIFIED Requirements

### Requirement: 独立维护额外信息分类和模板
系统 MUST 在设置功能之外提供独立的“信息管理”入口。信息管理窗口 MUST 包含“额外信息管理”和“快捷输入管理”标签页，且每次打开时 MUST 默认显示“额外信息管理”。额外信息模板即用户可选择的分类，模板 MUST 保存唯一标识、非空且唯一的分类名称、一个或多个固定字段定义及零个或多个动态参数定义。固定字段定义 MUST 保存键、显示名称和默认值；动态参数定义 MUST 保存键、显示名称和必填标记。系统 MUST 允许用户基于模板创建、查看、修改和删除可复用的信息；信息 MUST 保存其模板引用和固定字段实际值。

#### Scenario: 创建自定义模板并创建信息
- **WHEN** 用户新建一个非 Git 模板，并基于该模板填写固定字段后保存信息
- **THEN** 系统保存该模板和信息，且后续创建或编辑任务时将该信息作为该模板分类下的可选项提供

#### Scenario: 新建模板自动包含名称字段
- **WHEN** 用户开始新建一个非内置模板
- **THEN** 系统预置键为 `name` 的固定字段，且用户可修改该字段的显示名称

#### Scenario: 信息使用名称字段展示
- **WHEN** 用户保存一条 `name` 字段值为“API 服务”的信息
- **THEN** 系统在信息列表、任务选择器和任务已选标签中展示“API 服务”，且不要求用户另行填写独立展示名称

#### Scenario: 模板存在信息时不可删除
- **WHEN** 用户尝试删除仍关联一条或多条信息的模板
- **THEN** 系统拒绝删除并提示先删除或迁移关联信息，且不修改任何已有任务快照

#### Scenario: 删除信息不改变任务快照
- **WHEN** 用户删除已经被一个或多个任务选用的信息
- **THEN** 系统从可选信息中移除该信息，且不修改任何已有任务保存的附加信息

#### Scenario: 管理入口不属于设置
- **WHEN** 用户查看顶部工具栏
- **THEN** 系统在设置按钮旁展示“信息管理”入口，且不在设置弹窗中提供额外信息或快捷输入管理标签

#### Scenario: 默认打开额外信息管理
- **WHEN** 用户打开信息管理窗口
- **THEN** 系统默认显示“额外信息管理”标签页及现有模板和信息管理内容
