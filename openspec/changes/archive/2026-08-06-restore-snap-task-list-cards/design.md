## Context

`design-preview/index.html` 的第 29 组 `.d-snap` 是当前工作台的视觉参考。该参考以 2px、3px、4px 的共享硬投影区分控件、任务卡片和覆盖层；任务卡片与终端子项还各自具有完整的描边、错位投影和悬停抬起。

当前 `TaskTree` 为顶层任务项提供 4px 左边框和约 4% 的任务色背景，但没有完整外描边或与参考相符的悬停投影。终端子项使用低透明描边。`style.css` 的任务启动反馈直接动画 `box-shadow`，会与卡片的硬投影争夺同一个属性。此前未提交的阴影令牌变更将共享偏移收紧为 1px、2px、3px。

## Goals / Non-Goals

**Goals:**

- 恢复 Snap 共享硬投影的 2px、3px、4px 层级。
- 让顶层任务项和终端子项与 `.d-snap` 的卡片层级、间距和悬停反馈一致。
- 用钴蓝选择态与任务色内嵌条同时表达选择和任务归属。
- 保留任务色常态背景、悬停操作、拖拽、生命周期状态、键盘操作和减少动态效果行为。

**Non-Goals:**

- 不重做任务树标题、状态标签页、详情面板、菜单或全局排版。
- 不修改任务颜色数据、终端会话、任务状态迁移或交互回调。
- 不引入新的主题色、动画库、图像资源或装饰性状态尾标。

## Decisions

### 1. 恢复共享阴影，并为列表卡片选用其对应层级

将 `shadow-snap-sm`、`shadow-snap`、`shadow-snap-lg` 恢复为 2px、3px、4px 的零模糊偏移。图标按钮继续使用小档，顶层任务项使用中档并在 hover 时使用大档，终端子项使用小档并在 hover 时使用中档。这样与 `.d-snap` 的 2px 控件、3px 任务卡片和 4px 悬停卡片相符。

仅在任务树中覆盖阴影的备选方案会使操作按钮与覆盖层继续弱于参考；只恢复令牌但不改卡片结构则无法解决列表层级不足，因此不采用。

### 2. 以完整外框和内阴影色条构建任务卡片

任务行改为 2.5px Snap 描边、9px 圆角、7px 横向外间距、3px 默认硬投影和 5px 内嵌任务色条。色条作为与外部硬投影并列的 `inset 5px 0 0 var(--task-color)` 内阴影渲染，与 `.d-snap .task-row` 保持一致；外框不再依赖左边框，因此可在选中时稳定改为钴蓝。常态任务色背景仍使用约 4% 不透明度，以保留已有的任务归属要求。

直接把任务色作为外框的备选方案会使选择态难以与任务色区分；将色条继续作为左边框则无法同时获得参考中的完整外描边，因此不采用。

### 3. 将选择、开始反馈和悬停分离为独立层级

已选中的任务行使用钴蓝描边和同色硬投影，任务色内嵌条保持可见。悬停只改变 `transform` 和硬投影，减少动态效果时保持静态。开始任务反馈使用独立伪元素的短暂描边动画，不再动画 `box-shadow`，确保卡片的硬投影在反馈期间仍可见。

用同色任务背景表示选择的备选方案不符合 Snap 的主要操作色语义；继续动画 `box-shadow` 会覆盖卡片层级，因此不采用。

### 4. 将终端子项视为较低层级的 Snap 卡片

终端子项使用 2px 描边、7px 圆角、次级表面、2px 默认硬投影和 3px 悬停硬投影；选中时使用钴蓝描边和投影。关闭按钮的既有悬停显示容器、状态点和选择回调保持不变。

只提高终端边框透明度的备选方案无法产生与顶层任务一致的卡片层级，因此不采用。

### 5. 固定两行任务正文，避免列表高度跳动

顶层任务卡片固定为 60px 高，任务名称和描述分别占第一、第二行。名称使用参考中的 Hanken Grotesk 800、13.5px，描述使用 Plus Jakarta Sans 500、11.5px，并保持 1px 间距；两行均保持单行截断。描述为空时渲染“暂无描述”，并在悬停提示中使用相同文案。这样可在保留操作区域和任务色条的同时，让任务列表拥有稳定、可扫描的节奏。

## Risks / Trade-offs

- [列表密度降低] → 仅按参考增加 7px/4px 卡片间距，保留当前紧凑的标题、描述和操作尺寸。
- [粗描边与长标题竞争空间] → 维持现有 `min-w-0`、截断和操作容器的固定占位。
- [固定高度压缩长文本] → 标题和描述都单行截断，完整描述仍可通过悬停提示查看。
- [色条与参考样式不一致] → 色条使用与参考相同的内阴影，而非独立伪元素。
- [选中、拖拽或反馈难以区分] → 钴蓝选择框、任务色反馈框和既有拖拽轮廓采用不同层与时机。

## Migration Plan

无需数据迁移。部署后所有已有任务和终端立即使用新的视觉外壳；回退时恢复原有阴影令牌与任务树样式，不影响任务或终端记录。
