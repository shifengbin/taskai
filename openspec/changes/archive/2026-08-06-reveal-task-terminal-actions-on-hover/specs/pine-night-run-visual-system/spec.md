## ADDED Requirements

### Requirement: 任务与终端的上下文操作可见性
系统 SHALL 将任务行的展开、执行、结束、重试和任务操作按钮，以及终端子项和右侧终端标题栏的关闭按钮，作为上下文操作控件。支持悬停的输入环境中，这些控件 MUST 在默认状态下视觉隐藏，并在所属容器悬停、容器内控件获得键盘焦点或对应任务操作菜单打开时显示。视觉隐藏不得移除控件的 DOM、语义或固定布局占位。

#### Scenario: 默认查看任务和终端
- **WHEN** 用户在支持悬停的设备上查看未悬停且没有键盘焦点的任务行、终端子项或终端标题栏
- **THEN** 其上下文操作控件视觉隐藏，任务标题、描述、状态点、生命周期进度/错误提示和批量选择复选框保持可见，且标题与行布局不得因操作控件隐藏而重排

#### Scenario: 悬停任务或终端容器
- **WHEN** 用户将鼠标移入任务行、终端子项或右侧终端标题栏
- **THEN** 该容器的上下文操作控件显示并可按原有规则执行，其他容器的控件不因本次悬停而显示

#### Scenario: 使用键盘聚焦上下文操作
- **WHEN** 用户通过键盘将焦点移入任务行、终端子项或终端标题栏中的上下文操作控件
- **THEN** 所属容器的上下文操作控件显示，当前焦点与既有焦点环保持可见，且按钮的 ARIA 标签、禁用状态和触发结果不变

#### Scenario: 在无悬停设备上操作
- **WHEN** 用户使用不支持悬停的输入设备查看任务行、终端子项或终端标题栏
- **THEN** 上下文操作控件保持可见并可直接操作，不得要求用户执行不可用的悬停手势

#### Scenario: 打开任务操作菜单
- **WHEN** 用户通过任务操作按钮打开某个任务的操作菜单
- **THEN** 菜单保持既有定位、内容和关闭规则，且该任务行的上下文操作控件在菜单打开期间保持显示

## MODIFIED Requirements

### Requirement: 工作台与任务树保持跑道式层级
系统 SHALL 在不改变现有工作台布局和操作位置的前提下，使用 2–2.5px 实色描边、`Npx Npx 0` 错位硬投影、6–9px 圆角和 hover 抬起位移表现快门波普的新粗野层级。顶栏、任务树、状态标签、任务行、终端子项、详情区、空状态、分隔条及拖拽反馈必须使用同一视觉语言。每个未选中的任务行 MUST 以其用户定义的任务颜色渲染约 4% 不透明度的极浅背景，并继续以该颜色的左边框作为主要颜色标记。任务和终端的上下文操作控件显示时，必须继承同一视觉语言并保持清晰可辨。

#### Scenario: 查看未选中的任务项
- **WHEN** 用户在任一亮色或暗色模式中查看未选中的任务项
- **THEN** 任务项必须显示与左侧任务色条相同色相的极浅背景（约为该任务色的 4% 不透明度）、粗描边与硬投影卡片，且标题、描述、状态提示和用户定义的任务颜色保持清晰可辨；上下文操作控件按既有上下文操作可见性规则显示

#### Scenario: 选择任务
- **WHEN** 用户在任务树中选择一个任务
- **THEN** 选中任务必须获得可见的快门波普选择态（钴蓝描边或填充），同时任务标题、描述、状态提示和用户定义的任务颜色仍保持可辨；上下文操作控件显示时必须保持可辨，且不得显示易被误解为新建任务状态的装饰性尾标

#### Scenario: 拖拽调整任务顺序
- **WHEN** 用户拖拽任务并悬停在有效插入位置
- **THEN** 插入指示器与拖拽预览必须使用快门波普主色或描边清晰标示目标，且不改变原有拖拽判定或排序行为

#### Scenario: 未选择任务或终端
- **WHEN** 用户未选择任务和终端
- **THEN** 详情区必须显示与快门波普主题一致、易读的引导空状态，且创建任务入口保持可见

### Requirement: 终端与实时状态的视觉连续性
系统 SHALL 让终端标题栏、终端背景、前景文字、光标、选择区和实时状态点适配快门波普视觉系统。终端背景必须叠加半色网点底纹，并通过 xterm 主题注入提示符珊瑚、成功信息钴蓝、关键字与光标紫罗兰的配色；无论工作台处于亮色或暗色模式，亮色模式终端背景必须使用快门波普浅次表面 + 半色网点，暗色模式必须使用比亮色更深的夜色次表面 + 半色网点；若亮色模式下输出可读性不足，亮色终端可回退为深色表面。终端标题栏不得出现影响终端图标或标题阅读的额外横杠装饰。终端的输入输出、尺寸调整、焦点、关闭、剪贴板和实时事件行为不得因视觉改造而变化；关闭操作的视觉可见性必须遵守上下文操作可见性规则，实时状态点始终可见。

#### Scenario: 在任意模式查看活动终端
- **WHEN** 用户在亮色或暗色模式选择一个活动终端
- **THEN** 终端必须使用高对比前景与背景、半色网点底纹和快门波普配色的高亮，且终端标题不与图标或额外横杠装饰重叠；关闭操作按上下文操作可见性规则显示，实时状态点保持可见

#### Scenario: 在暗色模式查看活动终端
- **WHEN** 用户在暗色模式选择一个活动终端
- **THEN** 终端必须使用比亮色模式更深的背景和高对比前景，并保持终端标题与实时状态点可见；关闭操作在其上下文操作可见性条件满足时必须清晰可辨

#### Scenario: 终端出现工作中或未读状态
- **WHEN** 终端实时状态为工作中或未读
- **THEN** 状态点必须使用快门波普主题一致的静态或脉冲提示（working=钴蓝、unread=琥珀、error=红、idle=muted），且其现有无障碍状态标签保持不变
