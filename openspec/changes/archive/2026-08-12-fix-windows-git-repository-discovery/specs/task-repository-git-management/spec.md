## MODIFIED Requirements

### Requirement: 发现任务工作目录中的 Git 仓库
系统 MUST 在用户查看任务详情的 Git 标签时，基于该任务保存的工作目录发现其中所有 Git 仓库。系统 MUST 识别具有 `.git` 目录的普通 Git 仓库和具有 `.git` 文件的 Git worktree，MUST 先从文件系统标记收集候选，再仅对候选执行 Git 顶层目录验证，MUST 使用相对于任务工作目录的稳定路径区分仓库，MUST 跳过 `.git` 元数据目录和符号链接目录，且 MUST 不访问任务工作目录之外的路径。系统 MUST 使用持久化的 Git 最大扫描深度限制目录遍历；任务工作目录为第 1 层，直属子目录为第 2 层。默认最大深度 MUST 为 3，设置值 MUST 限制在 1–10；系统升级时 MUST 将仍处于旧默认深度 2 的旧版本设置一次性迁移到 3，迁移完成后 MUST 保留用户后续显式保存的有效深度。任务没有保存工作目录，或保存的工作目录尚未实际创建时，系统 MUST 不显示 Git 标签；任务工作目录存在但未发现仓库时，系统 MUST 展示明确空态。

#### Scenario: 列出多个普通仓库和 worktree
- **WHEN** 用户打开一个任务的 Git 标签，且扫描范围内包含两个具有 `.git` 目录的普通仓库和一个具有 `.git` 文件的 Git worktree
- **THEN** 系统只对三个候选执行 Git 顶层目录验证，列出验证通过的仓库及其相对路径和当前分支，且不将 `.git` 元数据目录作为仓库列出

#### Scenario: 默认深度发现默认生命周期仓库
- **WHEN** Git 最大扫描深度使用默认值 3，默认生命周期将仓库克隆到 `<任务工作目录>/workspaces/<项目>`
- **THEN** 系统进入 `workspaces` 并列出其中位于第 3 层的项目仓库

#### Scenario: 显式较小深度限制扫描
- **WHEN** 用户在迁移完成后将 Git 最大扫描深度显式保存为 2，仓库位于 `<任务工作目录>/workspaces/<项目>`
- **THEN** 系统不进入第 3 层项目目录，且后续加载设置时保持深度 2

#### Scenario: 迁移旧默认扫描深度
- **WHEN** 系统加载迁移版本较旧且 Git 最大扫描深度为旧默认值 2 的设置
- **THEN** 系统将最大扫描深度一次性迁移并持久化为 3

#### Scenario: 保留旧版非默认扫描深度
- **WHEN** 系统加载迁移版本较旧且 Git 最大扫描深度为 1 或 3–10 的设置
- **THEN** 系统完成版本迁移但保持该扫描深度不变

#### Scenario: 普通目录不启动 Git 进程
- **WHEN** 扫描范围包含多个没有 `.git` 目录或文件的普通目录
- **THEN** 系统遍历这些目录以查找更深层候选，但不以这些普通目录作为工作目录启动 Git 验证进程

#### Scenario: 任务没有工作目录
- **WHEN** 用户查看没有保存工作目录，或虽已保存预期路径但工作目录尚未创建的任务详情
- **THEN** 系统不显示 Git 标签，也不请求 Git 仓库列表

#### Scenario: 从 Git 标签切换到没有工作目录的任务
- **WHEN** 用户正在查看某任务的 Git 标签，随后切换到没有保存工作目录或工作目录尚未创建的任务
- **THEN** 系统选中并展示新任务的“项目信息”，且不保留不可见的 Git 标签状态

#### Scenario: 拒绝工作目录外的仓库请求
- **WHEN** 前端请求读取或操作不在该任务工作目录内的仓库路径
- **THEN** 后端拒绝请求且不启动 Git 进程

## ADDED Requirements

### Requirement: 仓库发现和状态读取相互隔离
系统 MUST 独立验证和读取扫描范围内的每个仓库候选。候选无法验证为任务工作目录内的 Git 顶层目录时，系统 MUST 跳过该候选；候选验证成功但基础状态读取失败时，系统 MUST 返回包含仓库相对路径和可读错误的不可操作状态，并继续读取和返回其他有效仓库。单个候选或仓库失败 MUST NOT 使整个仓库列表请求失败。

#### Scenario: 无效 Git 标记不影响有效仓库
- **WHEN** 扫描范围内同时存在一个伪造或损坏的 `.git` 候选和一个有效仓库
- **THEN** 系统跳过无效候选并正常展示有效仓库

#### Scenario: 单个仓库状态读取失败
- **WHEN** 两个候选均通过 Git 顶层目录验证，但其中一个仓库的工作区状态或远程列表无法读取
- **THEN** 系统为失败仓库展示相对路径和错误提示且不提供操作按钮，同时正常展示另一个仓库的完整状态和操作
