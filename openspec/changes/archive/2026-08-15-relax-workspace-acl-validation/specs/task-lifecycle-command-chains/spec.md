## MODIFIED Requirements

### Requirement: 系统内置目录命令
系统 SHALL 将创建和删除任务工作目录作为可放入任意钩子链的系统内置命令。两个命令 MUST 仅操作当前任务 ID 在任务工作区根目录下的直接子目录，并 MUST 拒绝路径穿越或指向工作区外的符号链接。工作区根目录和所有权元数据目录 MUST 仅按目录形状与软件访问能力校验：系统 MUST 要求它们存在、是普通目录且不是符号链接，MUST NOT 因目录所有者、访问控制列表或权限位允许其他用户或组账户访问而拒绝。创建命令遇到目录已存在时 MUST 成功复用，删除命令遇到目录不存在时 MUST 成功结束。

#### Scenario: beforeStart 链创建任务目录
- **WHEN** `beforeStart` 链首先执行创建任务工作目录命令
- **THEN** 系统创建或复用任务专属目录，并让后续命令在该目录执行

#### Scenario: 根目录继承宽松访问控制条目
- **WHEN** 工作区根目录的访问控制列表或权限位包含其他用户、组账户或已删除账户残留 SID 的写入权限（例如沙箱工具在父目录添加后继承的 ACE）
- **THEN** 创建任务工作目录命令正常创建或复用任务目录并成功，不因访问控制条目拒绝

#### Scenario: 元数据目录带宽松权限
- **WHEN** 所有权元数据目录已存在，且其访问控制列表或权限位允许其他用户访问
- **THEN** 系统直接复用该目录继续所有权令牌操作，不修改其权限，也不拒绝使用

#### Scenario: 根目录不是普通目录
- **WHEN** 工作区根目录不存在、是普通文件或是指向工作区外的符号链接
- **THEN** 创建任务工作目录命令失败并阻止任务进入执行中

#### Scenario: 创建命令排在前序命令之后
- **WHEN** `beforeStart` 链在创建目录命令前执行需要任务目录的外部命令且目录不存在
- **THEN** 前序命令失败，任务保持未执行且系统不隐式创建目录

#### Scenario: postEnd 在工作区根目录运行
- **WHEN** 系统执行 `postEnd` 链中的任意命令
- **THEN** 命令工作目录为任务工作区根目录

#### Scenario: 重试重复执行目录命令
- **WHEN** 用户从链首重试已经创建过目录或已经删除过目录的链
- **THEN** 对应内置命令以成功复用或成功结束的方式继续执行
