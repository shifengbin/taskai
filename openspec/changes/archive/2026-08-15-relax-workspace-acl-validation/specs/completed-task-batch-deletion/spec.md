## MODIFIED Requirements

### Requirement: 记录删除不影响文件与生命周期操作
系统 MUST 将普通未执行任务和已完成任务的批量删除限定为任务记录操作。对于开始前命令链失败的未执行任务，系统 MUST 仅在持久化执行记录的随机令牌能同时匹配 TaskAI 侧车凭据、目录自身所有权标记及当前目录文件系统身份时，使用该记录的路径快照安全删除任务目录；侧车凭据所在的元数据目录 MUST NOT 因其所有者、访问控制列表或权限位允许其他用户访问而影响删除校验。没有创建命令、创建命令未执行或失败、创建命令复用已有目录、同名目录后来被替换或删除后同名重建时 MUST NOT 删除该目录。确认界面 MUST 明确说明任务记录删除不可撤销，以及启动失败任务的条件目录清理行为。批量删除 MUST NOT 调度、取消或重试生命周期命令链。

#### Scenario: 删除具有保留工作目录的普通任务
- **WHEN** 用户确认删除一项工作目录仍存在的符合资格未执行或已完成任务
- **THEN** 系统只移除任务记录，工作目录及其内容保持不变，且不执行任何生命周期命令

#### Scenario: 删除实际创建了工作目录的启动失败任务
- **WHEN** 用户确认删除一项开始前命令链失败的未执行任务，且执行记录确认 TaskAI 本次启动过程新建了对应任务目录
- **THEN** 系统先使用记录的根目录、任务目录和任务 ID 通过安全边界校验删除该目录，再删除任务记录，且不执行任何生命周期命令

#### Scenario: 删除未创建工作目录的启动失败任务
- **WHEN** 用户确认删除一项开始前命令链失败的未执行任务，且命令链没有创建目录命令、未执行到创建命令、创建命令失败或复用了已有目录
- **THEN** 系统不调用目录删除，只移除任务记录，任何已有目录及其内容保持不变

#### Scenario: 启动失败任务的目录已经不存在
- **WHEN** 执行记录确认目录由 TaskAI 新建，但用户删除任务时该目录已经不存在
- **THEN** 系统将目录清理视为成功并继续删除任务记录

#### Scenario: 启动失败任务的目录清理失败
- **WHEN** 安全路径校验、符号链接检查或文件系统操作无法删除 TaskAI 新建的任务目录
- **THEN** 系统拒绝删除请求并保留全部任务记录、失败执行记录和重试能力

#### Scenario: TaskAI 创建的同名目录已被替换
- **WHEN** 执行记录显示 TaskAI 创建过任务目录，但删除时同一路径目录的文件系统身份不再匹配所有权凭据
- **THEN** 系统不得删除替换后的目录，拒绝删除请求并保留任务记录与失败信息

#### Scenario: TaskAI 创建的目录删除后被同名重建
- **WHEN** TaskAI 创建的原任务目录已被删除，随后同一路径创建了新目录，即使文件系统复用了原目录身份
- **THEN** 系统因新目录缺少匹配的目录自身所有权标记而不得删除它，并保留任务记录与失败信息

#### Scenario: 宽松权限元数据目录不影响删除校验
- **WHEN** 侧车凭据所在的元数据目录带宽松访问控制（例如其他组账户可写入），且令牌、目录标记和文件系统身份全部匹配
- **THEN** 系统正常执行条件目录清理，不因元数据目录权限拒绝删除

#### Scenario: 清理期间并发新增任务
- **WHEN** 启动失败任务的目录清理期间创建了其他任务
- **THEN** 系统在清理后基于最新任务快照只移除目标任务，并保留并发新增任务
