## ADDED Requirements

### Requirement: 任务描述悬浮提示保留文本结构

系统 SHALL 在用户悬浮任务项时显示完整任务描述，并保留保存内容中的换行和连续空白。提示 SHALL 继续在可用面板宽度内自动折行，且不得改变任务项的固定两行布局、提示定位或空描述回退文案。

#### Scenario: 悬浮多行任务描述

- **WHEN** 用户悬浮描述包含多个换行或缩进的任务项
- **THEN** 悬浮提示必须按原始换行和连续空白显示完整描述，不得将换行折叠为空格

#### Scenario: 悬浮超长描述行

- **WHEN** 用户悬浮包含超出提示可用宽度的单行文本的任务项
- **THEN** 提示必须在面板内自动折行，且不得超出既有的最大宽度约束

#### Scenario: 悬浮空描述任务

- **WHEN** 用户悬浮描述为空的任务项
- **THEN** 提示必须继续显示“暂无描述”作为回退文案
