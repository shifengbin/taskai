## Context

任务项正文固定为两行，描述行使用单行截断。鼠标进入任务项时，`TaskTree` 会通过 portal 显示完整描述；该覆盖层没有设置保留空白的样式，因此浏览器会将换行渲染为空格。

## Goals / Non-Goals

**Goals:**

- 在悬浮描述提示中按任务保存时的结构显示多行内容。
- 保持现有提示的定位、最大宽度、自动折行、空描述回退和不透明覆盖层外观。
- 用组件回归测试锁定多行描述的呈现样式。

**Non-Goals:**

- 不改变任务描述的保存、编辑、传输或详情页渲染。
- 不增加 Markdown 解析、富文本、滚动逻辑或新的提示组件。
- 不改变任务项 60px 的两行布局。

## Decisions

- 在现有提示容器上使用 Tailwind 的 `whitespace-pre-wrap`。该样式保留换行、连续空格和缩进，同时允许超长文本按现有 `break-words` 与最大宽度折行。
- 不使用 `whitespace-pre-line`，因为它会折叠连续空白，不能完整呈现原始内容。
- 不改用 `<pre>` 元素，避免默认等宽字体和预格式化块的尺寸行为改变既有提示外观。

## Risks / Trade-offs

- [包含大量空白的描述占用更多提示高度] → 保留现有最大宽度与自动折行，提示仅在悬浮时显示。
- [仅断言文字内容无法检测浏览器的空白渲染规则] → 回归测试同时断言多行文本和 `whitespace-pre-wrap` 类。
- [空描述不含原始文本] → 保持既有“暂无描述”回退，不对该固定文案应用特殊数据处理。

## Migration Plan

无需迁移。该改动只影响前端显示，已有任务数据会在下一次悬浮时自动以保留换行的方式呈现；回退代码即可恢复原显示方式。
