## ADDED Requirements

### Requirement: 任务详情展示额外信息快照

系统 MUST 在用户选中任务且未选中终端时的任务详情中展示该任务保存的额外信息。系统 MUST 按 `catalogue` 分组，并在每条信息中展示保存时的展示名称、固定字段显示名称和值，以及动态参数显示名称和值。复选框动态参数 MUST 以可读的布尔值展示；没有额外信息时系统 MUST 提供明确的空态提示。

#### Scenario: 展示多个分类的额外信息
- **WHEN** 用户选中一个保存了 Git 信息和部署信息的任务
- **THEN** 任务详情按两个分类展示各自的信息名称、固定字段及动态参数，且不依赖信息或模板当前是否仍存在

#### Scenario: 展示复选框参数
- **WHEN** 用户选中一个包含值为 `true` 的复选框动态参数的任务
- **THEN** 任务详情将该参数展示为可读的肯定布尔值，而不是原始字符串 `true`

#### Scenario: 未保存额外信息
- **WHEN** 用户选中一个未附加任何信息的任务
- **THEN** 任务详情显示额外信息为空的提示

### Requirement: 任务详情仅展示系统环境变量

系统 MUST 在任务详情中提供“系统环境变量”说明区，并且只展示应用稳定注入的 `TASKAI_TASK_ID`、`TASKAI_TERMINAL_ID` 及条件性注入的 `TASKAI_STATUS_API`。说明区 MUST 标明每个变量的适用范围：任务 ID 用于任务关联的自定义命令和脚本，终端 ID 用于新建终端，状态 API 仅在 HTTP 状态管理模式下用于新建终端。系统 MUST 不在该区展示模板字段派生的环境变量或 Shell 运行器内部变量。

#### Scenario: 默认状态下展示系统变量范围
- **WHEN** 用户查看任意任务的详情且未启用 HTTP 状态管理
- **THEN** 系统展示 `TASKAI_TASK_ID` 和 `TASKAI_TERMINAL_ID` 的适用范围，并说明 `TASKAI_STATUS_API` 仅在 HTTP 状态管理模式下注入

#### Scenario: 不展示模板派生变量
- **WHEN** 当前任务模板将字段 `environment` 标记为生命周期环境变量注入
- **THEN** 任务详情的系统环境变量区不展示 `TASKAI_ENVIRONMENT`

### Requirement: 任务详情展示当前模板和模板环境变量

系统 MUST 在任务详情中提供独立于系统环境变量区的“任务模板”区。系统 MUST 使用当前启用模板的名称、字段定义和任务保存的字段值（缺失值使用模板默认值）展示每个模板字段的显示名、字段键及当前值。字段启用 `injectEnvironment` 时，系统 MUST 展示与现有注入规则一致的 `TASKAI_<字段键大写>=<序列化值>`，并注明其仅传入自定义生命周期 Shell 命令；未启用时系统 MUST 明确显示该字段不生成环境变量。未启用任务模板时系统 MUST 提供明确空态。模板字段环境变量 MUST 不混入系统环境变量区。

#### Scenario: 展示字符串和布尔模板变量
- **WHEN** 当前启用模板包含值为 `production` 的字符串字段 `environment` 和值为 `true` 的布尔字段 `deploy`，且两个字段均启用环境变量注入
- **THEN** 任务详情展示模板名称、两个字段的当前值，以及 `TASKAI_ENVIRONMENT=production` 和 `TASKAI_DEPLOY=true`，并标明它们仅对自定义生命周期 Shell 命令可用

#### Scenario: 字段未启用环境变量注入
- **WHEN** 当前启用模板的字段 `note` 未启用环境变量注入
- **THEN** 任务详情展示该字段的当前值，并明确显示“不生成环境变量”

#### Scenario: 未启用模板
- **WHEN** 用户查看任意任务详情且未启用任务模板
- **THEN** 系统显示未启用任务模板的空态，且系统环境变量区保持可见

### Requirement: 复制当前生命周期命令链输入

系统 MUST 在任务详情中提供一键复制当前生命周期命令链首段输入 JSON 的操作。复制内容 MUST 在用户触发时由后端使用与生命周期执行相同的输入构造规则生成，并包含当前任务详情结构、已选额外信息、当前活动终端及当前可见模板字段；本机 HTTP 服务正在监听时 MUST 包含顶层 `baseURL`，未监听时 MUST 不包含该字段。系统 MUST 将未格式化的原始 JSON 文本写入剪贴板，并在成功或失败时给出反馈；复制不得修改任务、设置或命令链。

#### Scenario: 服务可用时复制完整当前快照
- **WHEN** 用户在本机 HTTP 服务正在监听时点击复制，且任务包含额外信息与活动终端
- **THEN** 剪贴板获得与该时刻首段自定义命令输入同结构的 JSON，其中包含额外信息、终端、当前模板字段和 `baseURL`

#### Scenario: 服务未运行时不复制 baseURL
- **WHEN** 用户在本机 HTTP 服务未监听时点击复制
- **THEN** 剪贴板 JSON 不包含 `baseURL`，并显示复制成功反馈

#### Scenario: 复制任务不存在时失败
- **WHEN** 任务在用户触发复制前已被删除
- **THEN** 系统显示错误反馈且不写入剪贴板
