## 为什么

当前点击任务后只显示标题、描述、生命周期错误和部分工作目录信息。任务已保存的额外信息、当前启用模板的字段及其环境变量注入状态、应用注入的系统环境变量，以及自定义生命周期命令实际接收的首段输入都难以直接查看，用户调试或编写命令链时只能转而查阅代码和 README。

命令管理页也缺少对参数追加、标准输入输出传递和重试语义的集中说明，容易使命令链配置与实际执行行为不一致。

## 变更内容

- 扩展任务详情，按分类展示任务保存的额外信息及其字段、动态参数和空态。
- 在任务详情中分区展示当前启用模板的字段和值，以及每个字段是否会生成仅供自定义生命周期 Shell 命令使用的 `TASKAI_<字段>` 环境变量；系统环境变量区仍只展示应用稳定注入的变量。
- 提供只读的“当前命令链输入”预览与一键复制能力，复制内容与自定义生命周期命令首段标准输入使用同一后端构造规则，并反映当前额外信息、活动终端和可用的 `baseURL`。
- 在“生命周期编排”的命令管理页提供中文“命令链扩展规则”帮助，说明钩子范围、参数合并、标准输入输出、环境变量、内置命令和失败重试规则。

## 能力

### 新增能力

- `task-detail-command-context`：在任务详情中提供额外信息、系统环境变量和可复制的命令链首段输入快照。
- `lifecycle-command-chain-guidance`：在生命周期命令管理页面提供命令链扩展和传递规则的应用内帮助。

### 修改能力

- 无。

## 影响

- 前端：`frontend/src/App.tsx` 的任务详情、生命周期编排区域及其交互测试；复用已有模板字段解析逻辑和 Wails 剪贴板运行时能力。
- 后端：`app.go` 增加只读的命令链输入预览绑定，并抽取生命周期执行与预览共用的输入构造路径；更新 Wails 生成绑定。
- 测试：补充 Go 侧输入快照一致性测试和前端详情、复制、帮助文档测试。
- 文档：新增的应用内帮助以中文说明现有命令链规则；不改变 HTTP 接口和持久化数据格式。
