## MODIFIED Requirements

### Requirement: 稳定展示分类模板并按名称搜索信息

系统 MUST 将分类模板定义区与信息列表区分开显示。分类模板定义区 MUST 支持整体折叠；折叠后模板定义内容 MUST 不可见且不得继续占据信息列表的布局高度。模板多于一条时布局 MUST 在窄宽度下换行而不遮挡或挤压操作控件。信息列表 MUST 按模板保留全部分类分组；名称模糊搜索 MUST 只筛选信息行，不得隐藏分类模板定义或分类分组标题。系统 MUST 在搜索命中时自动展开对应信息分组，并默认展开 Git 信息分组。额外信息管理主体 MUST 在窗口高度不足时提供真实可操作的纵向滚动，使全部模板行、信息分组和搜索结果均可访问；底部关闭操作 MUST 保持可见且可操作。

#### Scenario: 搜索信息不隐藏分类

- **WHEN** 用户在额外信息管理中搜索“缺陷”，且 Git 分类没有匹配信息
- **THEN** Git 模板定义和 Git 信息分类标题仍显示，缺陷分类自动展开并仅显示名称匹配的信息

#### Scenario: 折叠分类模板定义

- **WHEN** 用户点击“分类模板”面板标题
- **THEN** 系统折叠或展开整块模板定义列表；折叠后模板行不可见且不占用其余信息区域的布局高度，不影响下方信息分组的展开状态或搜索条件

#### Scenario: 低高度窗口展示全部模板

- **WHEN** 分类模板面板展开且窗口高度不足以同时容纳模板列表和信息列表
- **THEN** 模板列表中的每个模板均按顺序展示，信息区域不得覆盖模板行，用户可通过管理弹窗主体的纵向滚动查看其余内容

#### Scenario: 底部操作在滚动后仍可用

- **WHEN** 管理弹窗主体内容超过可视高度且用户滚动到主体末尾
- **THEN** 用户仍能看到并点击“关闭”操作，不需要依赖页面外层滚动才能退出管理弹窗
