## 为什么

任务目前只能保存标题、描述和颜色，无法记录仓库、分支等与具体任务关联的业务上下文。需要提供可复用的附加信息模板，并在创建或编辑任务时保存所选信息及其动态参数，使自动化工具可从任务详情接口读取结构化上下文。

## 变更内容

- 新增独立的“额外信息管理”功能入口，用于维护分类、可选信息模板及其参数定义，不纳入应用设置。
- 分类可独立创建和删除；仅当分类下不再有任何信息模板时才允许删除。模板配置时只能从已创建的分类中选择。
- 支持为模板配置信息展示名称、多个固定字段（键、字段显示名称、静态值）及多个带必填标记的动态参数。
- 创建和编辑任务时以分类选择器筛选并勾选模板，切换分类时保留跨分类已选项；已选项集中展示并可单项移除。任务保存完整信息快照，后续修改或删除模板、分类不影响已有任务。
- 扩展任务详情 HTTP 接口，按 `catalogue` 聚合返回任务附加信息，并将多个固定字段和参数键值平铺为 JSON 对象。

## 能力

### 新增能力

- `task-extra-info`: 管理可复用的额外信息模板，在任务中保存其快照，并通过任务详情接口提供按目录聚合的结构化附加信息。

### 修改能力

- 无。

## 影响

- 后端：任务领域模型、生命周期服务、仓储持久化、Wails 绑定及本机 HTTP 任务详情映射。
- 前端：顶部工具栏、分类与额外信息管理弹窗、任务创建/编辑弹窗、类型定义和 API 调用。
- 数据：`tasks.json` 增加分类集合、额外信息模板和每个任务的附加信息快照；旧单键值模板保持兼容并迁移为一个固定字段。
- 文档与测试：更新 HTTP 接口说明，覆盖模板管理、任务编辑、持久化和详情响应。
