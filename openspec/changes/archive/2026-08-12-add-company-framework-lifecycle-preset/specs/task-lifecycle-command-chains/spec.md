## ADDED Requirements

### Requirement: 新安装默认提供公司框架预设
系统 SHALL 在没有持久化数据的新安装中同时创建“默认预设”和“公司框架”两个生命周期命令链预设，并 MUST 将“公司框架”设为默认预设。“公司框架” MUST 使用稳定 ID，其 `beforeStart` MUST 选择 `iterations-ai`，`postEnd` MUST 选择“删除任务工作目录”，`updateTask` MUST 选择稳定仓库更新链，`postStart` 与 `beforeEnd` MUST 保持为空。“默认预设” MUST 继续保留原有创建和删除任务工作目录的映射。两个预设 MUST 继续作为普通预设参与现有编辑、复制、删除和引用校验，任务 MUST 只保存展开后的链映射。

#### Scenario: 新安装生成两个预设并默认选择公司框架
- **WHEN** 用户首次启动且应用数据目录中不存在持久化数据文件
- **THEN** 设置包含“默认预设”和“公司框架”，默认预设 ID 指向“公司框架”，且公司框架仅在开始前、结束后和任务更新三个钩子保存指定命令链

#### Scenario: 新任务自动使用公司框架
- **WHEN** 新安装用户打开新建任务表单
- **THEN** 表单选择“公司框架”，开始前显示 `iterations-ai`，结束后显示“删除任务工作目录”，任务更新显示“更新框架仓库”，开始后和结束前显示不执行命令链

#### Scenario: 新任务保存展开后的公司框架映射
- **WHEN** 新安装用户保持默认选择并创建未执行任务，随后重新编辑该任务
- **THEN** 任务保存并重新显示公司框架对应的三个链 ID，而不保存或依赖公司框架预设 ID

#### Scenario: 已有设置不注入公司框架
- **WHEN** 应用加载已经存在的持久化设置，无论其中是否已有生命周期预设或默认预设选择
- **THEN** 系统不得因本次变更新增“公司框架”、切换默认预设或改写已有预设内容

#### Scenario: 公司框架仍可由用户管理
- **WHEN** 新安装用户编辑、复制或删除“公司框架”预设
- **THEN** 系统使用现有普通预设规则保存操作，删除当前默认的公司框架时清空默认预设 ID，且不修改已创建任务的链映射
