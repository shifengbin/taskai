## ADDED Requirements

### Requirement: 空链任务的交互操作目录

系统 SHALL 为执行中且未选择任何生命周期命令链的任务，将当前用户的 Home 目录用作任务级交互操作的工作目录。该规则适用于新增 Shell 终端、新增命令终端、直接任务命令、任务菜单自定义命令及其前置和后置脚本，以及“打开任务文件夹”。系统 MUST 在启动操作前确认 Home 路径可用且为目录；无法获取、访问或确认该目录时，系统 MUST 拒绝该操作并报告错误。系统 MUST NOT 为此类任务隐式创建任务工作目录，也 MUST NOT 将 Home 目录写入任务的工作区根目录或工作目录快照。

#### Scenario: 空链任务新增终端
- **WHEN** 执行中任务的五个生命周期钩子均未选择命令链，用户新增 Shell 终端或命令终端
- **THEN** 系统在当前用户的 Home 目录启动对应终端，且不创建任务工作目录

#### Scenario: 空链任务运行菜单命令和脚本
- **WHEN** 执行中任务未选择任何生命周期命令链，用户从任务菜单运行自定义命令
- **THEN** 系统在当前用户的 Home 目录运行该命令及其配置的前置和后置脚本

#### Scenario: 空链任务打开文件夹
- **WHEN** 执行中任务未选择任何生命周期命令链，用户选择“打开任务文件夹”
- **THEN** 系统打开当前用户的 Home 目录，且不创建任务工作目录

#### Scenario: Home 目录不可用
- **WHEN** 执行中任务未选择任何生命周期命令链，且当前用户的 Home 目录无法获取、访问或不是目录
- **THEN** 系统拒绝相应的终端、命令或目录打开操作并报告错误，且不得启动部分操作

### Requirement: 已选链任务保留工作目录语义

系统 SHALL 对至少选择了一条生命周期命令链的执行中任务继续使用持久化的任务工作目录作为任务级交互操作目录。任务工作目录不存在、不是目录或无法访问时，系统 MUST 保留既有失败行为，且 MUST NOT 回退到当前用户的 Home 目录。

#### Scenario: 已选链任务的目录不可用
- **WHEN** 执行中任务至少选择了一条生命周期命令链，但其任务工作目录不存在、不是目录或无法访问
- **THEN** 系统拒绝对应的终端、命令或目录打开操作并报告任务工作目录错误，且不得改用当前用户的 Home 目录

#### Scenario: 生命周期命令不使用 Home 回退
- **WHEN** 系统执行任意生命周期钩子中的命令
- **THEN** 系统继续按该钩子的既有任务工作区规则执行，不得因任务链选择为空而将命令目录改为当前用户的 Home 目录
