## MODIFIED Requirements

### Requirement: 高频重绘不出现可见的中间态渲染

对以“逐行重绘 + 光标定位”方式高频刷新屏幕的终端程序，嵌入终端的可见画面 MUST 只呈现每个输出突发完成后的状态，MUST NOT 在重绘过程中显示光标跳到中间位置。渲染同步 MUST NOT 通过应用层附加控制序列永久修改终端程序的光标可见性、闪烁设置或光标样式；终端程序自身发送的光标控制序列 MUST 按原顺序生效。该行为 MUST 同时适用于 Windows ConPTY、Unix PTY、前台选中会话和后台会话切回后的画面。

#### Scenario: 合成重绘流下光标稳定

- **WHEN** 在嵌入终端中运行一个循环执行“光标归位、重写多行、重新定位光标”的高频重绘程序
- **THEN** 屏幕字符持续更新为各轮输出的最终内容，期间不出现光标在行间反复跳变的中间态；输出静默后光标位于程序最后指定的位置，并保持程序指定的可见性和闪烁行为

#### Scenario: 后续普通输出不会遗留隐藏光标

- **WHEN** 一次大规模重绘输出后，终端继续收到不包含光标控制序列的普通文本输出
- **THEN** 普通输出完成后，光标可见性和闪烁状态仍由终端程序最后一次光标控制决定，不会因为重绘同步而永久隐藏或改变闪烁频率

#### Scenario: 用户输入后光标保持可见并正常移动

- **WHEN** 用户在重绘输出结束后输入字符或按左右方向键移动光标，且终端程序没有明确要求隐藏光标
- **THEN** 光标随输入结果移动并保持可见，闪烁节奏不因前一次输出同步或恢复操作而异常

#### Scenario: 程序主动隐藏光标保持隐藏

- **WHEN** 终端程序明确发送隐藏光标控制序列，且后续没有发送显示光标控制序列
- **THEN** 嵌入终端保持光标隐藏，不被应用层的重绘同步逻辑强制显示

#### Scenario: 击键回显光标保持可见

- **WHEN** 用户在交互中输入字符、终端回显少量输出，且终端程序未隐藏光标
- **THEN** 光标在这些输出写入后立即可见，不被渲染同步逻辑掩盖

#### Scenario: 后台会话切回画面无丢失

- **WHEN** 某终端在后台持续重绘输出，用户切换到其他终端后再切回
- **THEN** 该终端呈现重绘完成后的最新画面，各轮输出内容一致、无内容丢失，光标状态与程序最后指定的状态一致

#### Scenario: 会话生命周期不会遗留同步状态

- **WHEN** 终端在输出突发期间退出、分离、重新附着或销毁
- **THEN** 终端在退出或销毁前完成必要的最终渲染，未决同步回调被取消，后续不会向已销毁会话写入或改变光标状态

#### Scenario: 集成验证方法

- **WHEN** 使用 `wails dev` 启动应用并从输出获取浏览器调试地址，用浏览器工具打开应用，在任务终端中运行跨平台的高频重绘脚本
- **THEN** 使用 rAF 采样 `.xterm-cursor` 的可见性和位置，确认重绘期间不出现行间中间态、重绘结束后位置稳定、普通输出和左右键输入后光标可见且闪烁节奏正常；测试完成后关闭调试进程
