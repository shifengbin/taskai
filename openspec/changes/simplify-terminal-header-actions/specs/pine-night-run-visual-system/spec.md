## MODIFIED Requirements

### Requirement: 终端与实时状态的视觉连续性
系统 SHALL 让终端标题栏、终端背景、前景文字、光标、选择区和左侧终端项的实时状态点适配快门波普视觉系统。终端背景必须叠加半色网点底纹，并通过 xterm 主题注入提示符珊瑚、成功信息钴蓝、关键字与光标紫罗兰的配色；无论工作台处于亮色或暗色模式，亮色模式终端背景必须使用快门波普浅次表面 + 半色网点，暗色模式必须使用比亮色更深的夜色次表面 + 半色网点；若亮色模式下输出可读性不足，亮色终端可回退为深色表面。右侧活动终端标题栏不得出现影响终端图标或标题阅读的额外横杠、实时状态点或关闭终端按钮，并必须保留始终可见的快捷输入入口。终端的输入输出、尺寸调整、焦点、关闭、剪贴板和实时事件行为不得因视觉改造而变化；实时状态点和关闭操作必须继续在左侧终端项中可用。

#### Scenario: 在任意模式查看活动终端
- **WHEN** 用户在亮色或暗色模式选择一个活动终端
- **THEN** 终端必须使用高对比前景与背景、半色网点底纹和快门波普配色的高亮；右侧标题栏必须显示终端图标、可裁剪标题和可直接操作的快捷输入入口，不得显示实时状态点或关闭终端按钮；左侧对应终端项必须继续提供实时状态点和关闭入口

#### Scenario: 在暗色模式查看活动终端
- **WHEN** 用户在暗色模式选择一个活动终端
- **THEN** 终端必须使用比亮色模式更深的背景和高对比前景，右侧标题和快捷输入入口保持清晰可见，且左侧终端项的实时状态点与关闭入口保持可用

#### Scenario: 终端出现工作中或未读状态
- **WHEN** 终端实时状态为工作中或未读
- **THEN** 左侧终端项的状态点必须使用快门波普主题一致的静态或脉冲提示（working=钴蓝、unread=琥珀、error=红、idle=muted），且其现有无障碍状态标签保持不变

### Requirement: 任务与终端的上下文操作可见性
系统 SHALL 将任务行的展开、执行、结束、重试和任务操作按钮，以及终端子项的关闭按钮，作为上下文操作控件。支持悬停的输入环境中，这些控件 MUST 在默认状态下视觉隐藏，并在所属容器悬停、容器内控件获得键盘焦点或对应任务操作菜单打开时显示。视觉隐藏不得移除控件的 DOM、语义或固定布局占位。右侧活动终端标题栏的快捷输入入口不是上下文操作控件，MUST 始终可见。

#### Scenario: 默认查看任务和终端
- **WHEN** 用户在支持悬停的设备上查看未悬停且没有键盘焦点的任务行或终端子项
- **THEN** 其上下文操作控件视觉隐藏，任务标题、描述、状态点、生命周期进度/错误提示和批量选择复选框保持可见，且标题与行布局不得因操作控件隐藏而重排；右侧活动终端标题栏的快捷输入入口保持可见

#### Scenario: 悬停任务或终端子项
- **WHEN** 用户将鼠标移入任务行或终端子项
- **THEN** 该容器的上下文操作控件显示并可按原有规则执行，其他容器的控件不因本次悬停而显示；右侧活动终端标题栏的快捷输入入口不依赖本次悬停

#### Scenario: 使用键盘聚焦上下文操作
- **WHEN** 用户通过键盘将焦点移入任务行或终端子项中的上下文操作控件
- **THEN** 所属容器的上下文操作控件显示，当前焦点与既有焦点环保持可见，且按钮的 ARIA 标签、禁用状态和触发结果不变

#### Scenario: 在无悬停设备上操作
- **WHEN** 用户使用不支持悬停的输入设备查看任务行或终端子项
- **THEN** 上下文操作控件保持可见并可直接操作，不得要求用户执行不可用的悬停手势；右侧活动终端标题栏的快捷输入入口同样保持可见

#### Scenario: 打开任务操作菜单
- **WHEN** 用户通过任务操作按钮打开某个任务的操作菜单
- **THEN** 菜单保持既有定位、内容和关闭规则，且该任务行的上下文操作控件在菜单打开期间保持显示
