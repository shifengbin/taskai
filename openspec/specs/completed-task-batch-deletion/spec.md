## Purpose

让用户能够在已完成任务列表中安全地选择并批量删除任务记录，同时确保任务工作目录和生命周期执行状态不受影响。
## Requirements
### Requirement: 已完成任务选择模式
系统 SHALL 仅在“未执行”和“已完成”任务标签中提供显式的选择模式。进入选择模式后，系统 MUST 允许用户逐项选择当前标签中符合删除资格的任务、全选当前标签中全部符合资格的任务，以及取消选择模式；离开选择模式或切换到其他状态标签时，系统 MUST 清空本次选择。

#### Scenario: 选择多个可删除任务
- **WHEN** 用户在“未执行”或“已完成”标签进入选择模式并勾选多个符合资格的任务
- **THEN** 系统显示已选任务数量，并仅将当前标签中这些任务作为待删除目标

#### Scenario: 全选当前标签中的可删除任务
- **WHEN** 用户在“未执行”或“已完成”标签的选择模式触发全选
- **THEN** 系统选择当前标签中全部符合删除资格的任务，且不选择其他状态的任务

#### Scenario: 取消或切换标签会清空选择
- **WHEN** 用户取消选择模式或切换到其他状态标签
- **THEN** 系统退出选择模式并清空所有待删除任务 ID

### Requirement: 删除资格保护
系统 MUST 仅允许删除以下任务：状态为 `pending` 或 `completed` 且不存在生命周期执行记录的任务；以及状态为 `pending`、生命周期执行记录为失败状态且钩子为 `beforeStart` 的任务。存在运行中生命周期执行记录、其他状态或其他失败钩子的任务 MUST 保持不可选择和不可删除。目录归属未知的旧版开始前失败任务 MUST 保持不可删除，系统不得根据当前设置、命令进度或目录存在性推断归属。

#### Scenario: 完成任务的结束后命令链失败
- **WHEN** 一项已完成任务存在失败的结束后生命周期执行记录
- **THEN** 系统不得将该任务加入可删除选择或删除请求，并保留现有重试能力

#### Scenario: 未执行任务的开始前命令链失败
- **WHEN** 一项未执行任务存在失败的开始前生命周期执行记录，且目录归属为 `not-created` 或 `created`
- **THEN** 系统允许用户在未执行任务选择模式中选择并删除该任务，同时保留删除前的重试入口

#### Scenario: 旧版开始前失败记录缺少目录归属
- **WHEN** 一项未执行任务存在失败的开始前生命周期执行记录，但系统无法确认当时的路径和目录归属
- **THEN** 系统不得将该任务加入可删除选择或删除请求，也不得尝试删除任何推测出的目录

#### Scenario: 删除请求混入不可删除任务
- **WHEN** 批量删除请求包含执行中、运行中生命周期执行记录、非开始前失败记录、目录归属未知或不存在的任务 ID
- **THEN** 系统拒绝整个请求且不删除任何任务记录

### Requirement: 原子化批量删除任务记录
系统 SHALL 提供接收多个任务 ID 的批量删除接口。该接口 MUST 在一次持久化操作前校验全部 ID，拒绝空集合和重复 ID；所有目标均符合删除资格时，系统 MUST 一次性移除全部目标任务记录，并返回最新完整任务列表。

#### Scenario: 成功删除多个未执行或已完成任务
- **WHEN** 用户确认删除多个符合资格的未执行或已完成任务
- **THEN** 系统一次性移除这些任务记录，返回不含这些任务的最新任务列表，并更新对应任务标签的计数

#### Scenario: 一个目标已被其他操作移除
- **WHEN** 用户确认删除时，所选 ID 中有一个已不存在
- **THEN** 系统拒绝整个请求，保留其余所有任务记录，并向用户报告错误

### Requirement: 记录删除不影响文件与生命周期操作
系统 MUST 将普通未执行任务和已完成任务的批量删除限定为任务记录操作。对于开始前命令链失败的未执行任务，系统 MUST 仅在持久化执行记录的随机令牌能同时匹配 TaskAI 私有侧车凭据、目录自身所有权标记及当前目录文件系统身份时，使用该记录的路径快照安全删除任务目录；没有创建命令、创建命令未执行或失败、创建命令复用已有目录、同名目录后来被替换或删除后同名重建时 MUST NOT 删除该目录。确认界面 MUST 明确说明任务记录删除不可撤销，以及启动失败任务的条件目录清理行为。批量删除 MUST NOT 调度、取消或重试生命周期命令链。

#### Scenario: 删除具有保留工作目录的普通任务
- **WHEN** 用户确认删除一项工作目录仍存在的符合资格未执行或已完成任务
- **THEN** 系统只移除任务记录，工作目录及其内容保持不变，且不执行任何生命周期命令

#### Scenario: 删除实际创建了工作目录的启动失败任务
- **WHEN** 用户确认删除一项开始前命令链失败的未执行任务，且执行记录确认 TaskAI 本次启动过程新建了对应任务目录
- **THEN** 系统先使用记录的根目录、任务目录和任务 ID 通过安全边界校验删除该目录，再删除任务记录，且不执行任何生命周期命令

#### Scenario: 删除未创建工作目录的启动失败任务
- **WHEN** 用户确认删除一项开始前命令链失败的未执行任务，且命令链没有创建目录命令、未执行到创建命令、创建命令失败或复用了已有目录
- **THEN** 系统不调用目录删除，只移除任务记录，任何已有目录及其内容保持不变

#### Scenario: 启动失败任务的目录已经不存在
- **WHEN** 执行记录确认目录由 TaskAI 新建，但用户删除任务时该目录已经不存在
- **THEN** 系统将目录清理视为成功并继续删除任务记录

#### Scenario: 启动失败任务的目录清理失败
- **WHEN** 安全路径校验、符号链接检查或文件系统操作无法删除 TaskAI 新建的任务目录
- **THEN** 系统拒绝删除请求并保留全部任务记录、失败执行记录和重试能力

#### Scenario: TaskAI 创建的同名目录已被替换
- **WHEN** 执行记录显示 TaskAI 创建过任务目录，但删除时同一路径目录的文件系统身份不再匹配所有权凭据
- **THEN** 系统不得删除替换后的目录，拒绝删除请求并保留任务记录与失败信息

#### Scenario: TaskAI 创建的目录删除后被同名重建
- **WHEN** TaskAI 创建的原任务目录已被删除，随后同一路径创建了新目录，即使文件系统复用了原目录身份
- **THEN** 系统因新目录缺少匹配的目录自身所有权标记而不得删除它，并保留任务记录与失败信息

#### Scenario: 清理期间并发新增任务
- **WHEN** 启动失败任务的目录清理期间创建了其他任务
- **THEN** 系统在清理后基于最新任务快照只移除目标任务，并保留并发新增任务

### Requirement: 删除后的前端状态清理
系统 SHALL 在批量删除成功后从前端状态清理已删任务的详情选择、终端选择、展开状态和待删除选择，并退出选择模式。

#### Scenario: 删除当前详情任务
- **WHEN** 用户删除的集合包含当前在详情区域选中的任务
- **THEN** 系统清除该任务及其终端选择，并不再在任务树或详情区域引用已删除记录
