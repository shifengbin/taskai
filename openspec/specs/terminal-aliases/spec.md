## Requirements
### Requirement: 为当前终端会话设置展示别名
系统 SHALL 允许用户在任务树终端项和右侧终端标题栏双击终端名称，为该活动终端会话编辑别名。两个位置 MUST 基于同一会话别名显示相同名称；非空别名 MUST 完全替代实际终端名称显示，且不得修改实际终端标题或启动命令。

编辑时，系统 MUST 提供已聚焦的单行输入框；按 Enter 或输入框失焦时，系统 MUST 保存去除首尾空白后的内容；按 Escape 时，系统 MUST 放弃本次未保存修改。保存空内容 MUST 清除别名并恢复实际终端名称显示。

#### Scenario: 从任务树设置别名
- **WHEN** 用户双击任务树中的活动终端名称，输入 `前端调试` 并按 Enter
- **THEN** 任务树和右侧终端标题栏都只显示 `前端调试`

#### Scenario: 从终端标题栏修改别名
- **WHEN** 已有别名 `前端调试` 的终端在右侧标题栏被双击，用户将其改为 `接口调试` 后使输入框失焦
- **THEN** 任务树和右侧终端标题栏都只显示 `接口调试`

#### Scenario: 清空别名恢复实际名称
- **WHEN** 用户编辑已有别名并保存空字符串或仅包含空白字符的内容
- **THEN** 系统清除别名，并在两个位置恢复该终端当前实际标题的既有显示规则

#### Scenario: 取消编辑保留原别名
- **WHEN** 用户编辑别名后按 Escape
- **THEN** 系统放弃本次输入，两个位置继续显示编辑前的别名

### Requirement: 别名终端显示实际会话信息
系统 SHALL 仅在终端具有非空别名且未处于名称编辑状态时，为任务树终端项和右侧终端标题栏提供悬浮提示。提示 MUST 恰好按两行显示：第一行固定为 `标题: <实际标题>`，其中实际标题按既有回退规则得到；第二行固定为 `命令: <启动命令>`；启动命令缺失时，第二行 MUST 在命令值位置显示明确的缺省文本。

任务树中的终端悬浮提示 MUST 显示在对应终端项右侧，并与条目保留间距，不得显示在终端项上方。该提示 MUST NOT 接收鼠标事件或阻挡任务树中终端项的点击。右侧终端标题栏的提示 MUST 保持既有定位行为。

没有别名的终端 MUST 保持既有名称展示，系统不得仅因本能力新增悬浮提示。

#### Scenario: 悬浮查看别名终端的实际信息
- **WHEN** 名为 `前端调试` 的终端实际标题为 `npm run dev`、启动命令为 `zsh`，用户将鼠标悬浮在任务树或右侧标题栏的名称上
- **THEN** 对应提示按两行显示 `标题: npm run dev` 和 `命令: zsh`，且不将别名作为任一提示行

#### Scenario: 启动命令缺失时保留提示结构
- **WHEN** 具有别名的终端缺少启动命令信息，用户将鼠标悬浮在其名称上
- **THEN** 提示仍按两行显示实际名称和明确的启动命令缺省文本

#### Scenario: 任务树终端提示显示在右侧
- **WHEN** 用户将鼠标悬浮在任务树中具有别名的终端名称上
- **THEN** 提示显示在对应终端项右侧并与条目保留间距，不得出现在该终端项上方

#### Scenario: 任务树终端提示不阻挡点击
- **WHEN** 任务树中的终端悬浮提示处于显示状态，用户点击任务树中的终端项
- **THEN** 提示不接收鼠标事件，终端项仍可按既有行为被选中

#### Scenario: 右侧标题栏保持既有定位
- **WHEN** 用户将鼠标悬浮在右侧终端标题栏中具有别名的终端名称上
- **THEN** 系统继续使用该标题栏既有的提示定位行为，不应用任务树专用的右侧定位策略

### Requirement: 别名不得影响基于标题变化的实时状态
系统 MUST 将别名作为纯展示数据。终端实际标题的 OSC 解析、实际标题变化检测以及 `title-change` 实时状态方式 MUST 继续只使用实际标题字段；设置、修改、清空别名或显示悬浮提示 MUST NOT 触发终端活动上报、改变终端实时状态或改变聚合任务实时状态。

#### Scenario: 修改别名不触发标题变化状态
- **WHEN** 状态管理方式为 `title-change`，用户为一个空闲终端设置、修改或清空别名，且该终端未收到新的 OSC 标题输出
- **THEN** 该终端和所属任务的实时状态保持修改前的值，且不会产生标题变化活动上报

#### Scenario: 实际标题变化仍驱动状态
- **WHEN** 状态管理方式为 `title-change`，具有别名的终端收到与先前不同的完整 OSC 实际标题
- **THEN** 系统仍按现有标题变化规则上报该终端活动，名称显示继续保留别名
