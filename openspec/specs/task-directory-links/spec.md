## Requirements
### Requirement: 从任务绑定模板目录字段计算期望链接

系统 SHALL 只从任务绑定模板中输入类型为 `directories` 的可见字段读取字符串数组，并为数组中的每个独立绝对目录地址计算一个任务工作目录根级链接。系统 MUST 要求任务工作目录通过现有任务 ID、所有权令牌和目录身份校验，MUST 再次确认每个来源存在、可访问且解析为目录，并 MUST 在任务全部当前目录字段范围内拒绝重复规范来源。没有绑定模板、没有可见目录字段或所有目录数组为空时，期望链接集合 MUST 为空；历史目录字段值不得参与计算。切换全局当前模板 MUST NOT 改变既有任务的期望链接来源。

#### Scenario: 多个字段产生独立根级链接
- **WHEN** 任务绑定模板的两个目录字段分别保存一个和两个互不重复的现有目录
- **THEN** 系统计算三个直接位于任务工作目录根级、分别指向三个来源的期望链接

#### Scenario: 绑定模板删除目录字段
- **WHEN** 任务仍保存目录数组，但任务绑定模板已经删除对应字段
- **THEN** 系统不从历史值计算链接，并把此前由该字段管理的链接视为待清理项

#### Scenario: 切换新任务默认模板
- **WHEN** 任务绑定的模板包含目录字段，随后用户把全局当前模板切换为另一个模板
- **THEN** 既有任务继续按原绑定模板计算目录链接，新建任务使用新的全局当前模板

#### Scenario: 同一来源跨字段重复
- **WHEN** 两个当前目录字段通过不同文本路径解析到同一个规范目录
- **THEN** 系统拒绝同步，错误包含两个字段和重复来源，不创建或删除任何链接

#### Scenario: 同步时来源不再可用
- **WHEN** 已保存来源在同步前被删除、替换为文件或变为不可访问
- **THEN** 系统拒绝同步，错误包含字段显示名称和绝对路径，且不修改现有链接集合

### Requirement: 确定性生成唯一链接名称

系统 MUST 默认使用来源目录 basename 作为链接名称，并使用大小写不敏感比较检测任务内名称冲突。同名组中的所有来源 MUST 从直接父目录开始逐级前置祖先组件并以 `-` 连接，直到全部名称唯一；例如 `/project-a/src` 与 `/project-b/src` MUST 生成 `project-a-src` 与 `project-b-src`。新增或移除来源后系统 MUST 根据当前完整集合重新计算名称。到达根目录、生成名称不合法或超出平台限制后仍无法唯一命名时，系统 MUST 拒绝同步，不得使用添加序号或覆盖已有条目作为回退。

#### Scenario: 无冲突时使用目录 basename
- **WHEN** 当前来源目录 basename 分别为 `api` 和 `web`
- **THEN** 系统生成名为 `api` 和 `web` 的链接

#### Scenario: 同名目录使用父目录消歧
- **WHEN** 当前来源为 `/project-a/src` 和 `/project-b/src`
- **THEN** 系统生成 `project-a-src` 和 `project-b-src`，且不保留仅名为 `src` 的管理链接

#### Scenario: 多级父目录后才唯一
- **WHEN** 两个同名来源的直接父目录也同名，但更高一级父目录不同
- **THEN** 系统继续加入更高一级组件，直到两个链接名称唯一

#### Scenario: 无法生成唯一安全名称
- **WHEN** 来源路径的全部可用祖先仍不能产生合法且唯一的链接名称
- **THEN** 同步失败且工作目录和清单保持可重试状态

### Requirement: 只同步和清理有所有权证据的链接

系统 SHALL 在工作区根的受验证所有权元数据目录中，为每个任务保存包含任务 ID、所有权令牌、管理链接名称和绝对来源的事务清单。同步 MUST 在修改文件系统前完整预检来源、期望名称、目标占用和旧管理链接身份，并通过原子 pending 清单记录旧状态和期望状态。系统 MUST 只删除清单登记、仍是目录链接且仍指向登记来源的条目，MUST NOT 跟随链接删除来源，MUST NOT 覆盖普通文件、普通目录、未登记链接或目标不同的链接。成功收敛后系统 MUST 原子提交稳定清单；任务工作目录安全删除成功后 MUST 清理对应清单。

#### Scenario: 首次同步创建链接和稳定清单
- **WHEN** 任务工作目录为空且两个期望名称均未占用
- **THEN** 系统创建两个目录链接并提交只登记这两个名称和来源的稳定清单

#### Scenario: 空期望只删除登记链接
- **WHEN** 当前期望集合为空，工作目录同时包含一个登记链接和一个普通目录
- **THEN** 系统只删除登记链接，保留普通目录及其内容，并提交空管理清单

#### Scenario: 期望名称被未知条目占用
- **WHEN** 期望链接名称已经是普通文件、普通目录或未登记链接
- **THEN** 系统在预检阶段失败，不覆盖或删除占用条目，也不部分修改其他链接

#### Scenario: 登记链接已被替换
- **WHEN** 清单中的名称被替换为普通目录或指向其他来源的链接
- **THEN** 系统拒绝删除或覆盖该条目，报告管理链接身份不匹配并保留来源目录

#### Scenario: 从 pending 清单恢复部分同步
- **WHEN** 进程在提交 pending 清单后仅完成部分链接操作便中断
- **THEN** 下一次执行根据清单记录的旧状态和期望状态安全继续，最终收敛且不操作清单之外的条目

#### Scenario: 删除任务工作目录不删除来源
- **WHEN** 任务工作目录包含多个受管理目录链接并成功执行删除工作目录命令
- **THEN** 系统删除工作目录中的链接本身和对应清单，但所有外部来源目录及其内容保持完整

### Requirement: 生命周期同步保持既有提交和重试语义

系统 SHALL 以固定 ID `system.lifecycle.sync-directory-links` 提供“同步任务目录链接”系统命令。该命令 MUST 不接受参数，MUST 适用于 `beforeStart`、`postStart` 与 `updateTask`，成功时 MUST 原样输出收到的标准输入供下一命令使用。pending 任务更新目录值时 MUST 只保存任务数据并在之后的启动链同步；running 任务更新成功后 MUST 先保存数据再由 `updateTask` 同步。`beforeStart` 同步失败 MUST 阻止任务进入 running；`postStart` 或 `updateTask` 失败 MUST 保留已经提交的任务状态或字段值并记录失败和重试入口。重试 MUST 从链首开始，并根据最新任务值与任务绑定模板重新计算期望链接。

#### Scenario: pending 任务在启动时同步
- **WHEN** 用户为 pending 任务保存目录值后启动任务，且 `beforeStart` 链包含同步命令
- **THEN** 保存阶段不要求任务工作目录存在，启动链创建工作目录后同步链接

#### Scenario: beforeStart 同步失败阻止启动
- **WHEN** 同步命令因来源缺失或目标冲突在 `beforeStart` 失败
- **THEN** 任务保持 pending，记录包含字段和路径的失败信息，并允许从链首重试

#### Scenario: running 任务先保存再同步
- **WHEN** 用户更新 running 任务的可更新目录字段
- **THEN** 系统先持久化新数组，再执行 `updateTask` 链；同步失败时新数组保持已保存并提供重试

#### Scenario: 重试使用最新目录值
- **WHEN** 一次同步失败后用户通过允许的方式修正当前任务值或恢复来源，再重试命令链
- **THEN** 命令忽略失败执行时的旧请求缓存，按最新持久化任务和任务绑定模板收敛链接

#### Scenario: 成功时传递标准输入
- **WHEN** 同步命令位于包含后续命令的链中且同步成功
- **THEN** 后续命令收到与同步命令输入完全相同的字节内容

### Requirement: 跨平台目录链接不得退化为内容复制

系统 MUST 通过平台文件系统适配器创建、检查和删除目录链接。Unix MUST 使用目录 symlink；Windows MUST 使用不弹出终端窗口的原生目录 symlink 或 junction。平台不支持安全创建或识别目录链接时，系统 MUST 使同步命令失败并保留可重试状态，MUST NOT 复制、移动、遍历删除或修改来源目录内容。

#### Scenario: Unix 创建目录 symlink
- **WHEN** 同步命令在受支持的 Unix 文件系统执行
- **THEN** 工作目录条目为指向绝对来源的目录 symlink，而不是来源内容副本

#### Scenario: Windows 创建无窗口目录链接
- **WHEN** 同步命令在受支持的 Windows 文件系统执行
- **THEN** 系统通过原生 API 创建可作为目录访问的 symlink 或 junction，执行期间不弹出命令窗口

#### Scenario: 文件系统不支持安全链接
- **WHEN** 平台或目标文件系统无法安全创建或读取目录链接
- **THEN** 同步失败且不创建来源副本、不删除来源内容，并报告平台或文件系统错误
