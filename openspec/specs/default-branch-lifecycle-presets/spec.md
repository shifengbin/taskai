# default-branch-lifecycle-presets Specification

## Purpose
定义默认分支任务模板、一次性仓库命令链预置、系统命令适用范围扩展，以及 Git 克隆与开始前状态同步规则。

## Requirements

### Requirement: 提供并默认激活默认分支模板
系统 MUST 提供名称为“默认分支”的预置任务模板。该模板 MUST 包含唯一的 `branch` 字段，字段显示名称 MUST 为“默认分支”，输入类型 MUST 为 `string`，MUST 为必填，默认值 MUST 为空字符串，且 MUST 不注入生命周期环境变量。新安装时系统 MUST 将该模板设为当前模板；升级既有设置时，仅当当前模板为空时系统 MUST 将该模板设为当前模板，MUST 保留已有的当前模板选择。

#### Scenario: 新安装默认激活模板
- **WHEN** 用户首次启动没有持久化数据的应用
- **THEN** 设置包含“默认分支”模板并将其设为当前模板，且新建任务表单显示必填的“默认分支”文本输入

#### Scenario: 必填分支拒绝空白值
- **WHEN** 当前模板为“默认分支”，用户以空字符串或仅空白字符保存任务
- **THEN** 系统拒绝保存并提示“默认分支”为必填字段

#### Scenario: 升级保留用户已选模板
- **WHEN** 旧设置已有非空当前模板选择且尚未应用本预置迁移
- **THEN** 系统补齐预置内容但保持该已有选择，不自动切换到“默认分支”

#### Scenario: 修复版本 2 的异常缺失模板
- **WHEN** 系统加载预置版本为 2 且任务模板列表为空的设置
- **THEN** 系统仅在本次版本 3 迁移中补回“默认分支”模板并将其设为当前模板；此后用户删除模板不会被重新创建

### Requirement: 一次性补齐可删除的仓库命令链预置
系统 MUST 通过持久化的预置迁移版本为新安装和旧设置各补齐一次 `iterations-ai` 与“更新仓库”命令链。两个预置链 MUST 使用稳定标识，但 MUST 作为普通命令链管理，不得成为不可编辑或不可删除的系统固定链。系统 MUST 在一次性补齐后记录最新预置迁移版本，并且在后续加载时 MUST 不重新创建用户删除的预置链。删除仍 MUST 遵循既有规则：被未执行或执行中任务引用的链不可删除，其他情况允许删除。

#### Scenario: 旧设置只补齐一次
- **WHEN** 系统加载未记录本预置迁移版本的既有设置
- **THEN** 系统补齐两个预置链并持久化最新版本，之后用户删除其中任一链再重启应用时该链不再自动出现

#### Scenario: 可以删除未被活动任务引用的预置链
- **WHEN** 用户删除未被未执行或执行中任务引用的 `iterations-ai` 或“更新仓库”链
- **THEN** 系统删除该链，并且不修改其他命令链或默认链映射

#### Scenario: 保护被活动任务引用的预置链
- **WHEN** 未执行或执行中任务选择了某条预置链，用户尝试删除该链
- **THEN** 系统拒绝删除并说明该链仍被任务引用

### Requirement: 预置 iterations-ai 开始前命令链
系统 MUST 提供名称为 `iterations-ai`、仅适用于 `beforeStart` 的预置命令链。该链 MUST 按以下顺序引用命令：创建任务工作目录；克隆指定 Git 仓库并传入唯一参数 `repository=git@gitlab.jiandan100.cn:webdev/iterations-ai.git`；生成清单文件且不传追加参数；Git 仓库克隆并传入唯一参数 `dir=workspaces`。系统 MUST 不将该链设为任何钩子的默认链。

#### Scenario: 用户在开始前选择 iterations-ai 链
- **WHEN** 用户为任务的 `beforeStart` 钩子选择 `iterations-ai` 并开始任务
- **THEN** 系统在任务进入执行中前依序创建目录、将指定仓库克隆到任务目录根部、生成清单文件，并将选定 Git 信息克隆到任务目录下的 `workspaces` 路径

#### Scenario: iterations-ai 不会自动预选
- **WHEN** 用户新建任务且未手动选择 `beforeStart` 命令链
- **THEN** 系统不因预置 `iterations-ai` 链而为该钩子保存命令链选择

### Requirement: 预置更新仓库命令链
系统 MUST 提供名称为“更新仓库”、仅适用于 `updateTask` 的预置命令链。该链 MUST 先引用生成清单文件命令且不传追加参数，再引用 Git 仓库克隆命令并传入唯一参数 `dir=workspaces`。系统 MUST 不将该链设为任何钩子的默认链；该链的 Git 仓库克隆步骤 MUST 保持既有语义，仅克隆缺失目标而不得执行拉取、合并、覆盖或删除已有 Git 工作树。

#### Scenario: 执行中任务更新时运行预置链
- **WHEN** 执行中任务选择“更新仓库”作为 `updateTask` 链并成功保存任务更新
- **THEN** 系统先重新生成任务目录根部的清单文件，再以 `dir=workspaces` 执行 Git 仓库克隆

#### Scenario: 已有仓库不被更新链覆盖
- **WHEN** “更新仓库”链运行时 `workspaces` 下的某个选定 Git 信息目标已存在
- **THEN** 系统保留已有目标并按 Git 仓库克隆的既有跳过语义继续处理，不执行 Git 拉取或覆盖

### Requirement: 所需系统命令支持开始后链
系统 MUST 将“创建任务工作目录”和“Git 仓库克隆”系统命令的固定适用范围设为包含 `beforeStart` 和 `postStart`。现有“创建任务工作目录”默认链 MUST 保持仅适用于 `beforeStart`，系统 MUST 不因扩展命令范围改变既有默认链映射或任务的默认选择。

#### Scenario: postStart 链可引用创建目录命令
- **WHEN** 用户保存仅适用于 `postStart` 且首个命令为“创建任务工作目录”的链
- **THEN** 系统接受该链并在任务状态提交为执行中后运行创建目录命令

#### Scenario: postStart 链可引用 Git 仓库克隆
- **WHEN** 用户保存仅适用于 `postStart` 且包含“Git 仓库克隆”命令的链
- **THEN** 系统接受该链并保留该命令既有的 `dir=<相对目录>` 参数校验和已存在目标跳过语义

#### Scenario: 既有开始前默认链保持不变
- **WHEN** 系统加载包含既有默认生命周期配置的设置
- **THEN** `beforeStart` 仍默认选择原创建目录链，系统不为 `postStart` 自动设置默认链

### Requirement: Git 克隆不依赖应用当前目录
系统 MUST 在远程分支检查、远程分支克隆和默认分支克隆时，将克隆目标的父目录传给 Git 作为工作目录。系统 MUST 不依赖应用进程当前工作目录；本地分支创建 MUST 继续在完成克隆后的目标目录中执行。

#### Scenario: 应用启动目录已经不存在
- **WHEN** 应用进程当前工作目录已被删除，且命令链以指定分支执行 Git 远程检查和克隆
- **THEN** 系统仍以克隆目标父目录运行 Git，不因无法读取应用当前目录而失败

### Requirement: 开始前链完成后保留执行中任务
系统 MUST 在开始前命令链完成并收到任务进入执行中事件后，自动切换到“执行中”任务标签。后续到达的旧未执行开始请求响应 MUST 不得覆盖该执行中任务状态。

#### Scenario: 生命周期事件先于开始请求响应
- **WHEN** 开始前链完成后的执行中事件先于开始请求的未执行响应到达界面
- **THEN** 界面切换到“执行中”标签并继续显示该任务
