## Requirements
### Requirement: 持久化全局快捷输入
系统 MUST 持久化与任务无关的全局快捷输入数组。每项 MUST 保存稳定唯一标识、名称、内容和用户定义顺序；名称可以重复。系统 MUST 允许既有数据文件缺少该数组，并将其作为空数组加载。新安装 MUST 不预置快捷输入。

#### Scenario: 读取没有快捷输入字段的既有数据
- **WHEN** 应用加载一个不含快捷输入字段的数据文件
- **THEN** 应用正常加载既有任务、设置和额外信息，并提供空的快捷输入列表

#### Scenario: 保存同名快捷输入
- **WHEN** 用户保存两项名称均为“部署”但内容不同的快捷输入
- **THEN** 系统分别以不同稳定标识保存两项，并在重新打开应用后保留两项及其排序

#### Scenario: 新安装不创建示例
- **WHEN** 用户首次打开快捷输入管理
- **THEN** 系统显示空列表，且不自动创建任何示例或默认内容

### Requirement: 校验快捷输入名称和内容
系统 MUST 拒绝保存去除首尾空白后为空或超过 100 字符的名称。系统 MUST 拒绝保存不含任何非空白字符的内容。系统 MUST 不对有效内容施加长度上限，并 MUST 保留其全部文本和换行格式。

#### Scenario: 拒绝空名称
- **WHEN** 用户保存名称为空或仅包含空白字符的快捷输入
- **THEN** 系统拒绝保存并说明名称不能为空

#### Scenario: 拒绝空白内容
- **WHEN** 用户保存仅包含空格、制表符或换行的内容
- **THEN** 系统拒绝保存并说明内容必须包含非空白字符

#### Scenario: 保存多行长内容
- **WHEN** 用户保存包含多行且长度超过常用命令长度的有效内容
- **THEN** 系统保存完整内容，编辑界面显示当前字符数，后续插入时使用完整内容

### Requirement: 管理快捷输入并立即持久化
系统 MUST 在快捷输入管理中提供新增、编辑、删除、名称和内容搜索及手动排序。搜索 MUST 同时匹配名称和内容，结果 MUST 显示名称及可区分同名项的内容摘要。每次成功的新建、编辑、删除或排序 MUST 立即持久化。删除前 MUST 请求确认并显示被删除项的名称。排序 MUST 按稳定标识执行，并在未搜索时决定列表的显示顺序。

#### Scenario: 编辑后立即可用
- **WHEN** 用户编辑一条快捷输入并保存
- **THEN** 系统立即持久化修改，关闭并重新打开信息管理或终端选择器后显示修改后的名称和内容

#### Scenario: 删除前确认
- **WHEN** 用户请求删除名称为“部署”的快捷输入
- **THEN** 系统显示包含“部署”名称的删除确认；用户未确认时系统保留该输入，确认后立即删除

#### Scenario: 对同名项手动排序
- **WHEN** 用户将两个同名但内容不同的快捷输入调整顺序
- **THEN** 系统按各自稳定标识保存新的顺序，重新打开列表后保持该顺序

#### Scenario: 按内容关键词管理搜索
- **WHEN** 用户在快捷输入管理中搜索只出现于某项内容的关键词
- **THEN** 系统显示该项及其名称和内容摘要，即使名称不包含该关键词

### Requirement: 从活动终端搜索并插入快捷输入
系统 MUST 在每个活动终端的工具栏提供快捷输入入口。入口的悬停提示和无障碍标签 MUST 展示 `Ctrl+Shift+P`，macOS MUST 展示 `Command+Shift+P`。该组合键仅在终端聚焦时打开选择器，不得成为系统级全局快捷键。

选择器打开后 MUST 自动聚焦搜索输入；未输入搜索词时 MUST 按用户排序显示，输入搜索词时 MUST 同时匹配名称和内容。结果 MUST 显示名称和内容摘要。系统 MUST 支持方向键选择结果、Enter 插入和 Escape 关闭；点击结果与 Enter 的插入行为相同。成功插入后系统 MUST 关闭选择器并将焦点归还给原终端。

#### Scenario: 通过工具栏打开并按排序显示
- **WHEN** 用户点击活动终端工具栏中的快捷输入入口
- **THEN** 系统打开并聚焦选择器，展示按已保存手动顺序排列的名称和内容摘要

#### Scenario: 通过终端快捷键打开
- **WHEN** 活动终端获得焦点且用户按下平台对应的快捷输入组合键
- **THEN** 系统打开该终端的快捷输入选择器，且不将该组合键作为普通输入写入 PTY

#### Scenario: 通过内容搜索并用键盘插入
- **WHEN** 用户输入仅出现在某项内容中的关键词，使用方向键选中结果后按 Enter
- **THEN** 系统向当前终端插入该项完整内容、关闭选择器并将焦点恢复至该终端

#### Scenario: 关闭选择器不写入内容
- **WHEN** 用户在选择器打开时按 Escape
- **THEN** 系统关闭选择器、保持终端焦点，且不向任何 PTY 写入数据

### Requirement: 使用模拟粘贴写入当前终端
系统 MUST 使用当前 xterm 会话的模拟粘贴机制向所选活动终端写入快捷输入完整内容。系统 MUST NOT 在内容前后额外添加换行、Enter 或命令执行字符。系统 MUST NOT 将内容写入其他终端；目标会话已关闭、缺失或写入失败时，系统 MUST 报告错误且不得把内容路由到其他会话。

多行内容在目标 Shell 或终端程序启用 bracketed paste 时 MUST 以该终端协议的粘贴语义传递。系统 MUST NOT 承诺未支持 bracketed paste 的第三方程序不会把内容中的换行当作提交。

#### Scenario: 插入单行内容不追加执行字符
- **WHEN** 用户选择内容为 `git status` 的快捷输入
- **THEN** 系统仅通过模拟粘贴写入 `git status`，且不追加换行或其他执行字符

#### Scenario: 插入多行内容
- **WHEN** 用户选择包含多行文本的快捷输入，且目标程序已启用 bracketed paste
- **THEN** 系统通过 xterm 模拟粘贴将完整文本传给当前终端，使目标程序按粘贴内容处理而非由 TaskAI 额外提交命令

#### Scenario: 目标终端已关闭
- **WHEN** 用户打开选择器后目标终端在选择前关闭
- **THEN** 系统报告该终端不可用，且不得将快捷输入写入其他终端

### Requirement: 明确快捷输入的范围和数据保护边界
系统 MUST 将快捷输入作为本机普通应用数据保存，不得宣称其适合保存密码、令牌或其他机密信息。系统 MUST NOT 在本能力中提供任务专属输入、变量替换、分类、标签、导入导出、同步或预置示例。

#### Scenario: 仅显示全局库内容
- **WHEN** 用户在任意任务的终端中打开快捷输入选择器
- **THEN** 系统只显示同一个全局快捷输入库，不显示或创建任务专属内容
