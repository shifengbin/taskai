## Requirements
### Requirement: 全局生命周期命令管理
系统 SHALL 提供全局生命周期命令库。每个自定义命令 MUST 包含稳定 ID、非空名称、非空可执行命令、逐行参数和至少一个钩子适用范围；名称用于用户识别，ID 用于链引用。系统 SHALL 始终提供“创建任务工作目录”和“删除任务工作目录”两个内置命令，且用户不得编辑或删除它们；创建命令仅适用于 `beforeStart`，删除命令仅适用于 `postEnd`。

#### Scenario: 创建并管理自定义命令
- **WHEN** 用户保存名称、可执行命令和参数均有效的自定义命令
- **THEN** 系统保存该命令并允许后续命令链按 ID 引用它

#### Scenario: 保护系统内置命令
- **WHEN** 用户尝试编辑或删除任一系统内置目录命令
- **THEN** 系统拒绝该操作并保留内置命令的固定定义

#### Scenario: 拒绝删除被链引用的命令
- **WHEN** 用户尝试删除仍被任一命令链引用的自定义命令
- **THEN** 系统拒绝删除并说明该命令仍被引用

### Requirement: 命令链管理和钩子默认值
系统 SHALL 允许用户创建、重命名、复制和删除带有非空名称与至少一个钩子适用范围的命令链。每条链 MUST 保存有序命令引用，且每个引用命令 MUST 覆盖该链的全部适用范围；用户 SHALL 能调整其中命令顺序。系统 SHALL 为 `beforeStart`、`postStart`、`beforeEnd`、`postEnd` 和 `updateTask` 分别保存至多一个默认链，默认链必须适用于对应钩子。

#### Scenario: 复制并调整命令链
- **WHEN** 用户复制一条已有命令链并调整副本中的命令顺序
- **THEN** 系统创建具有新稳定 ID 的链副本，原链顺序保持不变

#### Scenario: 设置钩子默认链
- **WHEN** 用户将链设置为 `postStart` 的默认链
- **THEN** 新建任务表单的 `postStart` 选择器预选该链，其他钩子默认值不受影响

#### Scenario: 删除默认链
- **WHEN** 用户删除只被已完成任务引用且同时被某钩子设为默认值的链
- **THEN** 系统删除该链并清除对应钩子的默认值

### Requirement: 任务保存独立的钩子链选择
任务 SHALL 为五个生命周期钩子分别保存零或一个命令链 ID。新建任务表单 MUST 按钩子仅显示适用链名称选择器，并以当前默认链预选新任务；未执行任务的编辑表单 MUST 允许修改该映射，执行中和已完成任务的编辑表单 MUST 只读展示已保存选择。后端 MUST 拒绝执行中或已完成任务的链选择修改。任务执行或重试链时 MUST 解析该 ID 指向的最新链定义，而非使用任务创建时的链快照。

#### Scenario: 链只显示适用命令
- **WHEN** 用户将命令链范围设置为 `beforeStart` 和 `postStart`
- **THEN** 链编辑器只允许选择同时覆盖这两个钩子的命令

#### Scenario: 默认链和新建任务按范围筛选
- **WHEN** 用户为 `beforeEnd` 配置默认链或在新建任务中选择该钩子的链
- **THEN** 下拉框只显示覆盖 `beforeEnd` 的链

#### Scenario: 未执行任务编辑链选择
- **WHEN** 用户编辑未执行任务并修改某个钩子的命令链
- **THEN** 系统保存该任务新的链选择，且不执行 `updateTask` 钩子

#### Scenario: 执行中或已完成任务保持链选择
- **WHEN** 用户编辑执行中或已完成任务的标题、描述、颜色或额外信息
- **THEN** 系统保留该任务既有的生命周期链选择，界面不允许修改它们，后端也拒绝修改请求

#### Scenario: 新建任务覆盖默认选择
- **WHEN** 新建任务表单为 `postStart` 预选默认链且用户改选另一条链
- **THEN** 保存的任务仅在 `postStart` 保存用户改选的链 ID，其他钩子选择保持各自值

#### Scenario: 编辑链影响已选择任务
- **WHEN** 任务已经选择某条链且用户随后编辑该链的命令顺序
- **THEN** 该任务下一次执行或重试该钩子时使用更新后的顺序

#### Scenario: 删除链保护可运行任务
- **WHEN** 用户尝试删除被未执行或执行中任务引用的链
- **THEN** 系统拒绝删除该链

### Requirement: 生命周期钩子时序和状态保护
系统 SHALL 在开始任务的状态变更前运行 `beforeStart`，并在状态变更为执行中后运行 `postStart`。系统 SHALL 在结束任务的状态变更前运行 `beforeEnd`，并在状态变更为已完成后运行 `postEnd`。系统 SHALL 仅在执行中任务成功保存修改后运行 `updateTask`；未执行和已完成任务修改时不得运行该钩子。

#### Scenario: beforeStart 失败阻止开始
- **WHEN** 未执行任务的 `beforeStart` 链失败
- **THEN** 任务状态保持未执行且系统显示该链失败状态

#### Scenario: postStart 失败不回滚开始
- **WHEN** 任务已变更为执行中后其 `postStart` 链失败
- **THEN** 任务保持执行中且系统显示该链失败状态

#### Scenario: beforeEnd 失败阻止结束
- **WHEN** 执行中任务的 `beforeEnd` 链失败
- **THEN** 任务保持执行中且系统不得关闭终端或标记任务完成

#### Scenario: postEnd 失败不回滚结束
- **WHEN** 任务已变更为已完成后其 `postEnd` 链失败
- **THEN** 任务保持已完成且系统显示该链失败状态

#### Scenario: 仅执行中任务触发 updateTask
- **WHEN** 用户保存执行中任务的修改
- **THEN** 系统先保存修改结果，再执行该任务的 `updateTask` 链

#### Scenario: 未执行任务修改不触发 updateTask
- **WHEN** 用户保存未执行任务的修改
- **THEN** 系统保存修改结果且不运行 `updateTask` 链

### Requirement: 命令链上下文与标准输入输出
系统 SHALL 将任务详情 HTTP 响应结构编码为首命令的标准输入；HTTP 服务正在运行时，系统 MUST 在该对象顶层增加状态 API 基址 `baseURL`。系统 SHALL 将每条命令的标准输出原样作为下一条命令的标准输入，且不得解析、合并、追加或恢复字段。命令 MUST 自行产生下一命令所需的输出。

#### Scenario: HTTP 服务可用时传入 baseURL
- **WHEN** 生命周期链开始执行且本机 HTTP 服务正在监听
- **THEN** 首命令输入为任务详情对象，并在顶层包含当前状态 API 基址 `baseURL`

#### Scenario: HTTP 服务未运行时不传入 baseURL
- **WHEN** 生命周期链开始执行且本机 HTTP 服务未运行
- **THEN** 首命令输入不包含 `baseURL`

#### Scenario: 原样传递上一命令输出
- **WHEN** 链中前一命令输出任意字节序列
- **THEN** 系统将该字节序列不经合并或修改地写入下一命令的标准输入

### Requirement: 系统内置目录命令
系统 SHALL 将创建和删除任务工作目录作为可放入任意钩子链的系统内置命令。两个命令 MUST 仅操作当前任务 ID 在任务工作区根目录下的直接子目录，并 MUST 拒绝路径穿越或指向工作区外的符号链接。创建命令遇到目录已存在时 MUST 成功复用，删除命令遇到目录不存在时 MUST 成功结束。

#### Scenario: beforeStart 链创建任务目录
- **WHEN** `beforeStart` 链首先执行创建任务工作目录命令
- **THEN** 系统创建或复用安全的任务专属目录，并让后续命令在该目录执行

#### Scenario: 创建命令排在前序命令之后
- **WHEN** `beforeStart` 链在创建目录命令前执行需要任务目录的外部命令且目录不存在
- **THEN** 前序命令失败，任务保持未执行且系统不隐式创建目录

#### Scenario: postEnd 在工作区根目录运行
- **WHEN** 系统执行 `postEnd` 链中的任意命令
- **THEN** 命令工作目录为任务工作区根目录

#### Scenario: 重试重复执行目录命令
- **WHEN** 用户从链首重试已经创建过目录或已经删除过目录的链
- **THEN** 对应内置命令以成功复用或成功结束的方式继续执行

### Requirement: 运行进度、锁定和重试
系统 SHALL 为每轮生命周期链持久化钩子、链、当前命令进度和失败信息。链开始后直到成功前，系统 MUST 锁定该任务的右键操作、任务操作菜单、编辑、排序和状态变更。链失败时，系统 SHALL 显示失败原因和重试入口；重试 MUST 从当前链的第一个命令执行，并使用最新链定义。

#### Scenario: 显示当前命令进度
- **WHEN** 链正在执行第 2 个命令
- **THEN** 任务界面显示当前钩子、该命令名称及其在链中的序号

#### Scenario: 链失败后保持任务锁定
- **WHEN** 生命周期链执行失败
- **THEN** 任务操作持续不可用，仅显示允许重新执行该链的重试入口

#### Scenario: 重试从链首开始
- **WHEN** 用户对在第 2 个命令失败的链点击重试
- **THEN** 系统从该链第 1 个命令开始执行并重新读取链的最新定义

#### Scenario: 已完成任务的失败链已删除
- **WHEN** 已完成任务的 `postEnd` 链失败且该链随后被删除
- **THEN** 用户重试时系统提示命令链已删除且不得改变任务完成状态

### Requirement: 旧任务数据兼容
系统 SHALL 兼容不含生命周期命令链字段的既有设置和任务快照。加载旧数据时，系统 MUST 补齐系统内置目录命令、初始目录链、五钩子默认映射、任务链选择和空执行记录。

#### Scenario: 迁移既有未执行任务
- **WHEN** 系统加载不含链选择字段的未执行任务
- **THEN** 系统为其预选默认创建目录链和默认删除目录链

#### Scenario: 迁移既有执行中任务
- **WHEN** 系统加载不含链选择字段的执行中任务
- **THEN** 系统为其预选默认删除目录链且不重新创建任务目录

#### Scenario: 迁移既有已完成任务
- **WHEN** 系统加载不含链选择字段的已完成任务
- **THEN** 系统保留其五个钩子选择为空且不创建或删除任何目录
