## Requirements
### Requirement: 全局生命周期命令管理
系统 SHALL 提供全局生命周期命令库。每个自定义命令 MUST 包含稳定 ID、非空名称、非空可执行命令、逐行参数和至少一个钩子适用范围；名称用于用户识别，ID 用于链引用。系统 SHALL 始终提供“创建任务工作目录”和“删除任务工作目录”两个内置命令，且用户不得编辑或删除它们；创建命令仅适用于 `beforeStart`，删除命令仅适用于 `postEnd`。

#### Scenario: 创建并管理自定义命令
- **WHEN** 用户保存名称、可执行命令和参数均有效的自定义命令
- **THEN** 系统保存该命令并允许后续命令链按 ID 引用它

#### Scenario: 保护系统内置命令
- **WHEN** 用户尝试编辑或删除任一系统内置目录命令
- **THEN** 系统拒绝该操作并保留内置命令的固定定义

#### Scenario: 拒绝删除被链引用的命令
- **WHEN** 用户尝试删除仍被任一命令链引用的自定义命令
- **THEN** 系统拒绝删除并说明该命令仍被引用

### Requirement: 命令链管理和生命周期预设
系统 SHALL 允许用户创建、重命名、复制和删除带有非空名称与至少一个钩子适用范围的命令链。每条链 MUST 保存有序命令引用，且每个引用命令 MUST 覆盖该链的全部适用范围；用户 SHALL 能调整其中命令顺序。系统 MUST 拒绝删除仍被任一生命周期预设引用的链，也 MUST 拒绝将链的适用范围缩小到不能覆盖任一预设引用钩子的修改。

#### Scenario: 复制并调整命令链
- **WHEN** 用户复制一条已有命令链并调整副本中的命令顺序
- **THEN** 系统创建具有新稳定 ID 的链副本，原链顺序保持不变

#### Scenario: 拒绝删除被预设引用的链
- **WHEN** 用户尝试删除仍被一个或多个命令链预设引用的命令链
- **THEN** 系统拒绝删除并说明该命令链仍被预设引用

#### Scenario: 拒绝缩小被预设引用链的适用范围
- **WHEN** 用户编辑命令链并移除一个仍被预设引用的钩子适用范围
- **THEN** 系统拒绝保存该修改并保留原命令链定义

### Requirement: 生命周期预设管理
系统 SHALL 提供名称非空、大小写不重复且具有稳定 ID 的生命周期命令链预设。每个预设 MUST 为零至五个生命周期钩子保存命令链 ID，且每个非空引用 MUST 指向存在并适用于对应钩子的链。系统 SHALL 允许创建、重命名、复制和删除预设，并允许选择零或一个默认预设；删除当前默认预设 MUST 清除默认选择。预设空映射和空默认选择均为有效配置。

#### Scenario: 保存并复制预设
- **WHEN** 用户保存名称有效、链引用均适用于相应钩子的预设，随后复制该预设
- **THEN** 系统保存原预设并创建具有新稳定 ID 和独立钩子映射的副本

#### Scenario: 设置或清除默认预设
- **WHEN** 用户选择一个现有预设作为默认预设，或随后清除默认选择
- **THEN** 系统相应保存该预设 ID 或空 ID，且不修改预设内容、命令链或任务选择

#### Scenario: 删除当前默认预设
- **WHEN** 用户删除当前默认预设
- **THEN** 系统删除该预设并清除默认预设 ID，新建任务不再自动获得该预设的映射

#### Scenario: 拒绝无效预设引用
- **WHEN** 用户保存引用了不存在链或不覆盖目标钩子的预设
- **THEN** 系统拒绝保存，且不产生部分配置变更

### Requirement: 任务保存独立的钩子链选择
任务 SHALL 为五个生命周期钩子分别保存零或一个命令链 ID。新建任务表单 MUST 从当前默认预设的完整映射初始化；用户 SHALL 能选择任一预设以替换全部钩子选择，然后按钩子仅从适用链名称中独立调整。预设省略的钩子 MUST 清空该钩子的选择。新建任务保存时 MUST 持久化当前展开后的完整映射，包括显式空映射，而不得持久化预设 ID。未执行任务的编辑表单 MUST 允许修改该映射，执行中和已完成任务的编辑表单 MUST 只读展示已保存选择。后端 MUST 拒绝执行中或已完成任务的链选择修改。任务执行或重试链时 MUST 解析该 ID 指向的最新链定义，而非使用任务创建时的链快照。

#### Scenario: 链只显示适用命令
- **WHEN** 用户将命令链范围设置为 `beforeStart` 和 `postStart`
- **THEN** 链编辑器只允许选择同时覆盖这两个钩子的命令

#### Scenario: 预设和任务按范围筛选
- **WHEN** 用户在预设或任务中为 `beforeEnd` 选择命令链
- **THEN** 下拉框只显示覆盖 `beforeEnd` 的链

#### Scenario: 未执行任务编辑链选择
- **WHEN** 用户编辑未执行任务并修改某个钩子的命令链
- **THEN** 系统保存该任务新的链选择，且不执行 `updateTask` 钩子

#### Scenario: 执行中或已完成任务保持链选择
- **WHEN** 用户编辑执行中或已完成任务的标题、描述、颜色或额外信息
- **THEN** 系统保留该任务既有的生命周期链选择，界面不允许修改它们，后端也拒绝修改请求

#### Scenario: 默认预设初始化新任务
- **WHEN** 用户打开新建任务表单且设置了默认预设
- **THEN** 表单为全部五个钩子预选该预设完整映射中的选择

#### Scenario: 选择预设替换全部钩子
- **WHEN** 用户在新建任务表单中选择另一个预设
- **THEN** 系统以该预设的完整映射替换所有五个钩子选择，并清空新预设未包含的钩子

#### Scenario: 单独调整后成为自定义
- **WHEN** 用户在已应用预设的任务表单中改选任一钩子的命令链
- **THEN** 表单显示“自定义”预设状态，且保存该用户调整后的完整映射

#### Scenario: 显式清空不回退默认预设
- **WHEN** 用户清空新建任务的全部五个钩子选择并保存
- **THEN** 任务保存空映射，且不得重新应用默认预设

#### Scenario: 预设改动不影响已创建任务
- **WHEN** 任务已从预设保存其钩子映射，用户随后编辑或删除该预设
- **THEN** 该任务保存的钩子映射保持不变

#### Scenario: 编辑链影响已选择任务
- **WHEN** 任务已经选择某条链且用户随后编辑该链的命令顺序
- **THEN** 该任务下一次执行或重试该钩子时使用更新后的顺序

#### Scenario: 删除链保护可运行任务
- **WHEN** 用户尝试删除被未执行或执行中任务引用的链
- **THEN** 系统拒绝删除该链

### Requirement: 生命周期钩子时序和状态保护
系统 SHALL 在开始任务的状态变更前运行 `beforeStart`，并在状态变更为执行中后运行 `postStart`。系统 SHALL 在结束任务的状态变更前运行 `beforeEnd`，并在状态变更为已完成后运行 `postEnd`。系统 SHALL 仅在执行中任务成功保存修改后运行 `updateTask`；未执行和已完成任务修改时不得运行该钩子。

#### Scenario: beforeStart 失败阻止开始
- **WHEN** 未执行任务的 `beforeStart` 链失败
- **THEN** 任务状态保持未执行且系统显示该链失败状态

#### Scenario: postStart 失败不回滚开始
- **WHEN** 任务已变更为执行中后其 `postStart` 链失败
- **THEN** 任务保持执行中且系统显示该链失败状态

#### Scenario: beforeEnd 失败阻止结束
- **WHEN** 执行中任务的 `beforeEnd` 链失败
- **THEN** 任务保持执行中且系统不得关闭终端或标记任务完成

#### Scenario: postEnd 失败不回滚结束
- **WHEN** 任务已变更为已完成后其 `postEnd` 链失败
- **THEN** 任务保持已完成且系统显示该链失败状态

#### Scenario: 仅执行中任务触发 updateTask
- **WHEN** 用户保存执行中任务的修改
- **THEN** 系统先保存修改结果，再执行该任务的 `updateTask` 链

#### Scenario: 未执行任务修改不触发 updateTask
- **WHEN** 用户保存未执行任务的修改
- **THEN** 系统保存修改结果且不运行 `updateTask` 链

### Requirement: 命令链上下文与标准输入输出
系统 SHALL 将任务详情 HTTP 响应结构编码为首命令的标准输入；HTTP 服务正在运行时，系统 MUST 在该对象顶层增加状态 API 基址 `baseURL`。系统 SHALL 将每条命令的标准输出原样作为下一条命令的标准输入，且不得解析、合并、追加或恢复字段。命令 MUST 自行产生下一命令所需的输出。

#### Scenario: HTTP 服务可用时传入 baseURL
- **WHEN** 生命周期链开始执行且本机 HTTP 服务正在监听
- **THEN** 首命令输入为任务详情对象，并在顶层包含当前状态 API 基址 `baseURL`

#### Scenario: HTTP 服务未运行时不传入 baseURL
- **WHEN** 生命周期链开始执行且本机 HTTP 服务未运行
- **THEN** 首命令输入不包含 `baseURL`

#### Scenario: 原样传递上一命令输出
- **WHEN** 链中前一命令输出任意字节序列
- **THEN** 系统将该字节序列不经合并或修改地写入下一命令的标准输入

### Requirement: 系统内置目录命令
系统 SHALL 将创建和删除任务工作目录作为可放入任意钩子链的系统内置命令。两个命令 MUST 仅操作当前任务 ID 在任务工作区根目录下的直接子目录，并 MUST 拒绝路径穿越或指向工作区外的符号链接。创建命令遇到目录已存在时 MUST 成功复用，删除命令遇到目录不存在时 MUST 成功结束。

#### Scenario: beforeStart 链创建任务目录
- **WHEN** `beforeStart` 链首先执行创建任务工作目录命令
- **THEN** 系统创建或复用安全的任务专属目录，并让后续命令在该目录执行

#### Scenario: 创建命令排在前序命令之后
- **WHEN** `beforeStart` 链在创建目录命令前执行需要任务目录的外部命令且目录不存在
- **THEN** 前序命令失败，任务保持未执行且系统不隐式创建目录

#### Scenario: postEnd 在工作区根目录运行
- **WHEN** 系统执行 `postEnd` 链中的任意命令
- **THEN** 命令工作目录为任务工作区根目录

#### Scenario: 重试重复执行目录命令
- **WHEN** 用户从链首重试已经创建过目录或已经删除过目录的链
- **THEN** 对应内置命令以成功复用或成功结束的方式继续执行

### Requirement: 运行进度、锁定和重试
系统 SHALL 为每轮生命周期链持久化钩子、链、当前命令进度和失败信息。链开始后直到成功前，系统 MUST 锁定该任务的右键操作、任务操作菜单、编辑、排序和状态变更。链失败时，系统 SHALL 显示失败原因和重试入口；重试 MUST 从当前链的第一个命令执行，并使用最新链定义。

#### Scenario: 显示当前命令进度
- **WHEN** 链正在执行第 2 个命令
- **THEN** 任务界面显示当前钩子、该命令名称及其在链中的序号

#### Scenario: 链失败后保持任务锁定
- **WHEN** 生命周期链执行失败
- **THEN** 任务操作持续不可用，仅显示允许重新执行该链的重试入口

#### Scenario: 重试从链首开始
- **WHEN** 用户对在第 2 个命令失败的链点击重试
- **THEN** 系统从该链第 1 个命令开始执行并重新读取链的最新定义

#### Scenario: 已完成任务的失败链已删除
- **WHEN** 已完成任务的 `postEnd` 链失败且该链随后被删除
- **THEN** 用户重试时系统提示命令链已删除且不得改变任务完成状态

### Requirement: 旧任务数据兼容
系统 SHALL 兼容不含生命周期命令链字段的既有设置和任务快照。加载旧数据时，系统 MUST 补齐系统内置目录命令、初始目录链、默认生命周期预设、任务链选择和空执行记录。旧任务缺少链选择时，系统 MUST 从解析出的默认预设映射按任务状态应用既有的范围规则。

#### Scenario: 迁移既有未执行任务
- **WHEN** 系统加载不含链选择字段的未执行任务
- **THEN** 系统为其应用默认预设中的创建目录链和删除目录链选择

#### Scenario: 迁移既有执行中任务
- **WHEN** 系统加载不含链选择字段的执行中任务
- **THEN** 系统为其应用默认预设中的删除目录链选择且不重新创建任务目录

#### Scenario: 迁移既有已完成任务
- **WHEN** 系统加载不含链选择字段的已完成任务
- **THEN** 系统保留其五个钩子选择为空且不创建或删除任何目录

### Requirement: 空链任务的交互操作目录
系统 SHALL 为执行中且未选择任何生命周期命令链的任务，将当前用户的 Home 目录用作任务级交互操作的工作目录。该规则适用于新增 Shell 终端、新增命令终端、直接任务命令、任务菜单自定义命令及其前置和后置脚本，以及“打开任务文件夹”。系统 MUST 在启动操作前确认 Home 路径可用且为目录；无法获取、访问或确认该目录时，系统 MUST 拒绝该操作并报告错误。系统 MUST NOT 为此类任务隐式创建任务工作目录，也 MUST NOT 将 Home 目录写入任务的工作区根目录或工作目录快照。

#### Scenario: 空链任务新增终端
- **WHEN** 执行中任务的五个生命周期钩子均未选择命令链，用户新增 Shell 终端或命令终端
- **THEN** 系统在当前用户的 Home 目录启动对应终端，且不创建任务工作目录

#### Scenario: 空链任务运行菜单命令和脚本
- **WHEN** 执行中任务未选择任何生命周期命令链，用户从任务菜单运行自定义命令
- **THEN** 系统在当前用户的 Home 目录运行该命令及其配置的前置和后置脚本

#### Scenario: 空链任务打开文件夹
- **WHEN** 执行中任务未选择任何生命周期命令链，用户选择“打开任务文件夹”
- **THEN** 系统打开当前用户的 Home 目录，且不创建任务工作目录

#### Scenario: Home 目录不可用
- **WHEN** 执行中任务未选择任何生命周期命令链，且当前用户的 Home 目录无法获取、访问或不是目录
- **THEN** 系统拒绝相应的终端、命令或目录打开操作并报告错误，且不得启动部分操作

### Requirement: 已选链任务保留工作目录语义
系统 SHALL 对至少选择了一条生命周期命令链的执行中任务继续使用持久化的任务工作目录作为任务级交互操作目录。任务工作目录不存在、不是目录或无法访问时，系统 MUST 保留既有失败行为，且 MUST NOT 回退到当前用户的 Home 目录。

#### Scenario: 已选链任务的目录不可用
- **WHEN** 执行中任务至少选择了一条生命周期命令链，但其任务工作目录不存在、不是目录或无法访问
- **THEN** 系统拒绝对应的终端、命令或目录打开操作并报告任务工作目录错误，且不得改用当前用户的 Home 目录

#### Scenario: 生命周期命令不使用 Home 回退
- **WHEN** 系统执行任意生命周期钩子中的命令
- **THEN** 系统继续按该钩子的既有任务工作区规则执行，不得因任务链选择为空而将命令目录改为当前用户的 Home 目录

### Requirement: 新安装默认提供公司框架预设
系统 SHALL 在没有持久化数据的新安装中同时创建“默认预设”和“公司框架”两个生命周期命令链预设，并 MUST 将“公司框架”设为默认预设。“公司框架” MUST 使用稳定 ID，其 `beforeStart` MUST 选择 `iterations-ai`，`postEnd` MUST 选择“删除任务工作目录”，`updateTask` MUST 选择稳定仓库更新链，`postStart` 与 `beforeEnd` MUST 保持为空。“默认预设” MUST 继续保留原有创建和删除任务工作目录的映射。两个预设 MUST 继续作为普通预设参与现有编辑、复制、删除和引用校验，任务 MUST 只保存展开后的链映射。

#### Scenario: 新安装生成两个预设并默认选择公司框架
- **WHEN** 用户首次启动且应用数据目录中不存在持久化数据文件
- **THEN** 设置包含“默认预设”和“公司框架”，默认预设 ID 指向“公司框架”，且公司框架仅在开始前、结束后和任务更新三个钩子保存指定命令链

#### Scenario: 新任务自动使用公司框架
- **WHEN** 新安装用户打开新建任务表单
- **THEN** 表单选择“公司框架”，开始前显示 `iterations-ai`，结束后显示“删除任务工作目录”，任务更新显示“更新框架仓库”，开始后和结束前显示不执行命令链

#### Scenario: 新任务保存展开后的公司框架映射
- **WHEN** 新安装用户保持默认选择并创建未执行任务，随后重新编辑该任务
- **THEN** 任务保存并重新显示公司框架对应的三个链 ID，而不保存或依赖公司框架预设 ID

#### Scenario: 已有设置不注入公司框架
- **WHEN** 应用加载已经存在的持久化设置，无论其中是否已有生命周期预设或默认预设选择
- **THEN** 系统不得因本次变更新增“公司框架”、切换默认预设或改写已有预设内容

#### Scenario: 公司框架仍可由用户管理
- **WHEN** 新安装用户编辑、复制或删除“公司框架”预设
- **THEN** 系统使用现有普通预设规则保存操作，删除当前默认的公司框架时清空默认预设 ID，且不修改已创建任务的链映射
