# terminal-mouse-clipboard-policy Specification

## Purpose

定义所有活动终端统一的鼠标手势分流、选区自动复制和右键粘贴行为，使本地选择与终端程序鼠标协议可以同时使用。

## Requirements

### Requirement: 所有活动终端统一分流鼠标操作

系统 MUST 对所有活动终端使用同一套鼠标规则，不得根据终端来源、启动命令或既有 `disableTaskAIMouseClipboard` 数据改变行为。前端 MUST 接管左键文本选择和右键粘贴；未构成文本选择的左键单击以及滚轮、中键和其他未被前端接管的鼠标操作 MUST 继续交给 xterm，并仅在终端程序当前启用的鼠标协议要求时写入对应终端。

#### Scenario: 开启鼠标追踪的终端收到单击

- **WHEN** 终端程序已开启鼠标追踪，用户完成一次未移动、未形成双击或三击的左键单击
- **THEN** 前端在判定手势为单击后仅向当前 xterm 重放一次按下和松开，xterm 按当前鼠标协议将该单击写入对应终端

#### Scenario: 普通 Shell 单击不产生多余输入

- **WHEN** 终端程序未开启鼠标追踪，用户完成一次未形成选择的左键单击
- **THEN** 前端将该单击交给 xterm，且不得向 PTY 写入终端程序未请求的鼠标数据

#### Scenario: 滚轮和其他鼠标操作保持终端行为

- **WHEN** 用户在没有待判定左键手势时使用滚轮、中键或其他未被前端接管的鼠标操作
- **THEN** 前端不把该操作转换为文本选区，xterm 按当前终端模式处理该操作

### Requirement: 左键选择手势只创建本地选区

系统 MUST 在 xterm 处理前区分左键单击与选择手势。移动超过选择阈值的拖拽 MUST 创建范围选区，双击 MUST 选择单词，三击 MUST 选择整行；这三类手势从第一次按下至最终松开的左键事件 MUST 只用于 xterm 本地选择，不得作为鼠标输入写入终端程序。该规则 MUST 在终端程序未开启或已经开启鼠标追踪时保持一致。

#### Scenario: 鼠标追踪期间拖拽选择范围

- **WHEN** 终端程序已开启鼠标追踪，用户按住左键并移动超过选择阈值后松开
- **THEN** xterm 形成从起点到终点的本地文本选区，整次拖拽的按下、移动和松开均不写入终端程序

#### Scenario: 双击选择单词

- **WHEN** 用户在活动终端文本上完成双击
- **THEN** xterm 按终端单词边界选择当前位置的完整单词，两次点击均不写入终端程序

#### Scenario: 三击选择整行

- **WHEN** 用户在活动终端文本上完成三击
- **THEN** xterm 选择当前位置的完整终端行，三次点击均不写入终端程序

#### Scenario: 阈值内移动仍判定为单击

- **WHEN** 用户按下左键后的移动未超过选择阈值，并且未形成双击或三击
- **THEN** 前端不得创建文本选区，并在多击判定结束后把该操作作为一次单击交给 xterm

### Requirement: 所有活动终端统一自动复制和右键粘贴

系统 MUST 在任何活动终端产生非空 xterm 本地选区时，将完整选区写入系统剪贴板。用户在任何活动终端中点击右键时，系统 MUST 阻止浏览器上下文菜单，读取系统剪贴板，并仅通过当前 xterm 会话的模拟粘贴机制写入非空内容；右键事件不得另行发送给终端程序。键盘输入、终端输出和文件拖放 MUST 保持原有行为。

#### Scenario: 鼠标追踪期间选择后自动复制

- **WHEN** 终端程序已开启鼠标追踪，用户通过拖拽、双击或三击形成非空本地选区
- **THEN** 系统把选区原文写入系统剪贴板，不要求用户执行额外复制操作

#### Scenario: 鼠标追踪期间移动鼠标保留选区

- **WHEN** 终端程序启用了无按键鼠标移动追踪，用户形成非空本地选区后仅移动鼠标
- **THEN** xterm 继续把鼠标移动交给当前终端程序，同时保持同一份本地选区和备注入口可用

#### Scenario: 鼠标追踪期间右键粘贴

- **WHEN** 终端程序已开启鼠标追踪，用户在活动终端中点击右键且系统剪贴板包含非空文本
- **THEN** 系统阻止上下文菜单并把文本模拟粘贴到当前终端，不把右键鼠标事件发送给终端程序或其他会话

#### Scenario: 空剪贴板右键不写入

- **WHEN** 用户在活动终端点击右键且系统剪贴板为空或读取失败
- **THEN** 系统不向任何终端写入文本，并保持当前终端可继续交互
