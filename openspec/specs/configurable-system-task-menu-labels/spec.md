# configurable-system-task-menu-labels Specification

## Purpose
定义系统任务菜单项的可配置显示名称、排序及旧配置兼容行为。
## Requirements
### Requirement: 配置系统任务菜单项的显示名称

系统 MUST 将编辑任务、新增终端、打开任务文件夹和搁置切换作为具有稳定标识的系统任务菜单项保存。系统 MUST 允许用户分别修改所有系统项的显示名称，并保持每个系统项的固定操作类型和行为。搁置切换 MUST 分别保存未搁置任务的名称和已搁置任务的名称，默认值分别为“搁置任务”和“取消搁置”。

#### Scenario: 保存普通系统项的自定义名称
- **WHEN** 用户在菜单管理中将“编辑任务”改为非空名称并保存设置
- **THEN** 系统持久化该名称，右键菜单和“任务操作”下拉菜单均显示该自定义名称，且该项仍只打开任务编辑界面

#### Scenario: 保存搁置切换的两种名称
- **WHEN** 用户分别填写未搁置和已搁置任务的非空名称并保存设置
- **THEN** 系统持久化两种名称，未搁置执行中任务显示前者，已搁置执行中任务显示后者

#### Scenario: 拒绝空白系统项名称
- **WHEN** 用户保存任一仅含空白字符的系统项名称，或保存任一仅含空白字符的搁置切换名称
- **THEN** 系统拒绝保存并保留此前已持久化的设置

### Requirement: 系统菜单项保持可排序且受保护

系统 MUST 允许用户将任意系统菜单项与自定义菜单项一起排序。系统 MUST 不允许系统项被删除或改为自定义命令，且 MUST 忽略其命令、参数、终端和前后置脚本字段。菜单管理中普通系统项 MUST 仅显示一个名称编辑入口；搁置切换 MUST 显示两种名称编辑入口。

#### Scenario: 排序搁置切换
- **WHEN** 用户在菜单管理中移动搁置切换系统项并保存设置
- **THEN** 该项在执行中任务的右键菜单和“任务操作”下拉菜单中按已保存顺序显示

#### Scenario: 编辑系统项时不暴露命令配置
- **WHEN** 用户编辑任一系统任务菜单项
- **THEN** 界面不提供命令、参数、终端、前后置脚本或删除控件，且保存后系统项仍保留原有固定操作

### Requirement: 兼容既有任务菜单配置

系统 MUST 在读取或保存菜单配置时补齐缺少的系统菜单项。仅含原有三个系统项的配置 MUST 保留其顺序和已保存名称，并在末尾追加带默认两种名称的搁置切换项。空菜单配置 MUST 返回完整的默认系统菜单列表。

#### Scenario: 升级旧的三项菜单配置
- **WHEN** 系统读取仅包含编辑任务、新增终端和打开任务文件夹的既有菜单配置
- **THEN** 系统保留三项的顺序和名称，并在列表末尾补充默认的搁置切换项

#### Scenario: 加载没有菜单配置的旧设置
- **WHEN** 系统读取未保存任务菜单配置的旧设置
- **THEN** 系统提供包含四个系统项及其默认名称的完整菜单列表
