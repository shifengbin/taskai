# terminal-font-selection Specification

## Purpose
定义终端字体的系统发现、等宽筛选、设置选择与预览，以及持久化后仅让新建终端会话使用已保存字体的行为。

## Requirements

### Requirement: 发现终端可用系统字体

系统 SHALL 按当前操作系统发现已安装的终端字体族，并只返回等宽或双宽 spacing 的字体候选。系统 MUST 对字体族名称去重并稳定排序；发现失败或结果为空时 MUST 返回一个代表当前默认等宽字体回退栈的内置选项。

#### Scenario: 返回等宽和双宽字体

- **WHEN** 字体发现接口在支持平台上成功读取系统字体信息
- **THEN** 返回结果包含等宽字体和终端可用的双宽字体，不包含普通比例字体，且同一字体族只出现一次

#### Scenario: 字体发现失败时仍可使用设置

- **WHEN** 当前平台的字体 API、字体配置工具或字体信息读取失败
- **THEN** 接口返回内置默认字体选项，设置页面仍可打开、选择和保存，不阻断终端创建

### Requirement: 设置中预览和选择终端字体

系统 SHALL 在设置中提供终端字体选择区域。每个候选 MUST 显示字体族名称，并使用该字体渲染中文、英文和常见终端字符预览；用户 MUST 能选择默认回退栈或一个已发现的字体族。

#### Scenario: 查看字体预览

- **WHEN** 用户打开终端字体设置
- **THEN** 页面显示可滚动的字体选项，每个选项同时包含中文预览、英文预览和终端字符预览，且选中项有明确状态

#### Scenario: 选择字体但取消设置

- **WHEN** 用户选择字体后关闭设置并取消保存
- **THEN** 当前持久化设置不改变，新创建的终端继续使用保存前的字体

### Requirement: 持久化终端字体设置

系统 SHALL 将选中的字体族名称保存到普通设置的 `terminalFontFamily` 字段。缺少该字段的既有设置 MUST 按空值加载并使用当前默认字体回退栈；已保存但后来不可用的字体 MUST 不阻止设置加载或保存。

#### Scenario: 保存并重新打开设置

- **WHEN** 用户选择一个系统字体并保存设置，随后重新打开设置
- **THEN** 设置显示该字体为当前选项，且普通设置中的其他字段保持不变

#### Scenario: 加载缺少字体字段的旧设置

- **WHEN** 系统加载没有 `terminalFontFamily` 字段的既有设置文件
- **THEN** 字体设置按空值归一化，界面和新终端使用当前默认字体回退栈

#### Scenario: 已保存字体不可用

- **WHEN** 设置中保存的字体族已被系统移除或当前 WebView 无法加载
- **THEN** 设置仍能加载和保存，终端使用 CSS 等宽回退字体，不产生字体配置错误

### Requirement: 新终端使用已保存字体

系统 SHALL 在创建新的 xterm 会话时读取最新的 `terminalFontFamily` 设置，并将其解析为带默认回退栈的 CSS `fontFamily`。已存在的 xterm 会话 MUST 保持创建时的字体，不得因保存设置而修改或触发 PTY 尺寸变化。

#### Scenario: 保存字体后创建新终端

- **WHEN** 用户保存字体设置并创建一个新终端
- **THEN** 新终端使用所选字体族，缺少字形的字符按默认回退栈显示

#### Scenario: 输出先于视图挂载

- **WHEN** 新终端在右侧视图挂载前收到输出并创建 xterm 会话
- **THEN** 该会话仍使用保存设置中的字体，而不是固定硬编码的旧字体栈

#### Scenario: 已有终端不被重新布局

- **WHEN** 用户保存新的终端字体且已有终端会话仍处于活动状态
- **THEN** 已有终端保持原字体、滚屏内容和 PTY 行列尺寸不变
