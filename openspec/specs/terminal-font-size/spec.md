# terminal-font-size Specification

## Purpose
定义全局终端字号的持久化设置、界面控制与预览，以及保存后对现有和后续终端会话的显示、网格尺寸同步行为。

## Requirements

### Requirement: 持久化全局终端字号

系统 SHALL 将全局终端字号保存为普通设置中的 `terminalFontSize` 整数像素值。默认字号 MUST 为 13px；系统 MUST 只接受 10px 至 24px 的值，并将缺失或超出范围的值归一化到该范围内的有效值。字号设置 MUST 与终端字体族设置相互独立。

#### Scenario: 加载缺少字号字段的旧设置

- **WHEN** 系统加载不包含 `terminalFontSize` 的既有设置文件
- **THEN** 设置和新终端均使用 13px，且其他设置保持不变

#### Scenario: 保存超出支持范围的字号

- **WHEN** 保存的字号小于 10px 或大于 24px
- **THEN** 系统将其归一化为最近的支持边界，并保存有效字号

### Requirement: 设置页提供可理解的终端字号控制

系统 SHALL 在终端字体设置区域提供 10px 至 24px、步长为 1px 的终端字号滑块。系统 MUST 显示当前草稿的像素值和相对于 13px 默认字号的四舍五入比例，并 MUST 提供将草稿恢复为 13px 的操作。终端字体预览 MUST 使用当前草稿的字体族和字号渲染中文、英文与终端字符。

#### Scenario: 调整字号时查看数值和预览

- **WHEN** 用户将字号滑块从 13px 调整到 16px
- **THEN** 设置页显示 `16 px（123%）`，且所有字体预览以 16px 渲染

#### Scenario: 恢复默认字号

- **WHEN** 用户在设置中点击恢复默认字号操作
- **THEN** 字号草稿变为 13px，设置页显示 `13 px（100%）`，预览随之更新

#### Scenario: 取消字号修改

- **WHEN** 用户修改字号草稿后取消或关闭设置而未保存
- **THEN** 已持久化字号和活动终端的字号均不改变

### Requirement: 保存的字号全局作用于终端会话

系统 SHALL 在保存 `terminalFontSize` 后将新字号应用到所有已有 xterm 会话，并让之后创建的 xterm 会话使用该字号。当前可见终端 MUST 使用新字号重新适配网格，并将新的行列尺寸同步到对应 PTY；系统 MUST 保留该会话的滚屏内容和输入状态。没有可见内容容器的后台终端 MUST 在下次显示时按新字号适配网格并同步 PTY 尺寸。

#### Scenario: 保存字号后更新当前终端

- **WHEN** 用户保存新的终端字号且当前存在活动终端视图
- **THEN** 当前终端立即以新字号显示，滚屏内容保持可见，并且 PTY 收到与重新适配网格一致的行列尺寸

#### Scenario: 保存字号后切换到后台终端

- **WHEN** 用户保存新字号时另一个活动终端未显示，随后切换到该终端
- **THEN** 该终端以新字号显示并在可见容器中重新适配，PTY 收到对应行列尺寸，且其已有输出未被重置

#### Scenario: 在视图挂载前创建新终端

- **WHEN** 新终端先收到输出而在右侧视图挂载前创建 xterm 会话
- **THEN** 该会话从创建时起使用已保存的全局字号，并在首次挂载时按该字号适配网格
