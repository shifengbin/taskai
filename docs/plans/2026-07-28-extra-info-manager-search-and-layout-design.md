# 额外信息管理检索与布局设计

## 目标

在不改变模板、信息和任务快照的数据结构前提下，收敛额外信息的日常操作界面：信息按所属模板分组、分类可折叠、Git 默认展开；新建信息始终先选模板；管理页与任务选取页均可按信息 `name` 模糊检索。

## 管理页

- 信息管理区域以模板为分组单元，采用折叠面板展示。每个面板标题显示模板展示名称、分类键和该组信息数量。
- 首次打开时 Git 模板默认展开，其他模板默认收起；搜索有命中时，对应分组自动展开。
- 搜索框只匹配信息的 `name` 值，不改变保存的数据，也不匹配固定字段或动态参数。搜索时只展示有命中的分组；无命中时显示空状态。
- 保留独立的“新增信息”入口。点击后先在对话框选择模板，选定后才渲染该模板的固定字段及默认值。编辑既有信息时直接显示其所属模板的固定字段。
- 取消每个模板行内的“新增信息”按钮，避免绕过模板选择步骤。

## 模板参数布局

模板编辑器中的动态参数按响应式网格排列：窄屏单列、宽屏两列字段；必填开关与删除操作独占下一行。这样参数数量增加或窗口缩小时不会挤压、覆盖输入控件。

## 任务信息选择

- 分类选择仍用于切换当前模板范围。
- 分类下新增按 `name` 模糊检索的输入框。切换分类不会清空搜索词，已勾选的信息也不会因检索而取消。
- 候选项和已选标签只显示信息名称。
- 勾选后仅渲染该信息的动态参数；固定字段既不显示也不可编辑。用户仍可在任务快照中增加、修改和删除任务级动态参数。

## 兼容性

接口、持久化格式及任务提交载荷不变。固定字段仍随任务快照保存，只是在任务编辑界面不再展示，以便历史任务和后端校验保持兼容。
