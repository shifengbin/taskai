# 固定两行任务卡片设计

## 目标

任务列表中的每个顶层任务卡片固定为 60px 高。第一行显示任务名称，第二行显示任务描述；描述为空时第二行显示“暂无描述”。

## 方案

- 任务卡片从最小高度改为固定 60px，避免描述有无导致列表跳动。
- 文字容器保留在任务卡片的可收缩主区域中。名称使用参考中的 Hanken Grotesk 800、13.5px；描述使用 Plus Jakarta Sans 500、11.5px，标题与描述相距 1px。
- 名称与描述均采用单行截断，保证操作按钮、命令链进度和状态点的既有位置不变。
- 悬停提示的空描述文案同步为“暂无描述”。

## 验证

`TaskTree` 测试覆盖含描述与空描述任务的两行渲染、固定高度和缺省文案。完成后运行完整前端测试、生产构建、OpenSpec 严格校验和 Linux 打包。
