# 实时终端标题设计

## 目标

在任务树和右侧终端标题栏显示终端程序通过 OSC 0 或 OSC 2 控制序列设置的真实标题，并在标题变化时实时更新。未收到标题时显示“终端”，不再按创建顺序生成“终端 1”等名称。

## 数据流

后端继续原样发布终端输出事件。前端在接收每个终端的输出片段时，为该终端维护独立的流式 OSC 标题状态机；识别到完整的 OSC 0 或 OSC 2 序列后，立即更新 `TerminalRecord.title`。原始输出不会被修改，仍交给 xterm 渲染。

标题序列支持 BEL（`\u0007`）和 ST（`ESC \\`）终止符，并且必须能跨多个输出事件片段连续解析。标题内容超过上限时，状态机进入丢弃模式，并在下一个 `ESC ]` 立即重新同步；这样异常序列不会无限占用内存，也不会吞掉后续有效标题。终端退出后清理该终端的解析状态。

## 界面

任务树的终端子项和右侧终端标题栏优先显示 `title`；标题为空时显示“终端”。xterm 的 `onTitleChange` 只能在对应终端已被渲染时工作，因此不作为全局标题同步来源；输出事件流可让未选中的终端同样实时更新名称。

## 验证

- 为完整及分段到达的 OSC 0/2 标题序列添加状态测试。
- 验证标题变更不会修改终端输出或影响退出状态。
- 验证任务树和终端标题栏显示真实标题，且无标题时回退为“终端”。
- 使用 `scripts/build-linux.sh amd64`、Go 测试、前端测试和生产构建验证。
