# 任务详情模板与环境变量设计

## 目标

在任务详情中补充当前启用任务模板的名称和字段快照，并让用户一眼确认哪些字段会生成生命周期 Shell 命令可用的环境变量。

## 数据来源与边界

- 任务持久化的是 `templateFields` 值，不记录历史模板 ID。
- 详情页使用设置中的当前启用模板解析字段定义与默认值，因此模板名称、显示名、字段类型和注入开关均以当前配置为准。
- 已勾选“注入生命周期环境变量”的模板字段生成 `TASKAI_<字段键大写>`；值按现有领域规则序列化，布尔值为 `true` 或 `false`。
- 这类模板变量只注入自定义生命周期 Shell 命令，不属于终端或前后置脚本的系统环境变量。

## 界面设计

在“额外信息”后、“系统环境变量”前增加“任务模板”区：

1. 展示当前启用模板名称；未启用模板时展示空状态。
2. 按模板字段顺序展示字段显示名、当前解析值及字段键。
3. 已开启环境变量注入的字段显示变量名和作用范围；未开启的字段明确显示“不生成环境变量”。
4. 模板变量与三项系统环境变量保持分区展示，避免误解注入范围。

## 测试

前端测试将覆盖字符串与布尔模板字段、生成与不生成环境变量、模板变量的作用范围以及未启用模板时的空状态。现有任务详情测试继续保证系统变量区不混入模板变量。
