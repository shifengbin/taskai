# 统一终端鼠标选择与备注实施记录

## 目标

让普通 Shell、Claude、Codex 和其他终端程序使用相同的鼠标规则：用户可以用拖拽、双击和三击选择文本、自动复制并添加备注，同时仍可把单击、鼠标移动、滚轮和中键交给终端程序。

## 最终行为

- 所有活动终端统一启用 TaskAI 的本地选择、自动复制、备注入口和右键粘贴，不再按命令提供禁用设置。
- 左键单击在多击判定结束后交给 xterm；xterm 仅在终端程序请求鼠标协议时把它写入 PTY。
- 拖拽、双击和三击分别形成范围、单词和整行本地选区，选择手势不写入终端程序。
- 滚轮、中键和没有按键的鼠标移动继续由 xterm 处理。
- 开启无按键鼠标移动追踪的终端清空选区时，前端使用 xterm 的公开选区坐标恢复同一选区，并校验恢复后的原文一致；键盘输入、粘贴、滚轮、右键或新的鼠标按下会终止旧选区保护。
- 右键由前端读取系统剪贴板，并仅向当前终端执行模拟粘贴。
- `disableTaskAIMouseClipboard` 已从 Go 模型、前端类型、设置界面、终端记录和 Wails 绑定中删除。旧设置 JSON 中的同名字段会被忽略，再次保存后自然消失。

## 实现结构

- `frontend/src/terminal-mouse-gesture.ts` 在 xterm 之前捕获左键序列，判定单击、多击和拖拽，并用内部标记重放受控事件。
- `frontend/src/terminal-session.ts` 按当前会话安装和释放手势处理器，负责自动复制、选区坐标恢复以及会话切换清理。
- `frontend/src/components/TerminalView.tsx` 接收选择完成位置，在终端内容区内显示备注入口，并处理当前会话右键粘贴。
- Go 设置和终端模型只保留统一行为所需数据，不再向终端会话传递鼠标策略快照。

## 集成测试

1. 在功能 worktree 中运行 `wails dev`，从输出取得 `http://localhost:34115`，使用 Chrome DevTools 打开调试页面。
2. 在普通 Shell 中验证单击、拖拽、双击、三击、自动复制、备注原文、备注保存和右键粘贴，确认选择手势不产生 PTY 鼠标输入。
3. 启动真实 Claude，确认 `mouseTrackingMode` 为 `any`；选择文本后连续发送五次无按键鼠标移动，捕获到五条 SGR 鼠标序列。
4. 等待 500 毫秒后确认选区原文和坐标不变，备注入口仍可打开且显示同一原文。
5. 检查页面无相关控制台错误，关闭 `wails dev` 调试进程。
