# 终端选区自动复制设计

## 目标

当用户在嵌入式终端中选中非空文本时，自动将选区写入系统剪贴板，不要求右键或额外按钮操作。

## 方案

在 `TerminalView` 创建 xterm 实例后监听 `onSelectionChange`。每次事件触发时读取 `getSelection()`：

- 文本非空时，调用 Wails Runtime 的 `ClipboardSetText` 写入系统剪贴板。
- 文本为空时不写入，避免清空用户现有剪贴板内容。
- 写入失败时静默忽略，不影响终端输入、选区或其他交互。

监听器和现有数据监听器一样在组件卸载时释放。

## 取舍

- 不监听鼠标事件，因此键盘扩展选区也可自动复制。
- 不使用浏览器 Clipboard API，避免桌面运行环境中的权限和兼容性差异。
- 不增加提示、菜单或配置项，保持终端操作连续。

## 验证

在 `TerminalView` 单元测试中模拟 xterm 选区事件和 Wails 剪贴板 API，验证非空选区被复制、空选区不覆盖剪贴板，并确保监听器会在销毁时释放。
