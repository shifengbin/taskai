# 菜单命令终端的鼠标剪贴板配置设计

## 背景

TaskAI 的嵌入式终端默认会在选中文本后写入系统剪贴板，并在右键时读取系统剪贴板并输入到 PTY。Claude 等终端 TUI 会启用鼠标事件模式，用户可能需要将鼠标交给终端程序本身，而不是由 TaskAI 处理。

## 目标

允许用户在“菜单管理”的自定义显示终端命令中，按命令选择是否禁用 TaskAI 的鼠标复制和右键粘贴。

## 方案

- 为自定义菜单项增加 `disableTaskAIMouseClipboard` 布尔字段，默认值为 `false`。
- 菜单项编辑器仅在“显示终端”开启时显示“禁用 TaskAI 鼠标复制与右键粘贴”开关；关闭“显示终端”时，该值不影响后台命令。
- 从菜单项启动终端时，将该值写入终端运行时记录。终端创建后保留该快照，后续修改菜单项只影响新建终端。
- 当终端记录的值为 `true` 时，不注册选中自动复制，也不拦截右键菜单事件。键盘粘贴和终端程序自己的鼠标处理保持不变。
- 普通 Shell 终端、未勾选的菜单项以及旧设置中的菜单项继续使用现有默认行为。

## 取舍

1. 每个显示终端菜单项单独配置：采用。用户可以只为 Claude 等 TUI 关闭 TaskAI 鼠标处理，不影响其他命令。
2. 全局关闭鼠标剪贴板：会影响所有终端，不能满足按命令配置的需求。
3. 仅在前端临时保存菜单项与终端的对应关系：终端状态重新同步时可能丢失，且无法明确记录创建时的行为。

## 验证

- 设置校验会为旧菜单项补齐默认值，并保留自定义菜单项的配置。
- 通过菜单项创建终端时，终端记录携带对应开关；普通终端保持关闭状态。
- 前端测试覆盖两个分支：默认终端继续自动复制和右键粘贴；禁用后的终端不调用 Wails 剪贴板 API。
