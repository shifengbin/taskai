# 终端备注设计

> 更新：终端备注现已适用于所有活动终端，包括开启鼠标追踪的 Claude、Codex 等程序；选区保持与手势分流见 `2026-08-13-unify-terminal-mouse-selection-implementation.md`。

## 目标

在活动终端中，用户鼠标选中非空文本后可从选区附近的半透明备注按钮添加说明。备注只与创建它的终端会话绑定，只在本次应用运行期间存在；用户可从终端标题栏查看列表，并按设置模板一次性发送回同一终端。

## 交互

```text
鼠标选中终端文本
        ↓
选区附近显示半透明备注图标
        ↓ 点击
打开备注输入框（原文只读、备注可编辑）
        ↓ 保存
当前终端标题栏显示备注数量
        ↓ 点击标题栏备注图标
查看列表 → 发送到终端 → 无论结果均清空
```

关闭终端、终端退出、结束或删除所属任务、退出应用时，系统清除该终端的备注。备注不写入本地数据文件，重启后不会恢复。关闭 TaskAI 鼠标剪贴板处理的终端不显示备注入口，继续把鼠标操作交给终端程序。

## 模板

设置新增“终端备注”分类，保存以下三个字段：

- 原文前缀，默认 `原文：`
- 备注前缀，默认 `备注：`
- 列表统一后缀，默认空字符串

每条记录自动生成“原文前缀 + 原文 + 换行 + 备注前缀 + 备注”。记录按创建顺序以换行连接，最后无论统一后缀是否为空，都追加一个换行、统一后缀和结尾换行。

例如两条记录和后缀 `请逐项处理。` 会生成：

```text
原文：编译失败
备注：检查依赖版本
原文：测试超时
备注：确认网络环境
请逐项处理。
```

## 结构

- Go 设置模型仅持久化模板字段，并兼容缺少该字段的旧设置。
- 前端 `App` 以终端会话键维护备注列表，负责随终端生命周期释放。
- `TerminalSessionRegistry` 提供读取当前选区的受限方法；`TerminalView` 只负责浮动入口、输入框、标题栏面板和向同一 xterm 会话模拟粘贴。
- 汇总格式化使用纯前端函数，便于测试并避免界面预览与实际发送产生差异。

详细的 OpenSpec 决策和可验证需求分别位于 `openspec/changes/terminal-notes/design.md` 与 `openspec/changes/terminal-notes/specs/`。
