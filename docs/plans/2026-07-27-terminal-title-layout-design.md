# 终端标题自适应布局设计

## 背景

终端真实标题会随着运行程序变化。任务树终端项和右侧终端栏此前同时展示状态文字，且标题使用省略号截断，造成可用空间不足并遮蔽标题内容。

## 目标

- 使用颜色圆点表示终端状态，不展示“运行中”“已退出”等状态文字。
- 运行中的终端显示绿色圆点，已退出的终端显示红色圆点。
- 任务树终端标题和右侧终端标题始终保持单行。
- 标题占据同一行内除图标、状态点与关闭按钮之外的全部空间，并随容器宽度自然伸缩。
- 超出可用空间的标题直接裁剪，不换行、不显示省略号，也不设固定标题宽度。

## 组件设计

### 状态点

抽取终端状态点的展示逻辑，使用主题成功色表示活跃终端、错误色表示已退出终端。圆点提供可访问名称，供屏幕阅读器读取当前状态。

### 标题布局

终端条目和终端栏标题均采用弹性布局：标题容器设置 `flex: 1` 和 `minWidth: 0`，文本保持 `whiteSpace: nowrap`、隐藏溢出并使用 `textOverflow: clip`。因此容器因拖动或窗口变化而改变宽度时，标题可见区域同步变化。

右侧终端栏保留关闭按钮；任务树保留活动终端的关闭按钮。两处按钮不会挤出固定标题宽度。

## 测试

- 验证活跃和已退出终端分别暴露正确的状态点语义。
- 验证终端项不再渲染状态文字。
- 验证任务树和右侧栏的标题节点使用单行、隐藏溢出且无省略号的布局属性。
- 保留真实标题与回退标题的现有测试。
