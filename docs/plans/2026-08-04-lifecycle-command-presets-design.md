# 命令链预设设计

## 目标

用具名的命令链预设替代按钩子分别配置的默认链。用户可以在设置中维护成套选择，将一个预设应用到新建任务，并在任务内继续逐项调整；任务保存最终选择，不受预设后续变化影响。

## 术语与边界

- **命令链**：某个或多个生命周期钩子可执行的有序命令集合，继续沿用现有模型。
- **命令链预设**：五个生命周期钩子到命令链 ID 的具名映射，不复制命令链定义。
- **默认预设**：设置中至多一个预设，作为新建任务的初始命令链选择。
- **任务链选择**：任务自身保存的最终映射。任务不保存预设 ID，也不跟随预设变更。

本次不改变命令链的执行方式、任务状态约束或已创建任务的命令链解析规则。

## 数据模型

在设置中新增预设集合和默认预设标识，替代现有的逐钩子默认映射。

```text
LifecyclePreset
  ID       string
  Name     string
  Chains   map[LifecycleHook]string

Settings
  LifecyclePresets         []LifecyclePreset
  DefaultLifecyclePresetID string
```

- 预设名称去除首尾空白后必须非空，并在同一设置中唯一。
- 每个非空链 ID 必须存在，且对应命令链必须覆盖预设中的钩子。
- 空 `Chains` 合法，表示该预设不执行生命周期命令链。
- 默认预设 ID 可为空；为空时新建任务以空选择开始。
- 删除当前默认预设会清空默认预设 ID，不隐式改选其他预设。

任务仍只保存 `LifecycleChains`。新建任务表单始终显式提交当前映射，包括空映射，以区分“用户清空所有选择”和“调用旧入口而要求后端应用默认预设”。

## 迁移与兼容

- 新安装创建名称为“默认预设”的预设，包含现有默认行为：`beforeStart` 选择“创建任务工作目录”，`postEnd` 选择“删除任务工作目录”，并将其设为默认预设。
- 升级既有数据时，将原 `LifecycleDefaultChains` 映射迁移为一个“默认预设”并设为默认。原映射为空时也保留为空预设，确保新任务行为不变。
- 迁移以预置版本保护，只执行一次；完成后不再重建用户删除的预设。
- 旧任务已有 `LifecycleChains` 时保持不变；缺少该字段的历史任务兼容补齐逻辑改为读取默认预设，并继续按任务状态保留既有补齐规则。
- 不携带链选择的既有创建绑定继续从默认预设解析初始选择，保证旧调用方兼容；当前前端改为始终使用显式链选择入口。

## 设置交互

“生命周期编排”页顶部的“五个钩子的默认链”区域替换为“命令链预设”区域。

- 列表显示预设名称、五个钩子的已选链摘要及默认标记。
- 用户可新增、编辑、复制、删除预设，并将任一预设设为默认。
- 新增或编辑弹窗包含名称和五个钩子选择器；每个选择器只显示适用于该钩子的链，可留空。
- 预设列表和命令链列表使用专用保存接口；普通设置保存不得覆盖预设或默认预设选择。

不增加“根据当前任务选择创建预设”的入口，避免把任务编辑器和全局配置管理耦合。

## 新建与编辑任务交互

新建任务在“生命周期命令链”区域之前显示“命令链预设”选择器。

1. 打开新建任务时，表单读取默认预设的完整映射；无默认预设时从空映射开始。
2. 选择任一预设时，完整替换五个钩子的选择，包含清空该预设未设置的钩子。
3. 用户手动修改任一钩子后，预设选择器显示“自定义”。
4. 保存时任务仅保存最终的 `LifecycleChains` 映射。

编辑未执行任务时，界面将任务映射与当前预设逐项比较：完全匹配时显示对应预设，否则显示“自定义”。编辑执行中或已完成任务时，预设选择器与钩子选择器均只读；后端继续拒绝这些状态下的链选择修改。

## 一致性与错误处理

预设引用全局命令链，因此命令链的变更必须同时保护任务和预设。

- 删除被任一预设引用的命令链时，拒绝操作并指出引用该链的预设。
- 修改命令链适用范围时，若会使任一预设中的钩子引用无效，拒绝保存。
- 保存预设时拒绝不存在的命令链或范围不匹配的选择。
- 修改或删除预设不会影响已创建任务，因为任务没有预设关联。
- 删除命令或修改命令链内容的既有保护规则保持不变。

## 验证

- Go：预设规范化、名称和引用校验、默认预设切换、复制与删除、命令链删除或缩小范围的预设保护。
- Go：新安装默认预设、旧默认映射的一次性迁移、旧任务生命周期字段补齐，以及无默认预设的行为。
- 应用绑定：预设专用读写接口和旧创建入口读取默认预设。
- 前端：设置中预设管理，新建任务应用预设并覆盖所有钩子，手动改选显示自定义，以及清空全部钩子的显式保存。
- 回归：未执行任务可编辑，执行中和已完成任务的链选择保持只读。
