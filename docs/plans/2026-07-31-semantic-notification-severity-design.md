# 语义化提示颜色设计

## 目标

让应用提示颜色表达实际语义：错误使用红色，成功使用绿色，避免复制 JSON 成功提示看起来像失败。

## 设计

- 将当前仅保存文本的消息状态替换为包含文本与严重程度的通知状态。
- 所有表单校验、终端事件和异步异常通过统一错误入口生成 `error` 通知。
- “复制当前命令链输入 JSON”成功后生成 `success` 通知。
- Snackbar 按通知严重程度渲染 Material UI Alert；关闭行为与自动隐藏时间保持不变。

## 测试

扩展现有复制成功与复制失败交互测试，断言成功 Alert 为 `success`、失败 Alert 为 `error`。
