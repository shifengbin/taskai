# 额外信息编辑表单布局设计

## 背景

模板编辑弹窗中的分类、备注、固定字段和动态参数控件尺寸不一致。多个字段和操作按钮在窄宽度下共用紧凑网格，间距不足且没有稳定的最小列宽，导致字段贴近、操作控件被挤压。信息编辑弹窗和任务中的动态参数编辑区也存在同类问题。

## 目标

让模板、信息和任务三个编辑场景的输入控件保持紧凑、清晰且可在较窄窗口内自然换行，不修改字段含义、校验和保存数据。

## 方案

### 统一字段尺寸和基础布局

所有额外信息编辑输入使用 MUI `small` 尺寸。模板和信息弹窗的基础字段采用两列自适应网格，小窗口自动切换为单列，避免单个输入框横跨整个弹窗。

### 稳定的参数编辑行

固定字段和动态参数使用包含最小列宽的自适应网格。键、显示名称、类型和值在空间足够时并列；空间不足时按控件整体换行。删除按钮和复选框保持独立尺寸，不再因文本输入框缩放而互相覆盖。

每条字段或参数以垂直间距和细分隔线与相邻条目区分，不额外嵌套卡片。这样可以保留长列表的扫描密度，也能避免控件相邻过近。

### 覆盖范围

1. 新建和编辑模板：分类、备注、固定字段及模板动态参数。
2. 新建和编辑信息：选择模板、固定字段和信息级动态参数。
3. 新建和编辑任务：任务级动态参数的键、显示名称、类型、值、必填和删除操作。

## 验证

增加针对三个编辑场景的布局测试，确认编辑行使用紧凑字段和稳定网格；保留既有字段编辑、复选框和保存行为测试。完成后运行前端全量测试、Go 全量测试和 Linux 构建。
