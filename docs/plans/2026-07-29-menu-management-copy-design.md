# 菜单管理设置文案设计

## 背景

设置窗口已提供任务菜单项的排序和自定义命令管理能力，但对应 Tab 仍显示为“任务操作”。该名称容易与任务树中的三点操作按钮混淆。

## 方案

- 将设置窗口中 `menu` Tab 的可见标签改为“菜单管理”。
- 将该 Tab 的说明改为“右键菜单与任务操作下拉菜单共用此顺序。系统项仅可调序。”，明确这里管理的是菜单，而不是直接执行任务操作。
- 任务树三点按钮保持“任务操作”，因为其语义是对当前任务执行动作。
- 保持 `settingsTab` 的 `menu` 值、`taskMenuItems` 配置结构、持久化接口和运行时菜单行为不变。

## 备选方案

1. 仅修改设置窗口文案：实现范围最小，并能清楚区分“菜单管理”和运行时“任务操作”。采用此方案。
2. 全局替换“任务操作”：会改变运行时按钮的动作语义，且超出需求。
3. 新建独立菜单管理页面：重复现有设置能力，没有必要。

## 验证

前端测试应从设置窗口进入“菜单管理”Tab，继续验证菜单项编辑、排序与保存流程；已有任务树“任务操作”按钮测试保持不变。更新 README 中设置 Tab 的名称，并执行前端测试和项目 Linux 编译脚本。
