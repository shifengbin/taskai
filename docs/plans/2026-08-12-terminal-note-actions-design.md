# 终端备注操作设计

## 目标

在终端备注面板底部提供“操作后清空”复选框、“复制到剪贴板”和“发送到终端”三个操作组件。复制和发送使用相同的模板汇总文本；是否清空由当前终端会话的复选框决定。

## 状态与生命周期

- 清空偏好以 `任务 ID + 终端 ID` 为键，只保存在前端运行内存中。
- 新终端没有偏好记录时视为已勾选；取消或重新勾选后，关闭面板、切换终端再返回时保持该值。
- 终端退出或关闭、任务完成或删除、以及应用卸载时，清除偏好记录；应用重启后重新使用默认勾选。
- 备注内容仍使用现有的独立会话映射保存，偏好不会写入设置、任务数据或后端。

## 操作行为

- “复制到剪贴板”调用 Wails `ClipboardSetText`，复制 `formatTerminalNotes` 生成的完整文本。
- “发送到终端”继续通过当前 xterm 会话模拟粘贴同一完整文本，不追加 Enter。
- 任一操作结束后，若当前终端的“操作后清空”已勾选，则清空该终端备注；未勾选时保留备注。发送失败和复制失败也遵循该勾选值，并显示既有的错误提示。
- 操作完成后关闭备注面板并把焦点归还给当前终端。

## 验证

- 纯状态辅助函数覆盖默认勾选、会话隔离和任务清理。
- 组件测试覆盖默认勾选的复制及清空、取消勾选后的复制和发送保留、以及重新打开面板时同一终端保留勾选状态。
- App 测试覆盖终端生命周期清理偏好，并在完整前端测试、构建、Go 竞态测试和 Wails 运行中验证。
