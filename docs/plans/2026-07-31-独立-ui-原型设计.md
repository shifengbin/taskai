# 独立 UI 原型设计

## 目标

为“任务工作台”制作五套可在浏览器中直接打开的独立单页 UI 原型，帮助比较新的视觉方向。每套原型均保留应用的核心工作方式：顶部操作栏、左侧任务树、右侧任务详情与终端并排；并内置亮色与暗色主题。

## 边界

- 原型放在 `ui-prototypes/`，不导入、不修改 `frontend/src/` 的 React、MUI 或 Wails 代码。
- 每个方案是自包含 HTML 文件，包含自身的样式、示例数据与少量演示脚本，不依赖构建工具或网络资源。
- 示例数据覆盖未执行、执行中、已完成任务，任务实时状态、任务详情、生命周期信息和双终端；不连接后端、不执行命令。

## 共同信息架构

桌面工作台使用固定顶部栏；左栏提供三个任务状态标签和任务队列；右栏顶部显示当前任务、实时状态与主要操作，下方在“概览”和“终端”之间切换。亮暗切换位于顶部栏，任务状态标签、任务选择、详情/终端切换均可在浏览器中交互演示。

## 五套视觉方向

1. **白墙**：暖白、石墨与钴蓝的瑞士式秩序。以细线、明确对齐和单一强调色替代装饰性背景，适合长期作为默认界面。
2. **编辑部**：纸张米色、深墨与砖红的编辑版式。任务名使用衬线标题，元数据以小号标签呈现，适合重视任务内容和阅读节奏的场景。
3. **控制室**：雾蓝灰、工程绿与等宽数据标签的高密度工作台。突出生命周期步骤、时间和终端状态，适合频繁操作多任务的用户。
4. **夜航**：深海蓝与冷青的终端优先界面。右侧控制台获得更高视觉权重，亮色主题对应为低对比度的雾蓝，适合开发中的持续专注。
5. **庭院**：岩灰、鼠尾草绿与黏土色的低饱和队列。留白更充足，任务行更像安静的工作清单，适合需要降低视觉压力的使用者。

## 可访问性与适配

所有交互控件使用原生按钮，具备可见焦点样式和可读标签；亮暗模式保证主要文字与背景具有足够对比；动画限于短暂过渡，并在 `prefers-reduced-motion` 下关闭。原型按桌面端最小宽度设计，保持与当前 Wails 应用一致的并排工作台形态。

## 验收标准

- `ui-prototypes/` 包含五个可离线打开的 HTML 原型，且均能切换亮色与暗色主题。
- 五套原型共享同一核心信息架构，但字体、色彩、间距和视觉语言清晰不同。
- 不修改现有 `frontend/src/`，也不添加原型到前端构建入口。
