# 动态参数复选框类型设计

## 已确认的交互

- 动态参数新增输入类型，支持“文本”和“复选框”。
- 复选框新建时默认未选中，保存值为字符串 `false`；选中时保存为 `true`。
- 复选框不存在必填语义，界面不展示必填控件，服务端也强制将其规范化为非必填。
- 模板参数、信息专属参数和任务级新增参数都可选择复选框类型；任务中来自模板或信息的参数只允许修改值。
- 将现有文本参数切换为复选框时，值重置为 `false`，避免把任意文本误解释为布尔值。

## 数据与兼容性

为参数定义和带值参数增加 `inputType`，有效值为 `text` 与 `checkbox`。旧 JSON 未包含该字段时归一化为 `text`，保持既有保存内容和 HTTP 输出兼容。

复选框参数在模型归一化时只接受 `true` 或 `false` 两种字符串值；任务从模板参数创建快照且没有传入值时使用 `false`。信息参数保留自身保存的布尔默认值，任务选择该信息后复制该值。任务详情 API 继续按参数键输出值，不新增展示元数据。

## 界面与测试

参数编辑行增加类型下拉框。文本类型保留默认值和必填控件；复选框显示勾选控件并隐藏必填设置。任务编辑器按参数类型渲染文本框或复选框，既有来源锁定规则不变。

测试先覆盖模型对旧数据、非法布尔值、必填强制关闭和快照默认值的行为，再覆盖模板配置、信息默认值和任务勾选保存的前端流程。最后执行完整 Go、Vitest、前端构建、OpenSpec 和 Linux 构建验证。
