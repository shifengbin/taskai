# 任务悬浮提示换行设计

## 目标

任务列表在悬浮任务项时，提示框按任务描述原始内容保留换行和缩进；长行仍在提示框内自动换行。

## 现状

`TaskTree` 将完整描述放入 portal 提示框，但提示框使用浏览器默认的空白处理方式，换行会折叠为空格。任务卡片本身仍必须保持 60px 的两行、单行截断布局。

## 决策

给现有提示框添加 `whitespace-pre-wrap`。它能保留换行与连续空白，并配合已有 `break-words`、最大宽度和定位逻辑，避免引入新的组件或改变数据流。

不采用 `whitespace-pre-line`，因为它会压缩连续空白；不采用 `<pre>`，因为会改变当前字体和块布局。

## 验证

组件测试使用带换行和缩进的任务描述，确认提示同时保留原始文本并使用 `whitespace-pre-wrap`。随后执行前端测试、前端构建、Go 测试和 Linux 打包构建。
