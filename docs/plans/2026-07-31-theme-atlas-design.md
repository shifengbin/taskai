# 六套界面风格图鉴设计

## 目标

为任务工作台制作一个独立的单页视觉提案，不改动现有业务主界面。页面用于集中评审六套活泼、大胆的界面方向，并让每套方案都能查看亮色、暗色和新建任务弹窗状态。

## 展示结构

页面采用“主题图鉴”结构：顶部介绍评审目标，左侧为固定的主题导航，主内容按六个方案纵向排列。每个方案包含：

- 名称、设计关键词和三枚主色样本；
- 任务工作台的完整缩略场景，包括任务树、任务详情、终端和操作区；
- 亮色、暗色、弹窗三态切换控件；
- 随方案同步变化的“新建任务”弹窗，覆盖输入框、颜色选择、操作按钮和遮罩层。

小屏设备将导航收为横向主题索引，方案预览改为单列，保持操作与可读性。

## 六个视觉方向

1. **果汁俱乐部**：蜜桃、番茄红、钴蓝；饱满圆角、贴纸装饰与果汁般高对比色块。
2. **夜市电台**：荧光青、玫粉、深墨黑；复古电子仪表与发光状态信号。
3. **拼图总部**：明黄、靛蓝、砖红；拼贴杂志排版、粗边框与不对称卡片。
4. **熔岩赛道**：熔岩橙、酸性绿、炭黑；斜切分区、速度线和冲刺式高亮。
5. **泳池派对**：湖蓝、珊瑚、柠檬黄；波浪纹、半透明水面层次和漂浮标签。
6. **糖纸档案**：葡萄紫、薄荷、奶油白；糖纸色块、档案抽屉和俏皮标签系统。

## 交互与状态

每套方案独立保存当前预览状态，切换不会影响其他方案。状态切换采用短促的淡入与位移过渡；弹窗支持关闭按钮、遮罩点击和“取消”按钮关闭。主题导航可定位到对应方案。页面使用语义化按钮、可见焦点状态，并在用户偏好减少动态效果时关闭非必要动画。

## 技术边界

新增独立的 React 预览页与样式文件，通过现有 Vite 入口呈现。它仅使用静态演示数据，不调用 Wails API，也不修改任务、终端或设置功能。避免触及当前工作区中未提交的业务开发改动。
