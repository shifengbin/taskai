# 终端快捷键按键动作设计

## 背景

终端快捷键当前只支持文本和固定的回车动作。用户需要把任意常用按键或组合键作为动作保存，例如 `Tab`、`Ctrl+C` 和 `Shift+Tab`，并通过实际按键录入，避免手动填写按键名称。

## 设计

快捷键动作统一为两种：

- `text`：原样保存并直接写入文本。
- `key`：保存规范化的按键名称和修饰键数组，例如 `key: "C"`、`modifiers: ["Ctrl"]`。

设置编辑器为按键动作提供“录入按键”控件。控件捕获一次 `keydown`，忽略单独按下的修饰键，规范化 `KeyboardEvent.key` 与 `ctrl/alt/shift/meta`，然后显示组合键结果。设置对话框中的其他输入框不安装全局监听器。

发送端把按键动作映射成终端可识别的输入字节：可打印字符使用字符本身，控制组合键使用控制字节，导航键和功能键使用标准 xterm 转义序列，Alt 使用 ESC 前缀。无法安全映射的按键在保存时拒绝。动作仍按列表顺序逐步写入当前活动终端，快捷输入选择器的保留组合键优先级不变。

既有 `enter` 步骤作为兼容输入读取，并归一化为 `key: Enter`；新保存数据只输出 `text` 和 `key` 两种动作类型。

## 测试

- Go 设置测试覆盖 `key` 动作、修饰键、旧 `enter` 数据迁移和非法按键。
- 前端工具测试覆盖按键规范化与输入字节映射。
- 终端视图测试覆盖按键动作按序发送、组合键和关闭会话行为。
- 设置界面测试覆盖按键录入、文本/按键切换、取消和保存。
