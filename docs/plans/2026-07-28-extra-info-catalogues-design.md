# 额外信息分类与多键值设计

## 目标

让用户独立维护额外信息分类；每条信息可包含多组固定键值和多项动态参数，并能在创建或编辑任务时跨分类选择信息。

## 数据模型

- 在本地数据中新增分类名称集合，分类名称唯一。
- 模板仍使用分类名称关联，新增固定字段数组；固定字段包含键、显示名称和值。
- 模板继续保存动态参数定义；参数包含键、显示名称和必填标记。
- 任务附加信息快照复制分类、信息展示名称、固定字段及参数定义和参数值。
- 旧模板和旧任务快照中的单个 `key`、`keyDisplayName`、`value` 在读取时迁移为仅含一项的固定字段数组。

## 分类管理

- 额外信息管理弹窗提供分类下拉选择、新建分类和删除分类操作。
- 信息编辑表单只能从已创建的分类中选择分类。
- 分类下仍存在信息模板时，删除操作失败并提示先删除分类中的全部信息。
- 删除空分类不会删除或改写任何已创建任务的附加信息快照。

## 信息与任务交互

- 信息编辑表单支持增删多组固定字段，以及增删多项动态参数。
- 创建和编辑任务时，用户通过分类选择器查看当前分类的信息并进行勾选。
- 切换分类不会清除其他分类中已勾选的信息。
- 已选信息在表单顶部集中显示为紧凑方形标签，标签上的关闭按钮可取消选择。
- 参数输入仍在对应已选信息下显示，并沿用必填校验。

## HTTP 与兼容性

- 任务详情继续按分类聚合 `extraInfo`；每项输出固定字段和参数键值组成的扁平对象，不输出显示名称。
- 多个固定字段与参数键必须在同一信息内唯一，避免 HTTP 响应字段覆盖。
- 旧数据文件缺少分类集合或仍保存单键值格式时必须可读取；首次相关保存后以新格式持久化。

## 验证

- Go 单元测试覆盖分类创建/删除限制、多固定字段校验、旧数据迁移和 HTTP 聚合。
- 前端测试覆盖分类选择、跨分类勾选保留、已选方形标签移除和多字段编辑。
- 完成后执行全量 Go/前端测试、OpenSpec 严格校验和 Linux 构建脚本。
