# 额外信息模板、信息与任务快照设计

## 已确认的领域语言

系统中的“分类”即 **模板**，用于定义某类信息可填写的字段；模板本身不是可直接加入任务的具体数据。

```text
模板（字段与参数定义）
  -> 信息（模板对应的一条固定字段值）
    -> 任务附加信息快照（固定字段 + 本次任务的动态参数值）
```

- **模板**：定义固定字段、其显示名称和默认值，以及动态参数、其显示名称和必填标记。
- **信息**：先选择模板，再填写固定字段。每条信息可被多个任务复用。
- **任务附加信息快照**：任务选择信息后生成。固定字段不可改；动态参数可以填写、修改、删除或新增，且不会回写模板或信息。

## `name` 字段规则

- 每个模板必须包含固定字段 `name`。
- `name` 的字段值是信息列表、任务选择项和已选标签的展示内容，也是信息保存时的名称来源；不再维护单独可编辑的展示名称。
- 新建自定义模板自动添加 `name` 字段，用户可以调整它的显示名称。
- 保存信息时，`name` 的值必须非空；其他固定字段可使用空值或模板默认值。

## 内置 Git 模板

Git 模板作为默认分类自动存在，且不可删除。其初始结构如下：

| 类型 | 键 | 显示名称 | 规则 |
| --- | --- | --- | --- |
| 固定字段 | `name` | 项目名称 | 键和显示名称不可修改 |
| 固定字段 | `repository` | 仓库地址 | 键和显示名称不可修改，可设置默认值 |
| 动态参数 | `branch` | 仓库分支 | 键和显示名称不可修改，必填标记可配置 |

用户仍可为 Git 模板新增固定字段或动态参数，也可调整固定字段默认值。新建 Git 信息时，表单直接显示“项目名称”“仓库地址”输入框，并用对应的默认值预填；`branch` 不在信息表单填写，而是在任务中作为动态参数出现。

## 可编辑边界

| 位置 | 固定字段 | 动态参数 |
| --- | --- | --- |
| 模板 | 定义字段、显示名称和默认值；Git 内置项受保护 | 定义键、显示名称和必填标记；Git `branch` 的必填标记可调 |
| 信息 | 填写或更新固定字段实际值 | 不填写 |
| 创建/编辑任务 | 只读展示，不能新增或修改 | 可填写、修改、删除，并可新增任务级参数 |

任务级新增参数只属于该任务快照，键不得与固定字段或已有动态参数重复。模板或信息后续修改、删除均不会改写历史任务快照。

## 数据与兼容性

持久化结构从“分类集合 + 单层模板集合”演进为“模板定义集合 + 信息集合 + 既有任务快照”。加载时将旧模板拆分成模板定义和一条信息：旧展示名称成为 `name` 的值，旧固定值成为信息值与模板默认值。若同一旧分类有不同字段结构，迁移会拆分模板以保留数据。历史任务快照只做格式兼容，不通过新模板重新生成。

任务详情 HTTP 的 `extraInfo` 继续按 `catalogue` 分组，并以固定字段键、动态参数键平铺快照值，因此现有客户端无需适配新的领域层次。
